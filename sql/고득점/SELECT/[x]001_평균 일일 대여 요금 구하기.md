# 001. 평균 일일 대여 요금 구하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/151136?language=mysql)

- 분류: SELECT
- 문제 번호: 151136

## 문제 설명

다음은 어느 자동차 대여 회사에서 대여중인 자동차들의 정보를 담은 `CAR_RENTAL_COMPANY_CAR` 테이블입니다. `CAR_RENTAL_COMPANY_CAR` 테이블은 아래와 같은 구조로 되어있으며, `CAR_ID`, `CAR_TYPE`, `DAILY_FEE`, `OPTIONS`는 각각 자동차 ID, 자동차 종류, 일일 대여 요금(원), 자동차 옵션 리스트를 나타냅니다.

| Column name | Type | Nullable |
| --- | --- | --- |
| CAR_ID | INTEGER | FALSE |
| CAR_TYPE | VARCHAR(255) | FALSE |
| DAILY_FEE | INTEGER | FALSE |
| OPTIONS | VARCHAR(255) | FALSE |

자동차 종류는 '세단', 'SUV', '승합차', '트럭', '리무진'이 있습니다. 자동차 옵션 리스트는 콤마(',')로 구분된 키워드 리스트(예: '열선시트', '스마트키', '주차감지센서')로 되어있으며, 키워드 종류는 '주차감지센서', '스마트키', '네비게이션', '통풍시트', '열선시트', '후방카메라', '가죽시트'가 있습니다.

## 문제

`CAR_RENTAL_COMPANY_CAR` 테이블에서 자동차 종류가 'SUV'인 자동차들의 평균 일일 대여 요금을 출력하는 SQL문을 작성해주세요. 이때 평균 일일 대여 요금은 소수 첫 번째 자리에서 반올림하고, 컬럼명은 `AVERAGE_FEE`로 지정해주세요.

## 예시

예를 들어 `CAR_RENTAL_COMPANY_CAR` 테이블이 다음과 같다면

| CAR_ID | CAR_TYPE | DAILY_FEE | OPTIONS |
| --- | --- | --- | --- |
| 1 | 세단 | 16000 | 가죽시트,열선시트,후방카메라 |
| 2 | SUV | 14000 | 스마트키,네비게이션,열선시트 |
| 3 | SUV | 22000 | 주차감지센서,후방카메라,가죽시트 |

'SUV'에 해당하는 자동차들의 평균 일일 대여 요금은 18,000원이므로, 다음과 같은 결과가 나와야 합니다.

| AVERAGE_FEE |
| --- |
| 18000 |

## 문제 코드

```sql
-- 코드를 입력하세요
SELECT
```

사용 DBMS: MySQL. Oracle 지원 여부는 원문 언어 선택 목록에서 확인합니다.

## 내가 푼 답

```sql
SELECT AVG(DAILY_FEE) as AVERAGE_FEE FROM CAR_RENTAL_COMPANY_CAR WHERE CAR_TYPE = "SUV";
```

- SUV를 고르고 평균을 구하는 부분은 맞습니다. 평균을 반올림하는 `ROUND()`가 빠졌습니다.

## 수정한 답

```sql
SELECT ROUND(AVG(DAILY_FEE), 0) AS AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE = 'SUV';
```

- `AVG(DAILY_FEE)`를 `ROUND(AVG(DAILY_FEE), 0)`으로 감싸면 됩니다. 평균을 먼저 구하고 그 결과를 반올림합니다.
- 예시 평균은 `(14000 + 22000) / 2 = 18000`이라 반올림 전후가 같지만, 소수가 나오는 입력에도 맞아야 합니다.

## 정리

### 조회·평균 문법

- `SELECT 값` : 결과로 출력할 컬럼이나 계산식을 지정합니다.
- `FROM 테이블` : 어느 테이블에서 데이터를 가져올지 지정합니다.
- `WHERE 조건` : 조건에 맞는 행만 고릅니다. `CAR_TYPE = 'SUV'`는 자동차 종류가 SUV인 행입니다.
- `AVG(컬럼)` : 해당 컬럼의 평균을 구하는 집계 함수입니다. NULL은 제외합니다. 이 문제의 DAILY_FEE는 NULL이 없습니다.
- `AS 이름` : 결과 컬럼의 별명을 지정합니다. 여기서는 `AVERAGE_FEE`입니다. 원본 컬럼명을 바꾸는 것은 아닙니다.
- 문자열은 `'SUV'`처럼 작은따옴표를 사용합니다. MySQL의 큰따옴표는 설정에 따라 식별자용으로 해석될 수 있습니다.
- 이 쿼리는 테이블에서 SUV 행만 고른 뒤 그 요금들의 평균을 내고 반올림한다고 이해하면 됩니다. 모든 SUV를 하나로 집계하므로 GROUP BY는 필요 없습니다.

### 반올림·올림·내림

- `ROUND(숫자, 남길 소수 자릿수)` : 지정한 자리까지 남기도록 반올림합니다. 두 번째 인자 0은 소수 자릿수를 남기지 않는다는 뜻입니다.
- **소수 첫 번째 자리에서 반올림** : 소수 첫째 자리를 보고 정수로 만듭니다. `ROUND(18000.6, 0)` → `18001`, `ROUND(18000.4, 0)` → `18000`.
- **소수 첫 번째 자리까지 표시하도록 반올림** : 소수 둘째 자리를 보고 첫째 자리까지 남깁니다. `ROUND(12.36, 1)` → `12.4`. ‘에서’와 ‘까지’를 구분합니다.
- `ROUND(숫자)` : 자릿수를 생략하면 0입니다. `ROUND(AVG(DAILY_FEE))`도 같은 풀이입니다.
- `CEIL(숫자)` : 그 숫자 이상인 가장 작은 정수로 올립니다. `CEIL(12.1)` → `13`.
- `FLOOR(숫자)` : 그 숫자 이하인 가장 큰 정수로 내립니다. `FLOOR(12.9)` → `12`.
- `TRUNCATE(숫자, 자릿수)` : 반올림하지 않고 뒤를 버립니다. `TRUNCATE(12.96, 1)` → `12.9`.
- 음수에서는 내림과 버림이 다릅니다. `FLOOR(-12.3)` → `-13`, `TRUNCATE(-12.3, 0)` → `-12`.
- 이 문제의 핵심: **평균은 AVG, 반올림은 ROUND, 결과 이름은 AS**입니다.
