# 14. 문자열의 뒤의 n글자

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181910?language=javascript)

- 분류: 코딩 기초 트레이닝 · 문자열 · Lv. 0
- 상태: [x] 풀이 완료

## 문제 설명

문자열 `my_string`과 정수 `n`이 매개변수로 주어질 때, `my_string`의 뒤의 `n`글자로 이루어진 문자열을 return 하는 solution 함수를 작성해 주세요.

## 제한사항

- `my_string`은 숫자와 알파벳으로 이루어져 있습니다.
- 1 ≤ `my_string`의 길이 ≤ 1,000
- 1 ≤ `n` ≤ `my_string`의 길이

## 입출력 예

| my_string | n | result |
| --- | ---: | --- |
| `"ProgrammerS123"` | 11 | `"grammerS123"` |
| `"He110W0r1d"` | 5 | `"W0r1d"` |

## 입출력 예 설명

- 예제 #1: ProgrammerS123에서 뒤의 11글자는 grammerS123이므로 이 문자열을 반환합니다.
- 예제 #2: He110W0r1d에서 뒤의 5글자는 W0r1d이므로 이 문자열을 반환합니다.

## 문제 코드

```javascript
function solution(my_string, n) {
  var answer = '';
  return answer;
}
```

## 나의 풀이

```javascript
const solution = (my_string, n) => my_string.slice(-n);
```

정답입니다. 뒤에서 n번째 위치부터 끝까지 꺼냅니다. 원본 문자열은 바꾸지 않습니다.

## 다른 방법

### (1) 중괄호 + return — 같은 풀이를 풀어 쓰기

```javascript
const solution = (my_string, n) => {
  return my_string.slice(-n);
};
```

네 풀이와 동작은 같습니다. 중괄호를 썼으므로 반환할 값을 return으로 지정합니다.

### (2) 길이로 시작 위치 계산하기

```javascript
function solution(my_string, n) {
  return my_string.slice(my_string.length - n);
}
```

전체가 5글자이고 뒤의 2글자가 필요하면 시작 인덱스는 `5 - 2 = 3`입니다. 이 문제의 범위에서는 slice(-n)과 같습니다.

### (3) substring — 음수 대신 계산한 위치 사용

```javascript
function solution(my_string, n) {
  return my_string.substring(my_string.length - n);
}
```

substring은 음수를 뒤에서 세지 않고 0으로 처리합니다. `substring(-n)`으로 바꾸면 안 됩니다.

## 배울 것들

### slice의 음수는 ‘뒤에서 센 시작 위치’

- 사용법: `문자열.slice(시작, 끝)`. 시작부터 **끝 인덱스 직전까지** 꺼내며, 끝을 생략하면 마지막까지 꺼냅니다.
- 시작이 0 이상이면 앞에서, 음수이면 문자열 끝을 기준으로 셉니다.
- `-1`은 마지막 글자, `-2`는 뒤에서 두 번째 글자의 위치입니다. **역순으로 읽는다는 뜻은 아닙니다.**
- `slice(-n)`은 ‘뒤에서 n번째 위치부터 끝까지’이므로 뒤의 n글자가 됩니다.
- 이 문제에서 `slice(-n)`의 시작 위치는 `my_string.length - n`과 같습니다.

```javascript
// 글자:       a   b   c   d   e
// 앞 인덱스:  0   1   2   3   4
// 뒤 기준:   -5  -4  -3  -2  -1
'abcde'.slice(-1);     // 'e'
'abcde'.slice(-2);     // 'de' — 'ed'가 아님
'abcde'.slice(3);      // 'de' — 5 - 2 = 3
'abcde'.slice(-3, -1); // 'cd' — -1 위치의 e는 제외
'abcde'.slice(-5);     // 'abcde'
```

- 두 번째 인자도 음수로 쓸 수 있지만, 여전히 **끝 위치는 포함하지 않습니다**.
- 시작이 문자열 앞을 넘어가면 0부터 처리합니다. `'abc'.slice(-10)` → 'abc'.
- `-0`은 0과 같아서 `'abc'.slice(-0)`은 전체 문자열입니다. 이 문제는 n ≥ 1이라 상관없습니다.
- 배열에도 slice가 있습니다. `[1, 2, 3].slice(-2)` → [2, 3]. 문자열에서는 문자열, 배열에서는 새 배열을 반환합니다.
- 문자열의 slice는 여기처럼 숫자·알파벳에서는 글자 단위로 생각해도 됩니다. 이모지 등이 있는 일반 문자열에서는 UTF-16 코드 단위 기준이라는 점을 따로 주의합니다.

### 화살표 함수에서 {}가 없으면 왜 return을 안 써도 될까?

JavaScript가 화살표 함수의 본문을 **두 가지 문법**으로 정해 두었기 때문입니다.

- `(매개변수) => 표현식`: 표현식을 계산한 값을 **자동으로 반환**합니다. 이를 암시적 반환이라고 합니다.
- `(매개변수) => { 실행문들 }`: 중괄호는 여러 실행문을 담는 **블록**입니다. 반환할 값은 return으로 직접 지정해야 합니다.
- **표현식**은 계산하면 값이 나오는 코드입니다. `a + b`, `str.slice(-n)`, `조건 ? 1 : 0`이 해당합니다.
- ‘한 줄이라 자동 반환’이 아니라 **화살표 뒤 본문이 표현식 형태라 자동 반환**하는 것입니다.

```javascript
const addA = (a, b) => a + b;             // 자동 반환
const addB = (a, b) => {return a + b;};   // 직접 반환
const addC = (a, b) => {a + b;};          // 계산만 하고 반환하지 않음

console.log(addA(2, 3)); // 5
console.log(addB(2, 3)); // 5
console.log(addC(2, 3)); // undefined
```

- `=> {my_string.slice(-n);}`이라고만 쓰면 결과를 계산하고 버려서 undefined가 반환됩니다.
- `=> return my_string.slice(-n)`은 문법 오류입니다. return을 쓰려면 `=> {return ...;}` 형태로 씁니다.
- 일반적인 `function solution(...) { ... }`에는 이 생략 문법이 없습니다. 값을 반환하려면 return이 필요합니다.
- 객체를 바로 반환할 때는 `const make = () => ({name: 'kim'});`처럼 괄호로 감쌉니다. 객체의 {}를 함수 본문 블록으로 오해하지 않도록 **객체 표현식**임을 표시하는 것입니다.

## 시간·공간 복잡도 쉽게 보기

- 여기서 n은 꺼내서 반환할 글자 수입니다. 전체 길이와 구분합니다.
- 결과를 복사해 만든다고 보면, 5글자를 반환할 때 5글자, 100글자면 100글자를 처리하므로 **시간 O(n)**으로 설명합니다.
- 결과 문자열도 n글자를 저장하므로 **결과 포함 추가 공간 O(n)**으로 설명합니다. 코드가 한 줄이라고 O(1)이 되는 것은 아닙니다.
- 실제 slice·substring의 복사 여부와 저장 방식은 JavaScript 엔진에 따라 최적화될 수 있습니다. 위 설명은 결과 n글자를 새로 만드는 비용을 기준으로 한 학습용 분석입니다.
- 네 풀이와 다른 풀이들은 반환하는 문자열이 같습니다. 중괄호·return을 생략하는 것 자체가 성능 개선은 아닙니다.

**가장 추천하는 풀이: 네 slice(-n) 풀이 — ‘뒤의 n글자’라는 목적을 바로 표현하고, 시작 인덱스를 따로 계산할 필요도 없습니다.**
