# 15. 문자열로 변환

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181845?language=javascript)

- 분류: 코딩 기초 트레이닝 · 함수(메서드) · Lv. 0
- 상태: [x] 풀이 완료

## 문제 설명

정수 `n`이 주어질 때, `n`을 문자열로 변환하여 return하도록 solution 함수를 완성해주세요.

## 제한사항

- 1 ≤ `n` ≤ 10000

## 입출력 예

| n | result |
| ---: | --- |
| 123 | `"123"` |
| 2573 | `"2573"` |

## 입출력 예 설명

- 예제 #1: 숫자 123을 문자열 "123"으로 변환해 반환합니다.
- 예제 #2: 숫자 2573을 문자열 "2573"으로 변환해 반환합니다.

## 문제 코드

```javascript
function solution(n) {
  var answer = '';
  return answer;
}
```

## 나의 풀이

```javascript
const solution = (n) => String(n);
```

정답입니다. String을 함수로 호출해 숫자를 문자열로 바꿉니다. 가져온 설명의 ‘에러가 나거나 정답이 아니다’라는 말은 **이 코드에는 해당하지 않습니다.**

## 다른 방법

### (1) toString — 숫자에 붙여 호출

```javascript
const solution = (n) => n.toString();
```

n에 들어 있는 숫자를 문자열로 바꿉니다. 이 문제에서는 String(n)과 결과가 같습니다.

### (2) 빈 문자열 더하기 — 자동 형변환

```javascript
const solution = (n) => n + '';
```

숫자에 빈 문자열을 더하면 문자열 연결이 일어나 결과가 문자열이 됩니다.

### (3) 템플릿 리터럴 — 문자열에 값 넣기

```javascript
const solution = (n) => `${n}`;
```

백틱 안의 `${n}` 자리에 값이 문자열로 들어갑니다. 문장을 만들 때도 쓰지만, 단순 변환에는 String(n)이 더 직접적입니다.

## 배울 것들

### 함수와 메서드의 차이

- **함수**: 호출해서 일을 시키는 코드입니다. `solution(n)`, `String(n)`처럼 호출합니다.
- **메서드**: 객체의 속성으로 제공되는 함수입니다. `n.toString()`, `arr.map()`처럼 대상에 붙여 호출합니다. **메서드도 함수입니다.**
- `String(n)`은 바꿀 값을 **괄호 안에 인자**로 전달하고, `n.toString()`은 **점 앞의 값**을 대상으로 실행합니다.
- 점이 없는 함수와 점이 있는 메서드를 완전히 다른 종류의 기능으로 외우기보다, **함수를 어디에 두고 어떻게 호출하는지의 차이**로 이해하면 됩니다.

### String()은 뭐야?

- JavaScript가 제공하는 내장 기능입니다. 대문자 S를 써서 `String(변환할값)`으로 호출합니다.
- 지금처럼 new 없이 호출하면 문자열 원시값을 반환합니다. `String(123)` → `'123'`.
- 원래 변수 n이 바뀌는 것은 아닙니다. 변환 결과를 새로 반환합니다.
- `new String(123)`은 문자열을 감싼 **객체**를 만듭니다. 이 문제에서는 new를 붙이지 않습니다.

```javascript
const n = 123;
const text = String(n);
console.log(typeof n);                  // 'number'
console.log(typeof text);               // 'string'
console.log(typeof new String(123));    // 'object'
```

### ?.toString() 앞에는 뭐가 들어가?

여기서 말하는 ‘?’는 변환할 값을 뜻하는 빈자리일 뿐입니다. 실제 코드에는 `n.toString()`처럼 **변수나 값**을 적습니다. 별도 문법인 `?.`와는 구분합니다.

| 대상 | 예시 | 결과 |
| --- | --- | --- |
| 숫자 변수 | `const n = 123; n.toString()` | '123' |
| 숫자 값 | `(123).toString()` | '123' |
| 불리언 | `true.toString()` | 'true' |
| 문자열 | `'abc'.toString()` | 'abc' |
| 배열 | `[1, 2, 3].toString()` | '1,2,3' |
| 일반 객체 | `({name: 'kim'}).toString()` | '[object Object]' |

- 메서드라고 해서 점 앞에 반드시 `{}` 모양의 객체를 직접 써야 하는 것은 아닙니다. 숫자·문자열 같은 원시값에도 해당 메서드를 호출할 수 있게 JavaScript가 처리해 줍니다.
- **자료형마다 toString의 동작이 다릅니다.** 일반 객체를 예쁘게 출력하거나 JSON으로 바꾸는 기능이라고 생각하면 안 됩니다.
- 숫자 리터럴은 `(123).toString()`처럼 괄호로 감싸면 소수점 표기와 헷갈리지 않습니다.
- `toString(n)`은 `String(n)`의 대체 코드가 아닙니다. 실행 환경에서 같은 이름이 존재할 수도 있지만, n을 대상으로 변환하는 호출 방식은 `n.toString()`입니다.
- `n.toString(2)`의 2는 ‘변환할 값’이 아니라 **진법**입니다. `(10).toString(2)` → '1010'. 생략하면 숫자를 10진수 문자열로 바꿉니다.
- null과 undefined에는 직접 toString을 호출할 수 없습니다. 반면 `String(null)` → 'null', `String(undefined)` → 'undefined'입니다. 이 문제는 정수만 주어집니다.

### 숫자 + 빈 문자열은 왜 문자열이 돼?

- `+`는 숫자끼리 만나면 **덧셈**, 이 예시처럼 한쪽이 문자열이면 **문자열 연결**을 합니다.
- `''`는 글자가 하나도 없는 **빈 문자열**입니다. `' '`는 공백 한 글자가 들어 있는 문자열이라 다릅니다.
- `123 + ''`에서는 숫자 123이 '123'으로 변환되고, 뒤에 아무 글자도 붙지 않아 결과는 '123'입니다.
- 자동으로 자료형이 바뀌는 것을 **암시적 형변환**, String(n)처럼 변환을 직접 요청하는 것을 **명시적 형변환**이라고 합니다.

```javascript
123 + '';       // '123'
'' + 123;       // '123'
123 + ' ';      // '123 ' — 뒤에 공백이 붙음
1 + 2;          // 3
1 + '2';        // '12'
1 + 2 + '';     // '3' — 먼저 1 + 2
'' + 1 + 2;     // '12' — 먼저 '' + 1
'5' - 2;        // 3 — -는 문자열 연결이 아니라 숫자 계산
```

- 같은 우선순위의 +는 왼쪽부터 계산하므로 **문자열이 언제 등장하느냐**에 따라 결과가 달라집니다.
- ‘문자열과 계산하면 무조건 문자열’은 아닙니다. 문자열 연결 규칙은 +에서 주의하면 됩니다.
- ‘코딩테스트에서 가장 많이 쓰는 방법’이라고 단정할 근거는 없습니다. 짧은 코드보다 변환 의도가 분명한 String(n)을 우선 익히면 됩니다.

## 시간·공간 복잡도 쉽게 보기

- 여기의 n은 **숫자의 값**입니다. n이 10000이라고 10000번 반복하는 것은 아닙니다.
- 123은 결과가 3글자, 10000은 5글자입니다. 변환과 저장에서 중요한 것은 만들어지는 **자릿수**입니다.
- 결과가 d글자라고 하면, 글자를 만들어 저장하는 비용을 기준으로 시간·결과 공간을 O(d)로 설명할 수 있습니다.
- 이 문제는 최대 10000, 즉 결과가 최대 5글자로 제한됩니다. 이 제한 안에서는 시간·추가 공간 모두 **O(1)**로 봅니다. 메모리를 전혀 안 쓴다는 뜻이 아니라 처리·저장 크기에 고정된 상한이 있다는 뜻입니다.
- 위 방법들은 이 문제에서 복잡도로 우열을 가릴 필요가 없습니다. 실제 내부 구현 차이보다 읽기 쉬운 변환 방법을 고르면 됩니다.
