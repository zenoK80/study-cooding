# n 번째 원소까지

## 문제

정수 배열 `num_list`의 첫 번째 원소부터 `n`번째 원소까지를 새로운 배열로 반환한다.

```javascript
function solution(num_list, n) {
  return num_list.slice(0, n);
}
```

---

# 배울 것

## 1. 배열의 인덱스

JavaScript 배열의 인덱스는 `0`부터 시작한다.

```javascript
const numbers = [5, 2, 1, 7, 5];
//               0  1  2  3  4
```

| 순서 | 첫 번째 | 두 번째 | 세 번째 |
|---|---:|---:|---:|
| 인덱스 | 0 | 1 | 2 |
| 값 | 5 | 2 | 1 |

따라서 `n`번째 원소의 인덱스는 `n - 1`이다.

```javascript
const n = 3;

numbers[n - 1];
// numbers[2]
// 결과: 1
```

---

## 2. `slice()`란?

`slice()`는 배열의 일부를 잘라서 **새로운 배열로 반환하는 메서드**다.

```javascript
배열.slice(시작 인덱스, 종료 인덱스);
```

```javascript
const numbers = [10, 20, 30, 40, 50];

const result = numbers.slice(1, 4);

console.log(result);
// [20, 30, 40]
```

`slice(1, 4)`의 범위는 다음과 같다.

```text
시작 인덱스 1은 포함
종료 인덱스 4는 포함하지 않음
```

따라서 인덱스 `1`, `2`, `3`의 값만 반환한다.

---

## 3. `slice()`의 인자

```javascript
array.slice(인자1, 인자2);
```

### 인자 1: 시작 인덱스

배열을 자르기 시작할 위치다.

```javascript
const numbers = [10, 20, 30, 40];

numbers.slice(1);
// [20, 30, 40]
```

인자 2를 생략하면 시작 위치부터 배열 끝까지 반환한다.

### 인자 2: 종료 인덱스

배열 자르기를 끝낼 위치다.

단, 종료 인덱스에 있는 원소는 결과에 포함하지 않는다.

```javascript
const numbers = [10, 20, 30, 40];

numbers.slice(0, 2);
// [10, 20]
```

범위는 인덱스 `0`부터 `2` 직전까지다.

```text
0 이상 2 미만
```

---

## 4. 왜 `slice(0, n)`인가?

```javascript
function solution(num_list, n) {
  return num_list.slice(0, n);
}
```

`slice(0, n)`은 다음 범위를 반환한다.

```text
인덱스 0부터 인덱스 n 직전까지
```

`n`이 `3`이라면:

```javascript
const num_list = [5, 2, 1, 7, 5];
const n = 3;

num_list.slice(0, n);
// num_list.slice(0, 3)
// [5, 2, 1]
```

`slice()`의 종료 인덱스는 포함되지 않으므로 실제로 가져오는 인덱스는 다음과 같다.

```text
0, 1, 2
```

이는 첫 번째부터 세 번째 원소까지와 같다.

따라서 `n - 1`을 사용하지 않고 `n`을 그대로 종료 인덱스로 넣는다.

```javascript
num_list.slice(0, n);     // 올바름
num_list.slice(0, n - 1); // 원소가 하나 부족함
```

---

## 5. 원본 배열은 변경되지 않는다

`slice()`는 원본 배열을 수정하지 않고 새로운 배열을 만든다.

```javascript
const numbers = [1, 2, 3, 4];
const result = numbers.slice(0, 2);

console.log(result);
// [1, 2]

console.log(numbers);
// [1, 2, 3, 4]
```

---

# 실행 흐름

```javascript
solution([5, 2, 1, 7, 5], 3);
```

```text
1. num_list에는 [5, 2, 1, 7, 5]가 들어온다.
2. n에는 3이 들어온다.
3. slice(0, 3)을 실행한다.
4. 인덱스 0부터 3 직전까지 자른다.
5. 인덱스 0, 1, 2의 값이 선택된다.
6. 새로운 배열 [5, 2, 1]을 반환한다.
```

---

# 핵심 정리

- 배열의 인덱스는 `0`부터 시작한다.
- `slice()`는 배열의 일부를 새로운 배열로 반환한다.
- `slice(시작, 종료)`에서 시작 인덱스는 포함한다.
- 종료 인덱스는 포함하지 않는다.
- `slice(0, n)`은 첫 번째 원소부터 `n`번째 원소까지 반환한다.
- `slice()`는 원본 배열을 변경하지 않는다.
