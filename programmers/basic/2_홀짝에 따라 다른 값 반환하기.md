# 2. 홀짝에 따라 다른 값 반환하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181935?language=javascript)

## 문제 설명

양의 정수 `n`이 매개변수로 주어질 때, `n`이 홀수라면 `n` 이하의 홀수인 모든 양의 정수의 합을 return 하고 `n`이 짝수라면 `n` 이하의 짝수인 모든 양의 정수의 제곱의 합을 return 하는 solution 함수를 작성해 주세요.

## 제한사항

- 1 ≤ `n` ≤ 100

## 입출력 예

| n | result |
| ---: | ---: |
| 7 | 16 |
| 10 | 220 |

## 입출력 예 설명

- 예제 #1: 7 이하의 양의 홀수는 1, 3, 5, 7이므로 `1 + 3 + 5 + 7 = 16`입니다.
- 예제 #2: 10 이하의 양의 짝수는 2, 4, 6, 8, 10이므로 `2² + 4² + 6² + 8² + 10² = 4 + 16 + 36 + 64 + 100 = 220`입니다.

## 문제 코드

```javascript
function solution(n) {
  var answer = 0;
  return answer;
}
```

## 나의 풀이

```javascript
function solution(n) {
  if (n < 1 || n > 100) return;
  var answer = 0;
  if (n % 2 === 1) {
    for (let i = 0; i <= n; i++) {
      if (i % 2 === 0) continue;
      answer += i;
    }
  }
  if (n % 2 === 0) {
    for (let i = 0; i <= n; i++) {
      if (i % 2 === 1) continue;
      answer += i ** 2;
    }
  }
  return answer;
}
```

정답입니다. 짝수일 때 0도 계산하지만 `0 ** 2`는 0이라 결과에 영향이 없습니다.

## 다른 방법

### (1) 2씩 증가 — 추천

```javascript
function solution(n) {
  let answer = 0;
  if (n % 2 === 1) {
    for (let i = 1; i <= n; i += 2) {answer += i;}
  } else {
    for (let i = 2; i <= n; i += 2) {answer += i ** 2;}
  }
  return answer;
}
```

필요한 홀수 또는 짝수만 방문해서 나머지 숫자를 검사하는 일을 줄입니다.

### (2) Array.from + filter + reduce — 배열 메서드 연습

```javascript
function solution(n) {
  const isEven = n % 2 === 0;
  return Array.from({ length: n }, (_, i) => i + 1)
    .filter(value => isEven ? value % 2 === 0 : value % 2 === 1)
    .reduce((sum, value) => sum + (isEven ? value ** 2 : value), 0);
}
```

1~n 배열 생성 → 필요한 수만 남김 → 합산합니다. 반복문보다 배열을 더 만듭니다.

### (3) 합 공식 — 수학 원리 연습

```javascript
function solution(n) {
  if (n % 2 === 1) return ((n + 1) / 2) ** 2;
  return n * (n + 1) * (n + 2) / 6;
}
```

홀수 m개의 합은 `1 + 3 + … + (2m - 1) = m²`입니다. 짝수의 제곱합은 `4 × (1² + … + m²) = 4 × m(m + 1)(2m + 1) / 6`이며 `m = n / 2`를 대입한 식입니다. 반복문 없이 정해진 계산으로 합을 구합니다.

## 배울 것들

- `%`: 나머지 연산자. `n % 2 === 0`은 짝수, 이 문제의 양수에서는 `n % 2 === 1`은 홀수입니다.
- `**`: 거듭제곱 연산자. `4 ** 2`는 16이며 `4 * 4`, `Math.pow(4, 2)`와 같습니다.
- `continue`: 현재 반복의 나머지를 건너뜁니다. for문의 증감식을 실행한 뒤 다음 조건을 확인합니다.
- `break`: 반복문을 종료합니다. `return`: 함수 전체를 종료합니다. 셋은 다릅니다.
- `i += 2`: 같은 홀짝을 유지하며 이동합니다. 필요 없는 숫자를 검사하지 않아도 됩니다.
- `filter(조건 함수)`: 조건이 참인 원소만 담은 새 배열을 반환합니다.
- `reduce((누적값, 현재값) => 다음 누적값, 시작값)`: 여기서는 시작값 0부터 합을 누적합니다.
- `Array.from({ length: n }, (_, i) => i + 1)`: 길이 n인 배열에 1~n을 담습니다. `_`는 사용하지 않는 인자를 나타내려고 붙인 일반 변수명입니다.
- 홀수·짝수는 둘 중 하나이므로 `if / else`로 분기할 수 있습니다. 문제에서 범위를 보장하므로 입력 검사는 생략해도 됩니다.

## 시간·공간 복잡도 쉽게 보기

- **시간 복잡도**: 데이터가 많아지면 해야 할 일이 얼마나 늘어나는지 봅니다. 정확히 몇 초 걸리는지 뜻하는 것은 아닙니다.
- **공간 복잡도**: 풀이 중 새로 저장하는 데이터가 얼마나 늘어나는지 봅니다. 여기서는 정답을 담는 배열·문자열도 포함합니다.
- **O(1)**: 데이터가 늘어도 작업량 또는 저장량이 일정합니다. 딱 1번만 실행한다는 뜻은 아닙니다.
- **O(n)**: 데이터 개수 n에 비례해서 늘어납니다. 10개를 처리하다 20개가 되면 작업도 대략 2배입니다.

### 내 풀이: 반복해서 더하기

- n = 10이면 i = 0~10을 확인합니다. n = 100이면 i = 0~100을 확인하므로 n이 커질수록 검사도 늘어납니다. 그래서 시간은 `O(n)`입니다.
- 홀수일 때와 짝수일 때 중 한쪽 반복문만 실행됩니다. 반복문이 두 개 보인다고 `O(n²)`이 아닙니다.
- 저장하는 것은 합계 answer와 반복 숫자 i 등 몇 개뿐입니다. n이 커져도 숫자들을 배열에 모으지 않으므로 추가 공간은 `O(1)`입니다.

### 다른 방법과 비교

- **(1) 2씩 증가**: n = 10이면 2, 4, 6, 8, 10만 계산합니다. 검사 횟수는 줄지만 n이 두 배가 되면 반복도 대략 두 배라 시간은 여전히 `O(n)`입니다. 저장량은 일정해 추가 공간 `O(1)`입니다.
- **(2) 배열 메서드**: 1~n 배열을 만들고, 골라내고, 더합니다. 여러 번 순서대로 훑어도 작업은 n에 비례하므로 시간 `O(n)`입니다. n개의 숫자를 담는 새 배열도 만들어 추가 공간은 `O(n)`입니다.
- **(3) 합 공식**: n = 10이든 100이든 정해진 덧셈·곱셈·나눗셈으로 끝납니다. 이 문제의 숫자 범위에서 시간·추가 공간 모두 `O(1)`입니다.
- 여기서 n은 문제에 주어진 숫자입니다. 제한이 100이어도 입력값이 커지는 데 따른 작업량을 비교해 설명합니다.

**지금 가장 추천하는 풀이: (1) 2씩 증가하는 for문 — 필요한 숫자만 계산하고 원리를 이해하기 쉽습니다. 반복 횟수 증가가 없는 시간 O(1) 풀이를 원한다면 (3) 합 공식을 이해한 뒤 사용하면 됩니다.**
