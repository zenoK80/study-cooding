# 17. 두 수의 연산값 비교하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181938?language=javascript)

- 분류: 코딩 기초 트레이닝 · 연산 · Lv. 0
- 상태: [x] 풀이 완료

## 문제 설명

연산 ⊕는 두 정수를 붙여서 쓴 값을 반환합니다.

- 12 ⊕ 3 = 123
- 3 ⊕ 12 = 312

양의 정수 `a`와 `b`가 주어졌을 때, `a ⊕ b`와 `2 * a * b` 중 더 큰 값을 return하는 solution 함수를 완성해 주세요.

단, 두 값이 같으면 `a ⊕ b`를 return 합니다.

## 제한사항

- 1 ≤ `a`, `b` < 10,000

## 입출력 예

| a | b | result |
| ---: | ---: | ---: |
| 2 | 91 | 364 |
| 91 | 2 | 912 |

## 입출력 예 설명

- 예제 #1: 붙인 값은 291, 곱한 값은 `2 * 2 * 91 = 364`라서 364를 반환합니다.
- 예제 #2: 붙인 값은 912, 곱한 값은 `2 * 91 * 2 = 364`라서 912를 반환합니다.

※ 2023년 04월 27일 입출력 예 설명이 수정되었습니다.

## 문제 코드

```javascript
function solution(a, b) {
  var answer = 0;
  return answer;
}
```

## 나의 풀이

```javascript
const solution = (a, b) => Math.max(Number(String(a) + String(b)), 2 * a * b);
```

정답입니다. **숫자 → 문자열로 붙이기 → 숫자로 변환 → 큰 값 선택** 순서입니다.

### a = 2, b = 91이면

- `String(a)` → '2', `String(b)` → '91'
- `'2' + '91'` → '291': 숫자 덧셈이 아니라 문자열 연결
- `Number('291')` → 291: 반환할 숫자로 변환
- `2 * a * b` → 364
- `Math.max(291, 364)` → 364

## 다른 방법

### (1) 가져온 풀이 — parseInt + 삼항 연산자

```javascript
function solution(a, b) {
  let num1 = parseInt(a + "" + b + "");
  let num2 = 2 * a * b;
  return num1 > num2 ? num1 : num2;
}
```

이 풀이도 맞습니다. 네 코드와 목적은 같고, 문자열을 만드는 방법과 큰 값을 선택하는 방법만 다릅니다.

- `a + "" + b + ""`는 왼쪽부터 계산합니다. a = 2, b = 91이라면 `2 + ""` → '2' → `'2' + 91` → '291' → `'291' + ""` → '291'.
- 첫 빈 문자열은 문자열 연결을 시작하게 합니다. **마지막 빈 문자열은 이미 문자열인 결과에 붙이는 것이므로 불필요합니다.**
- `parseInt('291')`은 문자열을 정수 291로 읽습니다. 이 입력에서는 `Number('291')`과 같습니다.
- 두 변수는 재대입하지 않으므로 let 대신 const를 써도 됩니다.
- `num1 > num2`가 참이면 num1, 거짓이면 num2를 반환합니다. 같을 때 num2를 골라도 **숫자 값이 같기 때문에 정답에는 영향이 없습니다.**
- 좋아요 수만으로 더 빠르거나 더 좋은 풀이가 되는 것은 아닙니다. 네 코드는 형변환과 최댓값 선택이 명시적이라는 장점이 있습니다.

### (2) 변수로 분리 — 중간 과정 확인하기

```javascript
function solution(a, b) {
  const combined = Number(String(a) + String(b));
  const product = 2 * a * b;
  return combined >= product ? combined : product;
}
```

이름으로 계산 목적을 구분했습니다. >=를 쓰면 같을 때 combined를 선택한다는 조건도 코드에 그대로 나타납니다.

### (3) 템플릿 리터럴 — 두 값을 문자열에 넣기

```javascript
const solution = (a, b) => Math.max(Number(`${a}${b}`), 2 * a * b);
```

백틱 안에 a와 b를 순서대로 넣어 붙인 문자열을 만듭니다. 두 값 사이에 공백을 넣지 않습니다.

## 배울 것들

### 함수·메서드·연산자 구분

- `String(값)`: 문자열로 변환하는 내장 함수입니다. `String(2)` → '2'.
- `Number(값)`: 숫자로 변환하는 내장 함수입니다. `Number('291')` → 291.
- `parseInt(문자열, 진법)`: 문자열 앞부분부터 정수를 읽는 내장 함수입니다. `parseInt('291', 10)` → 291. 두 번째 인자 10은 10진수라는 뜻입니다.
- `Math.max(값1, 값2, ...)`: Math 객체의 메서드입니다. 인자로 받은 숫자 중 가장 큰 값을 반환합니다.
- `+`, `*`, `>`, `>=`는 연산자입니다. 문제의 ⊕는 설명을 위한 기호이지 JavaScript의 실제 연산자가 아닙니다.

### Number와 parseInt는 항상 같지 않음

| 입력 | Number(입력) | parseInt(입력, 10) |
| --- | --- | --- |
| '291' | 291 | 291 |
| '12.9' | 12.9 | 12 |
| '12px' | NaN | 12 |
| '' | 0 | NaN |

- Number는 문자열 전체를 숫자로 변환합니다. parseInt는 앞에서부터 정수로 읽을 수 있는 부분을 읽고 멈춥니다.
- 이 문제에서는 양의 정수를 붙여 숫자 글자만 만들기 때문에 둘 다 같은 결과가 나옵니다.
- **parseInt는 일반적인 숫자의 소수 부분 버리기용이 아닙니다.** 숫자를 문자열로 바꿔 읽으므로, 지수 표기처럼 예외가 생길 수 있습니다. 정수 부분만 필요하면 Math.trunc를 씁니다.

### 문자열로 붙이기와 숫자로 더하기

```javascript
2 + 91;                  // 93
String(2) + String(91);   // '291'
2 + '' + 91;             // '291'
2 + 91 + '';             // '93' — 더한 후 문자열로 바뀜
Number('291');           // 291
```

- +의 위치가 중요합니다. **숫자끼리 먼저 만나면 더하고**, 문자열을 만나면 연결합니다.
- Math.max는 문자열 인자도 숫자로 변환하지만, 네 코드처럼 Number로 직접 바꾸면 의도가 더 명확합니다.
- 문자열끼리 `>`로 비교하면 숫자 크기가 아니라 문자열 순서로 비교합니다. 숫자 크기를 비교하려면 숫자로 변환해 두는 편이 안전합니다.
- a와 b는 각각 최대 9999입니다. 붙인 값은 최대 99,999,999, 곱한 값은 최대 199,960,002라 Number의 안전한 정수 범위 안입니다. BigInt는 필요 없습니다.

### 두 값이 같으면?

- **a = 3, b = 6**이면 붙인 값 36, `2 * 3 * 6 = 36`으로 같습니다.
- `Math.max(36, 36)`도 36, 가져온 풀이의 num2도 36입니다. 반환하는 것은 계산식의 이름이 아니라 **숫자 값**이라 둘 다 맞습니다.

## 시간·공간 복잡도 쉽게 보기

- 배열을 돌거나 1부터 a까지 반복하는 풀이가 아닙니다. 두 숫자를 문자열로 만들고, 붙이고, 숫자로 읽고, 비교합니다.
- 자릿수가 커지는 상황을 따로 생각하면, 두 숫자의 총 자릿수 d만큼 문자열을 처리·저장하는 비용이 생깁니다.
- 하지만 이 문제는 a, b가 각각 최대 4자리라 합쳐도 최대 8글자입니다. **이 제한에서는 시간 O(1), 추가 공간 O(1)**로 설명합니다.
- O(1)은 연산을 딱 한 번 한다는 뜻이 아니라 입력 범위 안에서 처리량·저장량에 고정된 상한이 있다는 뜻입니다.
- 네 풀이와 다른 풀이들은 여기서 복잡도로 우열을 가릴 필요가 없습니다. 읽기 쉬운 쪽을 고르면 됩니다.
