# 8. 원소들의 곱과 합

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181929?language=javascript)

- 분류: 코딩 기초 트레이닝 · 조건문 · Lv. 0
- 상태: [x] 풀이 완료

## 문제 설명

정수가 담긴 리스트 `num_list`가 주어질 때, 모든 원소들의 곱이 모든 원소들의 합의 제곱보다 작으면 1을 크면 0을 return하도록 solution 함수를 완성해주세요.

## 제한사항

- 2 ≤ `num_list`의 길이 ≤ 10
- 1 ≤ `num_list`의 원소 ≤ 9

## 입출력 예

| num_list | result |
| --- | ---: |
| `[3, 4, 5, 2, 1]` | 1 |
| `[5, 7, 8, 3]` | 0 |

## 입출력 예 설명

- 예제 #1: 곱은 `3 × 4 × 5 × 2 × 1 = 120`, 합의 제곱은 `(3 + 4 + 5 + 2 + 1)² = 225`입니다. 120 < 225이므로 1을 반환합니다.
- 예제 #2: 곱은 `5 × 7 × 8 × 3 = 840`, 합의 제곱은 `(5 + 7 + 8 + 3)² = 529`입니다. 840 > 529이므로 0을 반환합니다.

## 문제 코드

```javascript
function solution(num_list) {
  var answer = 0;
  return answer;
}
```

## 나의 풀이

```javascript
function solution(num_list) {
  let multipleResult = 1;
  let sumResult = 0;

  for (const a of num_list) {
    multipleResult *= a;
    sumResult += a;
  }

  const addPowResult = sumResult ** 2;

  return multipleResult < addPowResult ? 1 : 0;
}
```

정답입니다. 배열을 한 번 돌면서 곱과 합을 동시에 구하고, 반복이 끝난 뒤 합을 제곱합니다.

### 내 코드가 실행되는 순서

`[3, 4, 5, 2, 1]`을 넣으면 다음처럼 바뀝니다.

| 꺼낸 값 a | multipleResult: 곱 | sumResult: 합 |
| --- | ---: | ---: |
| 시작 전 | 1 | 0 |
| 3 | 1 × 3 = 3 | 0 + 3 = 3 |
| 4 | 3 × 4 = 12 | 3 + 4 = 7 |
| 5 | 12 × 5 = 60 | 7 + 5 = 12 |
| 2 | 60 × 2 = 120 | 12 + 2 = 14 |
| 1 | 120 × 1 = 120 | 14 + 1 = 15 |

마지막에 `15 ** 2 = 225`를 계산하고, `120 < 225`가 참이라 1을 반환합니다.

## 다른 방법

### (1) 기본 for문 — 인덱스로 꺼내기

```javascript
function solution(num_list) {
  let product = 1;
  let sum = 0;
  for (let i = 0; i < num_list.length; i++) {
    product *= num_list[i];
    sum += num_list[i];
  }
  return product < sum ** 2 ? 1 : 0;
}
```

네 풀이와 계산은 같습니다. for...of는 값 자체를 받고, 여기서는 `num_list[i]`로 값을 꺼냅니다.

### (2) reduce — 누적 메서드 연습

```javascript
function solution(num_list) {
  const product = num_list.reduce((acc, value) => acc * value, 1);
  const sum = num_list.reduce((acc, value) => acc + value, 0);
  return product < sum ** 2 ? 1 : 0;
}
```

곱을 구할 때 한 번, 합을 구할 때 한 번 배열을 순회합니다. 짧지만 네 풀이보다 배열을 한 번 더 돕니다.

## 배울 것들

- `for (const a of num_list)`: 배열의 값을 하나씩 a에 담습니다. a는 직접 붙인 변수명이며, 각 반복에서 새로운 반복 변수가 만들어집니다.
- `multipleResult *= a`: `multipleResult = multipleResult * a`의 줄임말입니다.
- `sumResult += a`: `sumResult = sumResult + a`의 줄임말입니다.
- **곱은 1부터**: 0부터 시작하면 무엇을 곱해도 0입니다. 1은 첫 숫자를 그대로 받아 이어서 곱할 수 있습니다.
- **합은 0부터**: 첫 숫자에 불필요한 값을 더하지 않고 시작합니다.
- `sumResult ** 2`: 합을 제곱합니다. `sumResult * sumResult`와 같습니다.
- **합의 제곱 ≠ 제곱의 합**: 2와 3이면 `(2 + 3) ** 2 = 25`지만 `2 ** 2 + 3 ** 2 = 13`입니다. 이 문제는 먼저 다 더한 뒤 제곱합니다.
- `조건 ? 1 : 0`: 조건이 참이면 1, 거짓이면 0을 반환하는 삼항 연산자입니다.
- `배열.reduce((누적값, 현재원소) => 다음누적값, 시작값)`: 앞서 계산한 결과를 다음 계산에 넘깁니다. 곱의 시작값은 1, 합의 시작값은 0입니다.
- `multipleResult`, `sumResult`, `addPowResult`는 내장 기능이 아니라 네가 붙인 변수명입니다. 곱은 product, 합은 sum, 합의 제곱은 sumSquared처럼 이름 붙여도 됩니다.
- 최대로 곱해도 `9 ** 10 = 3486784401`입니다. JavaScript Number로 정확히 표현 가능한 정수 범위라 BigInt는 필요 없습니다.

## 시간·공간 복잡도 쉽게 보기

- 여기서 n은 배열에 들어 있는 숫자의 개수입니다.
- **네 풀이와 (1): 시간 O(n)**. 숫자 5개면 반복 5번, 10개면 10번입니다. 반복 한 번 안에서 곱셈과 덧셈을 함께 해도 n²이 되지는 않습니다.
- **(2): 시간 O(n)**. 5개면 곱 계산 5번 + 합 계산 5번입니다. 총 2n번이지만 빅오에서는 고정 배수 2를 생략합니다. 실제 작업량이 완전히 같다는 뜻은 아닙니다.
- **모두 추가 공간 O(1)**. 새 배열을 만들지 않고 곱·합 같은 숫자 몇 개만 저장합니다. 원소가 늘어도 변수 개수와 저장 공간이 함께 늘지 않습니다.
- O(1)은 메모리를 안 쓴다는 뜻이 아니라 **입력 개수에 따라 저장량이 늘지 않는다**는 뜻입니다. 여기서는 문제 범위의 Number 연산을 기준으로 봅니다.

**가장 추천하는 풀이: 네 for...of 풀이 — 배열을 한 번만 돌며 곱과 합을 함께 구하고, 계산 과정도 쉽게 읽힙니다. reduce로 억지로 줄일 필요 없습니다.**
