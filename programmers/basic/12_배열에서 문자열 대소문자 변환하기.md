# 12. 배열에서 문자열 대소문자 변환하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181875?language=javascript)

- 분류: 코딩 기초 트레이닝 · 문자열 · Lv. 0
- 상태: [x] 풀이 완료

## 문제 설명

문자열 배열 `strArr`가 주어집니다. 모든 원소가 알파벳으로만 이루어져 있을 때, 배열에서 홀수번째 인덱스의 문자열은 모든 문자를 대문자로, 짝수번째 인덱스의 문자열은 모든 문자를 소문자로 바꿔서 반환하는 solution 함수를 완성해 주세요.

## 제한사항

- 1 ≤ `strArr`의 길이 ≤ 20
- 1 ≤ `strArr`의 원소의 길이 ≤ 20
- `strArr`의 원소는 알파벳으로 이루어진 문자열입니다.

※ 제공된 지문의 `1 ≤ strArr ≤ 20`은 배열의 길이를 뜻하도록 정리했습니다.
※ 2023년 05월 15일 제한사항이 수정되었습니다.

## 입출력 예

| strArr | result |
| --- | --- |
| `["AAA", "BBB", "CCC", "DDD"]` | `["aaa", "BBB", "ccc", "DDD"]` |
| `["aBc", "AbC"]` | `["abc", "ABC"]` |

## 입출력 예 설명

- 예제 #1: 인덱스 0, 2는 짝수라 AAA와 CCC를 소문자로 바꿉니다. 인덱스 1, 3은 홀수라 대문자로 바꾸며, BBB와 DDD는 이미 대문자라 내용이 같습니다.
- 예제 #2: 인덱스 0의 aBc는 abc로, 인덱스 1의 AbC는 ABC로 바꿉니다.

## 문제 코드

```javascript
function solution(strArr) {
  var answer = [];
  return answer;
}
```

## 나의 풀이

```javascript
const solution = (strArr) => {
  return strArr.slice().map((str, index) => {
    return index % 2 === 0 ? str.toLowerCase() : str.toUpperCase();
  });
};
```

정답입니다. 원본을 복사한 뒤, 각 문자열을 인덱스에 맞게 바꾸고 새 배열로 반환합니다. 다만 **이 코드에서는 slice()를 빼도 원본 배열이 유지됩니다.** map이 새 배열을 만들고 대소문자 메서드도 원본 문자열을 바꾸지 않기 때문입니다.

### 내 코드의 실행 순서

- `slice()`: strArr를 얕게 복사한 배열을 만듭니다.
- `map((str, index) => ...)`: str에는 현재 문자열, index에는 0부터 시작하는 위치가 들어옵니다.
- `index % 2 === 0`: 짝수 인덱스인지 확인합니다. 참이면 소문자, 거짓이면 대문자로 바꿉니다.
- 콜백 안의 return은 **현재 원소에 넣을 문자열**, 바깥 return은 **map이 만든 전체 배열**을 반환합니다.

## 다른 방법

### (1) map만 사용 — 추천

```javascript
function solution(strArr) {
  return strArr.map((str, index) => index % 2 === 0 ? str.toLowerCase() : str.toUpperCase());
}
```

네 코드에서 불필요한 slice를 없앤 풀이입니다. 콜백을 표현식으로 쓰면 중괄호와 return을 생략할 수 있습니다.

### (2) for + push — 처리 순서를 직접 작성

```javascript
function solution(strArr) {
  const result = [];
  for (let i = 0; i < strArr.length; i++) {
    result.push(i % 2 === 0 ? strArr[i].toLowerCase() : strArr[i].toUpperCase());
  }
  return result;
}
```

새 배열에 바뀐 문자열을 하나씩 넣습니다. 원본 배열은 바뀌지 않습니다.

### (3) for + 인덱스 대입 — 원본 배열 수정

```javascript
function solution(strArr) {
  for (let i = 0; i < strArr.length; i++) {
    strArr[i] = i % 2 === 0 ? strArr[i].toLowerCase() : strArr[i].toUpperCase();
  }
  return strArr;
}
```

새 배열을 만들지 않고 기존 배열의 각 칸을 새 문자열로 교체합니다. 함수를 호출한 쪽에서 보던 배열도 바뀌므로 원본 보존이 필요하면 쓰지 않습니다.

## 배울 것들

- **인덱스는 0부터**: 첫 번째 원소의 인덱스는 0이므로 소문자로 바꿉니다. 사람 기준 ‘첫 번째’와 ‘홀수 인덱스’를 혼동하지 않습니다.
- `배열.map((값, 인덱스) => 변환한값)`: 각 원소를 변환한 새 배열을 만듭니다. 반환된 문자열이 결과 배열의 같은 위치에 들어갑니다.
- `배열.slice()`: 인자 없이 호출하면 전체 배열을 얕게 복사합니다. 이 풀이에서는 map이 다시 배열을 만들기 때문에 복사가 중복됩니다.
- map이 원본 수정을 무조건 막아주는 것은 아닙니다. 콜백에서 원본 배열이나 객체 속성을 직접 수정하면 바뀔 수 있지만, **지금 콜백은 문자열 변환 결과만 반환**하므로 안전합니다.
- `str.toLowerCase()`: 문자열을 소문자로 바꾼 새 문자열을 반환합니다. `'aBc'.toLowerCase()` → `'abc'`.
- `str.toUpperCase()`: 문자열을 대문자로 바꾼 새 문자열을 반환합니다. `'AbC'.toUpperCase()` → `'ABC'`.
- `index % 2 === 0`: 2로 나눈 나머지가 0이면 짝수입니다. 0도 짝수 인덱스입니다.
- `조건 ? A : B`: 조건이 참이면 A, 거짓이면 B를 선택합니다. 여기서는 두 변환을 모두 실행하는 것이 아니라 선택한 쪽만 실행합니다.
- `str`, `index`는 직접 붙인 매개변수 이름입니다. 다른 답의 v, i와 역할이 같습니다.
- 문자열 자체는 수정할 수 없습니다. (3)의 `strArr[i] = ...`는 문자열 내부를 고치는 것이 아니라 **배열의 해당 칸을 다른 문자열로 교체**합니다.

## 시간·공간 복잡도 쉽게 보기

- n은 배열 원소 개수, L은 모든 문자열의 글자 수를 합친 값입니다. `['ABC', 'De']`라면 n = 2, L = 5입니다.
- **시간 O(L)**: 배열의 각 문자열을 방문하고 그 안의 글자도 변환합니다. 3글자 문자열 4개면 총 12글자, 8개면 총 24글자를 처리하는 식입니다.
- 네 풀이에는 slice로 n칸을 복사하는 작업도 추가됩니다. 각 문자열이 최소 한 글자이므로 n ≤ L이고, 복사를 포함해도 전체 증가 정도는 O(L)입니다. 그렇다고 복사 비용이 없는 것은 아닙니다.
- **네 풀이·(1)·(2)의 결과 포함 추가 공간 O(n + L)**: 결과 배열 n칸과 변환한 문자열들을 저장합니다. n ≤ L이므로 O(L)로 줄여 표현할 수 있습니다.
- 네 풀이는 여기에 slice의 중간 배열 n칸도 더 만듭니다. (1)은 그 중간 복사 배열이 필요 없습니다.
- (3)은 새 배열은 만들지 않지만 새 문자열은 필요합니다. 그래서 **원본 수정이라고 전체 공간을 무조건 O(1)이라고 하면 안 됩니다.** 변환된 문자열 저장량까지 세면 최악 O(L)입니다.
- 이 문제는 문자열 하나가 최대 20글자라, 그 길이를 고정된 상한으로 보면 시간·결과 포함 공간을 O(n)이라고도 적습니다. 핵심은 **원소 개수뿐 아니라 각 문자열의 글자도 처리한다**는 점입니다.

**가장 추천하는 풀이: (1) map만 사용 — 네 풀이와 결과가 같고 원본도 보존하면서, 불필요한 slice 복사를 한 번 줄일 수 있습니다.**
