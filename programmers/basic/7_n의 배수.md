# 7. n의 배수

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181937?language=javascript)

- 분류: 코딩 기초 트레이닝 · 연산 · Lv. 0
- 상태: [x] 풀이 완료

## 문제 설명

정수 `num`과 `n`이 매개변수로 주어집니다. `num`이 `n`의 배수이면 1을, 배수가 아니라면 0을 return하도록 solution 함수를 완성해주세요.

## 제한사항

- 2 ≤ `num` ≤ 100
- 2 ≤ `n` ≤ 9

## 입출력 예

| num | n | result |
| ---: | ---: | ---: |
| 98 | 2 | 1 |
| 34 | 3 | 0 |

## 입출력 예 설명

- 98은 `2 × 49`이므로 2의 배수입니다. 따라서 1을 반환합니다.
- 34는 `3 × 11 + 1`로 나머지가 1이므로 3의 배수가 아닙니다. 따라서 0을 반환합니다.
- 원문의 두 번째 예시 설명에는 32라고 적혀 있지만, 여기서는 입출력 표의 34를 기준으로 설명합니다.

## 문제 코드

```javascript
function solution(num, n) {
  var answer = 0;
  return answer;
}
```

## 나의 풀이

```javascript
function solution(num, n) {
  if (num % n === 0) {return 1;}
  else {return 0;}
}
```

정답입니다. 나눈 나머지가 0이면 딱 나누어떨어지므로 배수입니다. 네 풀이의 로직은 그대로 두고 띄어쓰기만 정돈했습니다.

## 다른 방법

### (1) 삼항 연산자 — 간결하게 표현

```javascript
function solution(num, n) {
  return num % n === 0 ? 1 : 0;
}
```

`조건 ? 참일 때 값 : 거짓일 때 값`입니다. 네 if/else와 같은 판단을 합니다.

### (2) 화살표 함수 — return 생략

```javascript
const solution = (num, n) => num % n === 0 ? 1 : 0;
```

(1)과 같은 계산입니다. 화살표 뒤에 중괄호 없이 표현식을 쓰면 그 결과를 반환합니다. 한 줄이라서 더 빠른 것은 아닙니다.

### (3) Number() — 참·거짓을 숫자로 변환

```javascript
function solution(num, n) {
  return Number(num % n === 0);
}
```

`num % n === 0`의 결과는 true 또는 false입니다. `Number(true)`는 1, `Number(false)`는 0입니다. 형변환 연습용이고, 처음 읽을 때는 (1)이 더 분명합니다.

## 배울 것들

- **배수**: 어떤 수에 정수를 곱해 만들 수 있는 수입니다. 2의 배수는 2, 4, 6, 8…입니다.
- `%`: 나눈 **나머지**를 구하는 연산자입니다. 퍼센트를 계산하는 기호가 아닙니다. `98 % 2` → 0, `34 % 3` → 1.
- `/`: 나눗셈입니다. `5 / 2` → 2.5, `5 % 2` → 1로 서로 다릅니다.
- `===`: 값과 자료형이 같은지 비교합니다. 여기서는 숫자로 계산한 나머지가 숫자 0인지 검사합니다.
- `if / else`: 조건이 참이면 if 안, 거짓이면 else 안을 실행합니다.
- `return`: 값을 반환하고 함수를 끝냅니다. `return 1;` 다음에 else 쪽까지 실행되지는 않습니다.
- `Number(값)`: 값을 숫자로 변환하는 내장 함수입니다. `숫자.Number()`처럼 쓰는 메서드가 아닙니다.
- 이 문제에서 n은 2~9이므로 0으로 나누는 경우는 없습니다. 문제에서 보장한 입력을 다시 검사할 필요는 없습니다.

## 시간·공간 복잡도 쉽게 보기

- **시간 복잡도**는 입력이 커지면 해야 할 일이 얼마나 늘어나는지, **공간 복잡도**는 새로 저장할 내용이 얼마나 늘어나는지 보는 것입니다.
- 네 풀이는 `num % n`으로 나머지 계산 → 0인지 비교 → 1 또는 0 반환입니다. 반복문으로 1부터 num까지 세는 것이 아닙니다.
- `num = 10`이어도 `num = 100`이어도 같은 단계만 처리합니다. 그래서 시간은 **O(1)**입니다. ‘딱 한 번 실행’이 아니라 ‘작업량이 일정’하다는 뜻입니다.
- 입력 개수에 따라 커지는 새 배열이나 객체를 만들지 않습니다. 계산 결과도 숫자 하나라 추가 공간은 **O(1)**입니다.
- 여기의 모든 풀이가 시간 O(1), 추가 공간 O(1)입니다. 이 문제 범위의 JavaScript Number 연산을 기준으로 합니다.
- 이 문제의 매개변수 `n`과 복잡도 표기의 `O(n)`을 혼동하지 마세요. 변수 이름이 n이라고 자동으로 O(n)이 되는 것은 아닙니다.

**가장 추천하는 풀이: (1) 삼항 연산자 — ‘배수이면 1, 아니면 0’이라는 조건이 한눈에 보입니다. 네 if/else 풀이도 시간·공간 복잡도는 같고, 조건문을 익히기에는 충분히 좋은 답입니다.**
