# 13. 원하는 문자열 찾기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181878?language=javascript)

- 분류: 코딩 기초 트레이닝 · 문자열 · Lv. 0
- 상태: [x] 풀이 정리 완료 — 내 코드의 메서드 이름 오타 수정

## 문제 설명

알파벳으로 이루어진 문자열 `myString`과 `pat`이 주어집니다. `myString`의 연속된 부분 문자열 중 `pat`이 존재하면 1을 그렇지 않으면 0을 return 하는 solution 함수를 완성해 주세요.

단, 알파벳 대문자와 소문자는 구분하지 않습니다.

## 제한사항

- 1 ≤ `myString`의 길이 ≤ 100,000
- 1 ≤ `pat`의 길이 ≤ 300
- `myString`과 `pat`은 모두 알파벳으로 이루어진 문자열입니다.

※ 2023년 05월 15일 제한사항이 수정되었습니다.

## 입출력 예

| myString | pat | return |
| --- | --- | ---: |
| `"AbCdEfG"` | `"aBc"` | 1 |
| `"aaAA"` | `"aaaaa"` | 0 |

## 입출력 예 설명

- 예제 #1: myString의 인덱스 0~2에 있는 AbC는 대소문자를 무시하면 aBc와 같습니다. 따라서 1을 반환합니다.
- 예제 #2: myString은 4글자, pat은 5글자라 포함될 수 없습니다. 따라서 0을 반환합니다.

## 문제 코드

```javascript
function solution(myString, pat) {
  var answer = 0;
  return answer;
}
```

## 나의 풀이 — 오타 수정

```javascript
const solution = (myString, pat) => {
  return myString.toLowerCase().includes(pat.toLowerCase()) ? 1 : 0;
};
```

풀이 방향은 맞습니다. 원래 쓴 `toLoswerCase()`는 없는 메서드라 TypeError가 발생합니다. 두 곳 모두 `toLowerCase()`로 고쳤습니다.

- `myString.toLowerCase()`: 'AbCdEfG' → 'abcdefg'
- `pat.toLowerCase()`: 'aBc' → 'abc'
- `'abcdefg'.includes('abc')` → true → 삼항 연산자로 1 반환
- includes는 기본적으로 대소문자를 구분하므로 **양쪽을 같은 대소문자로 맞춘 뒤** 비교합니다.

## 다른 방법

### (1) 변수로 나누기 — 동작을 읽기 쉽게

```javascript
function solution(myString, pat) {
  const text = myString.toLowerCase();
  const target = pat.toLowerCase();
  return text.includes(target) ? 1 : 0;
}
```

네 풀이와 같은 동작입니다. 중간 값을 확인하고 싶으면 text와 target을 출력해 볼 수 있습니다.

### (2) toUpperCase — 둘 다 대문자로 통일

```javascript
function solution(myString, pat) {
  return myString.toUpperCase().includes(pat.toUpperCase()) ? 1 : 0;
}
```

이 문제는 알파벳만 있으므로 소문자 대신 양쪽을 대문자로 맞춰도 됩니다.

### (3) indexOf — 찾은 위치로 판단

```javascript
function solution(myString, pat) {
  return myString.toLowerCase().indexOf(pat.toLowerCase()) !== -1 ? 1 : 0;
}
```

indexOf는 찾은 첫 위치를 반환하고, 없으면 -1을 반환합니다. **0번 위치에서도 찾을 수 있으므로** 결과를 그대로 참·거짓 조건에 넣으면 안 됩니다.

## 배울 것들

### includes() 사용법

- 사용법: `문자열.includes(찾을문자열, 시작위치)` 또는 `배열.includes(찾을값, 시작위치)`.
- 반환값: 있으면 true, 없으면 false입니다. 1이나 0을 직접 반환하는 메서드는 아닙니다.
- 시작위치는 생략 가능하며 기본값은 0입니다. `'abcabc'.includes('abc', 3)` → true.
- 문자열에서는 **연속된 부분 문자열**, 배열에서는 **원소 하나와 일치하는 값**을 찾습니다.
- 대소문자를 구분합니다. `'ABC'.includes('a')` → false.
- 원본 문자열이나 배열을 바꾸지 않습니다. 정규식 검색용 메서드는 아닙니다.

```javascript
'hello'.includes('ell');        // true: 연속된 부분 문자열
'hello'.includes('hlo');        // false: 글자가 띄엄띄엄 있음
['hello'].includes('ell');      // false: 'ell'이라는 원소는 없음
['hello'].includes('hello');    // true: 같은 원소가 있음
[1, 2, 3].includes('2');        // false: 숫자 2와 문자열 '2'는 다름
```

### 함수야, 메서드야?

- **함수**는 호출해서 작업을 시키는 코드입니다. 네가 만든 `solution()`도 함수입니다.
- **메서드**는 객체의 속성으로 제공되는 함수입니다. `str.includes()`, `arr.map()`처럼 값에 붙여 쓰는 함수는 메서드라고 부릅니다.
- 즉 **메서드도 함수의 한 종류**입니다. includes는 JavaScript가 제공하는 내장 메서드입니다.
- `Math.floor()`, `Array.from()`도 메서드입니다. 각각 Math, Array에 붙어 있습니다.
- `arr.length`는 **속성**이지 메서드가 아닙니다. 값만 읽으므로 `length()`처럼 괄호를 붙이지 않습니다.

### 왜 어떤 건 문자열만, 어떤 건 배열만 될까?

- 기준은 **점 앞의 값이 어떤 자료형이고, 그 자료형에 어떤 메서드가 제공되는가**입니다.
- 배열과 문자열은 서로 다른 종류의 값입니다. JavaScript는 배열용 메서드와 문자열용 메서드를 따로 제공합니다.
- 같은 이름이 있어도 하나의 공통 함수를 공유한다는 뜻은 아닙니다. 배열의 includes와 문자열의 includes는 **별개의 메서드**이고 검색 대상도 다릅니다.
- 문자열은 원시값이지만 JavaScript가 문자열 메서드를 사용할 수 있도록 처리해 줍니다. 배열로 자동 변환되는 것은 아닙니다.
- iterable은 ‘하나씩 꺼낼 수 있다’는 뜻일 뿐입니다. 문자열에 for...of를 쓸 수 있다고 map이나 filter까지 생기는 것은 아닙니다.

### 배열·문자열 둘 다 제공하는 메서드

| 메서드 | 문자열 예시 | 배열 예시 |
| --- | --- | --- |
| includes(값) — 포함 여부 | `'abc'.includes('bc')` → true | `['a', 'b'].includes('b')` → true |
| indexOf(값) — 첫 위치, 없으면 -1 | `'abc'.indexOf('bc')` → 1 | `['a', 'b'].indexOf('b')` → 1 |
| lastIndexOf(값) — 마지막 위치 | `'aba'.lastIndexOf('a')` → 2 | `['a', 'b', 'a'].lastIndexOf('a')` → 2 |
| slice(시작, 끝) — 끝 직전까지 복사 | `'abcd'.slice(1, 3)` → 'bc' | `[1, 2, 3, 4].slice(1, 3)` → [2, 3] |
| concat(값) — 이어 붙이기 | `'ab'.concat('cd')` → 'abcd' | `[1, 2].concat([3, 4])` → [1, 2, 3, 4] |
| at(인덱스) — 해당 위치의 값 | `'abc'.at(-1)` → 'c' | `[1, 2, 3].at(-1)` → 3 |

위 예시들은 원본을 수정하지 않습니다. 문자열 slice는 문자열, 배열 slice는 배열을 반환합니다. 이름뿐 아니라 **무엇을 반환하는지**도 함께 봅니다.

### 배열용과 문자열용 구분

아래는 배열과 문자열 두 종류를 비교한 표입니다. forEach처럼 다른 자료구조에도 같은 이름이 있는 경우는 별개입니다.

| 구분 | 주요 메서드 | 용도 |
| --- | --- | --- |
| 배열용 | map, filter, reduce | 원소 변환·선별·누적 |
| 배열용 | forEach, some, every, find, findIndex | 원소 작업·조건 검사·검색 |
| 배열용 | push, pop, shift, unshift, splice | 원본 배열에 원소 추가·삭제 |
| 배열용 | sort, reverse | 원본 배열 정렬·뒤집기 |
| 배열용 | join | 배열 → 문자열 |
| 문자열용 | toLowerCase, toUpperCase | 대소문자 변환 |
| 문자열용 | replace, replaceAll | 일부 또는 전체 치환 |
| 문자열용 | split | 문자열 → 배열 |
| 문자열용 | trim, trimStart, trimEnd | 양 끝 또는 한쪽 끝 공백 제거 |
| 문자열용 | startsWith, endsWith | 특정 문자열로 시작·끝나는지 검사 |
| 문자열용 | repeat, padStart, padEnd | 반복·앞뒤 길이 채우기 |

### 메서드를 이어 쓸 때는 반환값을 보기

```javascript
'ABC'.toLowerCase().includes('b'); // 소문자 문자열 → 포함 여부 true
'abc'.split('').map(c => c.toUpperCase()).join(''); // 문자열 → 배열 → 배열 → 문자열
// 'abc'.map(c => c); // 오류: 문자열에는 map이 없음
```

**점 왼쪽의 결과가 문자열이면 문자열 메서드, 배열이면 배열 메서드를 고르면 됩니다.** 배열 원소가 문자열이라고 배열 자체에 toLowerCase를 쓸 수는 없고, map 안에서 각 문자열에 호출해야 합니다.

## 시간·공간 복잡도 쉽게 보기

- N은 myString의 글자 수, M은 pat의 글자 수입니다. 예제 #1은 N = 7, M = 3입니다.
- **소문자 변환**: 두 문자열의 글자를 처리하므로 시간 O(N + M)입니다.
- **검색**: includes 한 번 호출이 ‘글자 한 번 비교’라는 뜻은 아닙니다. 안에서 패턴을 찾아야 합니다.
- 가장 단순하게 검색한다면, 시작 위치를 바꿔 가며 매번 최대 M글자를 비교합니다. 최대 약 N × M번 비교하므로 최악 시간 O(NM)인 방식입니다.
- 다만 JavaScript includes·indexOf의 검색 알고리즘과 시간 복잡도는 언어 명세에서 고정하지 않습니다. 따라서 이 내장 메서드가 반드시 매번 NM번 비교한다고 단정하지 않습니다.
- **추가 공간 O(N + M)**: 대소문자를 바꾼 문자열 두 개를 저장하는 크기입니다. 반환하는 1 또는 0은 고정 크기지만, 중간 문자열도 공간에 포함합니다.
- 위 풀이들은 모두 ‘대소문자 변환 + 부분 문자열 검색’ 방식입니다. 줄 수를 줄이거나 변수에 나눠 담는 것만으로 복잡도가 달라지지는 않습니다.

**가장 추천하는 풀이: 오타를 고친 네 toLowerCase + includes 풀이 — 양쪽 대소문자를 통일한 뒤 포함 여부를 확인한다는 요구가 그대로 드러납니다. 중간 값이 헷갈리면 (1)처럼 변수로 나눠 쓰세요.**
