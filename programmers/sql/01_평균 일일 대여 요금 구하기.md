# 01. 평균 일일 대여 요금 구하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/151136?language=mysql)

- 분류: SQL 고득점 Kit · SELECT
- 사용 DBMS: MySQL

## 문제 설명

다음은 어느 자동차 대여 회사에서 대여 중인 자동차들의 정보를 담은 `CAR_RENTAL_COMPANY_CAR` 테이블입니다. `CAR_ID`, `CAR_TYPE`, `DAILY_FEE`, `OPTIONS`는 각각 자동차 ID, 자동차 종류, 일일 대여 요금(원), 자동차 옵션 리스트를 나타냅니다.

| Column name | Type | Nullable |
| --- | --- | --- |
| CAR_ID | INTEGER | FALSE |
| CAR_TYPE | VARCHAR(255) | FALSE |
| DAILY_FEE | INTEGER | FALSE |
| OPTIONS | VARCHAR(255) | FALSE |

자동차 종류는 '세단', 'SUV', '승합차', '트럭', '리무진'이 있습니다. 자동차 옵션 리스트는 콤마(',')로 구분된 키워드 리스트(예: '열선시트', '스마트키', '주차감지센서')입니다. 키워드 종류는 '주차감지센서', '스마트키', '네비게이션', '통풍시트', '열선시트', '후방카메라', '가죽시트'가 있습니다.

## 문제

`CAR_RENTAL_COMPANY_CAR` 테이블에서 자동차 종류가 'SUV'인 자동차들의 평균 일일 대여 요금을 출력하는 SQL문을 작성해주세요. 평균 일일 대여 요금은 **소수 첫 번째 자리에서 반올림**하고, 컬럼명은 `AVERAGE_FEE`로 지정해주세요.

## 입력 예

| CAR_ID | CAR_TYPE | DAILY_FEE | OPTIONS |
| ---: | --- | ---: | --- |
| 1 | 세단 | 16000 | 가죽시트,열선시트,후방카메라 |
| 2 | SUV | 14000 | 스마트키,네비게이션,열선시트 |
| 3 | SUV | 22000 | 주차감지센서,후방카메라,가죽시트 |

## 출력 예

| AVERAGE_FEE |
| ---: |
| 18000 |

SUV 두 대의 요금만 계산하면 `(14000 + 22000) / 2 = 18000`입니다. 세단의 16000원은 제외합니다.

```sql
-- 코드를 입력하세요
```

## 나의 풀이

```sql
SELECT ROUND(AVG(DAILY_FEE), 0) AS AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE = 'SUV';
```

계산 방식은 맞습니다. 네 답에서 줄만 정리하고, 문자열을 나타내는 "SUV"를 **'SUV'**로 바꿨습니다. MySQL 기본 설정에서는 큰따옴표도 되지만 ANSI_QUOTES 모드에서는 컬럼 같은 식별자로 해석하므로 작은따옴표가 안전합니다.

### 쿼리를 읽는 순서

- `FROM CAR_RENTAL_COMPANY_CAR`: 이 테이블에서 데이터를 봅니다.
- `WHERE CAR_TYPE = 'SUV'`: SUV인 행만 남깁니다.
- `AVG(DAILY_FEE)`: 남은 행들의 요금 평균을 구합니다.
- `ROUND(..., 0)`: 평균을 소수점 아래 0자리로 반올림합니다.
- `AS AVERAGE_FEE`: 결과 열 이름을 AVERAGE_FEE로 붙입니다.

SQL은 SELECT를 먼저 적지만, 이해할 때는 **어느 테이블 → 어떤 행 → 무엇을 계산** 순서로 읽으면 편합니다. 실제 물리적 실행 순서는 DB가 결정합니다.

## 다른 방법

### (1) ROUND의 두 번째 인자 생략

```sql
SELECT ROUND(AVG(DAILY_FEE)) AS AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE = 'SUV';
```

MySQL에서 ROUND의 자릿수를 생략하면 0입니다. 네 답과 같은 결과지만, 학습할 때는 0을 직접 적으면 요구 조건이 더 잘 보입니다.

## 배울 것들

### ROUND — 반올림할 자릿수 지정

- 정확한 이름은 **ROUND**입니다. ROUNT가 아닙니다. SQL 내장 숫자 함수입니다.
- 사용법: `ROUND(숫자 또는 계산식, 남길 소수 자릿수)`.
- 두 번째 인자는 **어느 자리를 보고 반올림할지**가 아니라 **결과에 소수점 아래 몇 자리를 남길지**입니다.
- 소수 첫째 자리에서 반올림 → 소수 부분을 남기지 않음 → **0**.
- 소수 둘째 자리에서 반올림 → 소수 첫째 자리까지 남김 → **1**.
- 음수 자릿수는 소수점 왼쪽을 처리합니다. -1은 십 단위, -2는 백 단위입니다.

| SQL | 결과 | 뜻 |
| --- | ---: | --- |
| ROUND(123.456, 0) | 123 | 정수 자리까지 |
| ROUND(123.656, 0) | 124 | 소수 첫째 자리의 6을 보고 올림 |
| ROUND(123.456, 1) | 123.5 | 소수 첫째 자리까지 |
| ROUND(123.456, 2) | 123.46 | 소수 둘째 자리까지 |
| ROUND(123.456, -1) | 120 | 십 단위로 반올림 |
| ROUND(163.456, -2) | 200 | 백 단위로 반올림 |

정확한 수치(정수·DECIMAL)는 정확히 중간일 때 0에서 멀어지는 쪽으로 반올림합니다. `ROUND(1.5, 0)` → 2, `ROUND(-1.5, 0)` → -2. FLOAT·DOUBLE 같은 근삿값은 경계에서 결과가 달라질 수 있습니다. 이 문제의 정수 컬럼 AVG는 DECIMAL 결과를 냅니다. [MySQL ROUND 설명](https://dev.mysql.com/doc/refman/8.4/en/mathematical-functions.html#function_round).

### 반올림·올림·내림·버림 비교

| 함수 | 뜻 | 1.7 | -1.7 |
| --- | --- | ---: | ---: |
| ROUND(x, 0) | 가까운 정수로 반올림 | 2 | -2 |
| CEIL(x) | x 이상인 가장 작은 정수 | 2 | -1 |
| FLOOR(x) | x 이하인 가장 큰 정수 | 1 | -2 |
| TRUNCATE(x, 0) | 소수 부분 버림 | 1 | -1 |

- `TRUNCATE(1.789, 2)` → 1.78, `ROUND(1.789, 2)` → 1.79입니다.
- SQL에서는 `Math.round()`가 아니라 `ROUND()`입니다. JavaScript와 함수 이름·인자·음수 반올림 규칙까지 모두 같다고 생각하면 안 됩니다.
- ROUND는 숫자 계산용입니다. 쉼표를 붙여 문자열로 표시하는 MySQL FORMAT과는 다릅니다.

### AVG — 평균을 구하는 집계 함수

- 사용법: `AVG(컬럼 또는 계산식)`. 여러 행의 값을 모아 평균 한 개를 만드는 **집계 함수**입니다.
- 이 문제에서는 SUV 요금의 합 ÷ SUV 요금 개수입니다. 14000과 22000 → 18000.
- 기본적으로 중복된 값도 각각 셉니다. 같은 요금의 차가 두 대면 두 대 모두 평균에 포함합니다.
- NULL은 평균 계산에서 제외합니다. `10, NULL, 20`의 평균은 15입니다. NULL을 0으로 보는 것이 아닙니다.
- 해당 행이 없으면 AVG 결과는 NULL이며, ROUND(NULL, 0)도 NULL입니다.
- 여기서는 DAILY_FEE가 NULL 불가 컬럼입니다. SUV만 골라 전체 평균 하나를 구하므로 GROUP BY는 필요 없습니다. [MySQL AVG 설명](https://dev.mysql.com/doc/refman/8.4/en/aggregate-functions.html#function_avg).

### ROUND(AVG(...), 0) — 안쪽부터 계산

- 먼저 `AVG(DAILY_FEE)`로 평균을 구한 다음, 그 **평균 결과를 한 번 반올림**합니다.
- `AVG(ROUND(DAILY_FEE, 0))`는 각 요금을 먼저 반올림한 후 평균을 구하는 다른 식입니다.
- 요금이 정수여도 평균은 소수가 될 수 있습니다. 100원과 101원의 평균은 100.5 → ROUND(..., 0)은 101입니다.
- 즉 각 행이 정수라고 평균 결과의 ROUND를 생략하면 안 됩니다.

### AS — 결과에 이름 붙이기

- 사용법: `계산식 AS 별칭`. AS는 함수가 아니라 **SQL 키워드**입니다.
- `ROUND(AVG(DAILY_FEE), 0) AS AVERAGE_FEE`는 계산 결과 열의 이름을 AVERAGE_FEE로 지정합니다.
- 원본 테이블의 컬럼명을 바꾸거나 새 컬럼을 저장하는 작업이 아닙니다. 이번 조회 결과에 붙이는 이름입니다.
- 이 위치에서는 AS를 생략해도 되지만, 명시하면 별칭이라는 뜻이 분명합니다.
- SELECT에서 붙인 별칭을 같은 쿼리의 WHERE에 바로 사용할 수는 없습니다. WHERE 단계의 원본 컬럼과 SELECT 결과를 구분합니다.

### 나머지 기본 문법

- `SELECT`: 결과로 보여 줄 컬럼·계산식을 지정합니다.
- `FROM`: 데이터를 가져올 테이블을 지정합니다.
- `WHERE`: 조건에 맞는 행만 선택합니다.
- `=`: SQL의 비교입니다. JavaScript의 ===를 쓰지 않습니다.
- `'SUV'`: 문자열 값입니다. CAR_TYPE과 DAILY_FEE는 컬럼 이름입니다.
- `Nullable = FALSE`: 해당 컬럼에 NULL을 허용하지 않는다는 뜻입니다. 모든 값이 불리언 false라는 뜻이 아닙니다.

## 시간·공간 복잡도 쉽게 보기

- 테이블을 전부 읽는 실행 계획이라면, 자동차 N대의 행을 확인하므로 시간 O(N)으로 생각할 수 있습니다.
- 평균 자체는 합계와 개수를 누적하면 됩니다. 단순 집계에 필요한 보조 저장량은 O(1)로 설명할 수 있습니다.
- 다만 SQL 전체 성능은 인덱스·데이터 분포·실행 계획·DB 내부 버퍼 등에 따라 달라집니다. 쿼리 한 줄만 보고 실제 시간·메모리를 확정하지 않습니다.
- 실제로 어떻게 읽는지는 쿼리 앞에 EXPLAIN을 붙여 확인합니다. 이 문제는 불필요한 정렬·그룹화를 추가할 필요가 없습니다.

**가장 추천하는 풀이: 네 WHERE + AVG + ROUND(..., 0) + AS 풀이 — SUV만 선택하고, 평균을 구해 반올림한 뒤 요구한 열 이름을 붙이는 순서가 명확합니다.**
