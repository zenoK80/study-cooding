# 12. 값과 참조

## 원시값

숫자, 문자열, Boolean은 값을 복사한다.

```js
let a = 10;
let b = a;

b = 20;

// console.log(a); 10
// console.log(b); 20
```

* `b`에 `a`의 값이 복사된다.
* `b`를 바꿔도 `a`는 그대로다.

---

## 배열

배열은 같은 데이터를 참조할 수 있다.

```js
const a = [1, 2, 3];
const b = a;

b[0] = 100;

// console.log(a); [100, 2, 3]
// console.log(b); [100, 2, 3]
```

* `a`, `b`가 같은 배열을 바라본다.

---

## 객체

객체도 배열과 같다.

```js
const user1 = {
  score: 10
};

const user2 = user1;

user2.score = 20;

// console.log(user1.score); 20
// console.log(user2.score); 20
```

---

## 배열 비교

```js
const a = [1, 2];
const b = [1, 2];

// console.log(a === b); false
```

값은 같아 보여도 서로 다른 배열이다.

```js
const a = [1, 2];
const b = a;

// console.log(a === b); true
```

* 같은 배열을 참조하면 `true`다.

---

## 함수에 배열 전달하기

```js
function change(numbers) {
  numbers[0] = 100;
}

const numbers = [1, 2, 3];

change(numbers);

// console.log(numbers); [100, 2, 3]
```

* 함수 안에서 배열을 수정하면 원본도 바뀔 수 있다.

---

## 원본을 유지하려면

```js
const numbers = [1, 2, 3];
const copied = [...numbers];

copied[0] = 100;

// console.log(numbers); [1, 2, 3]
// console.log(copied); [100, 2, 3]
```

---

## 핵심

```text
Number, String, Boolean
→ 값 복사

Array, Object
→ 참조 사용

배열/객체를 그냥 대입
→ 같은 데이터를 바라볼 수 있음

원본을 유지하려면
→ 복사해서 사용
```

## 재대입과 내부 수정의 차이

```javascript
const original = [1, 2];
let other = original;

other[0] = 100; // 같은 배열의 내부 수정
console.log(original); // [100, 2]

other = [9, 9]; // other만 새 배열을 가리키도록 재대입
console.log(original); // [100, 2]
console.log(other);    // [9, 9]
```

- 객체나 배열을 대입하면 객체 자체를 복사하는 것이 아니라 참조 값이 복사된다.
- 함수에 전달할 때도 값이 복사된다. 객체라면 참조 값이 복사되어 같은 객체를 수정할 수 있다.
- `const`는 변수의 재대입을 막는다. 배열·객체 내부의 수정까지 막지는 않는다.
- Spread로 복사해도 중첩 객체는 공유될 수 있다. 11번의 얕은 복사와 연결되는 내용이다.

## 직접 해보기

1. 숫자를 다른 변수에 대입한 뒤, 두 번째 변수만 바꿔서 둘 다 출력한다.
2. 배열을 다른 변수에 대입한 뒤, 두 번째 변수로 첫 원소를 바꿔서 둘 다 출력한다.
3. 두 번째 변수를 새 배열로 재대입한 뒤, 원래 배열도 바뀌는지 확인한다.
