# 05. 조건문

## if

조건이 참일 때 코드를 실행한다.

```js
const age = 20;

if (age >= 18) {
  console.log("성인");
}

// 성인
```

* `if`: 조건을 검사한다.
* 조건이 `true`일 때만 실행된다.

---

## if / else

조건이 참인지 거짓인지에 따라 나눈다.

```js
const number = 7;

if (number % 2 === 0) {
  console.log("짝수");
} else {
  console.log("홀수");
}

// 홀수
```

---

## else if

조건이 여러 개일 때 사용한다.

```js
const score = 85;

if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else {
  console.log("C");
}

// B
```

* 위에서부터 순서대로 조건을 확인한다.
* 먼저 참이 된 조건만 실행한다.

---

## 여러 조건 검사하기

```js
const age = 20;
const hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("입장 가능");
}

// 입장 가능
```

* `&&`: 두 조건이 모두 참
* `||`: 하나라도 참

---

## 중첩 조건문

`if` 안에 또 `if`를 사용할 수 있다.

```js
const number = 10;

if (number > 0) {
  if (number % 2 === 0) {
    console.log("양수이면서 짝수");
  }
}

// 양수이면서 짝수
```

---

## switch

하나의 값을 여러 경우와 비교할 때 사용한다.

```js
const day = 2;

switch (day) {
  case 1:
    console.log("월");
    break;
  case 2:
    console.log("화");
    break;
  case 3:
    console.log("수");
    break;
  default:
    console.log("기타");
}

// 화
```

* `case`: 비교할 값
* `break`: 실행 후 `switch` 종료
* `default`: 어떤 경우에도 맞지 않을 때 실행

---

## 조건으로 최댓값 갱신하기

```js
let maxValue = 5;
const number = 10;

if (number > maxValue) {
  maxValue = number;
}

// console.log(maxValue); 10
```

---

## 핵심

```text
if
→ 조건이 참일 때 실행

else
→ 조건이 거짓일 때 실행

else if
→ 여러 조건을 순서대로 검사

switch
→ 하나의 값을 여러 경우와 비교
```
