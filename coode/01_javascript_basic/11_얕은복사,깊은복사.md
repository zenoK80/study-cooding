# 11. 얕은 복사 / 깊은 복사

## 배열은 참조된다

배열을 그냥 대입하면 같은 배열을 바라본다.

```js
const original = [1, 2, 3];
const copied = original;

copied[0] = 100;

// console.log(original); [100, 2, 3]
```

* `copied`를 바꿨는데 `original`도 같이 바뀐다.

---

## 얕은 복사

새로운 배열을 만들지만, 한 단계만 복사한다.

```js
const original = [1, 2, 3];
const copied = [...original];

copied[0] = 100;

// console.log(original); [1, 2, 3]
// console.log(copied); [100, 2, 3]
```

배열은 `slice()`로도 복사할 수 있다.

```js
const copied = original.slice();
```

---

## 객체 얕은 복사

```js
const original = {
  name: "Kim",
  age: 20
};

const copied = {
  ...original
};

copied.age = 30;

// console.log(original.age); 20
// console.log(copied.age); 30
```

---

## 중첩 배열의 얕은 복사

안쪽 배열은 여전히 같은 값을 참조한다.

```js
const original = [
  [1, 2],
  [3, 4]
];

const copied = [...original];

copied[0][0] = 100;

// console.log(original[0][0]); 100
```

* 바깥 배열만 새로 만들어졌다.
* 안쪽 배열은 그대로 공유한다.

---

## 2차원 배열 복사

안쪽 배열까지 각각 복사한다.

```js
const original = [
  [1, 2],
  [3, 4]
];

const copied = original.map(row => [...row]);

copied[0][0] = 100;

// console.log(original[0][0]); 1
// console.log(copied[0][0]); 100
```

---

## 깊은 복사

중첩된 값까지 전부 새로 복사한다.

```js
const original = {
  user: {
    name: "Kim",
    score: 10
  }
};

const copied = structuredClone(original);

copied.user.score = 100;

// console.log(original.user.score); 10
// console.log(copied.user.score); 100
```

* `structuredClone()`은 중첩된 배열이나 객체까지 복사한다.

---

## 핵심

```text
그냥 대입
→ 같은 배열/객체를 참조

Spread, slice
→ 얕은 복사

map(row => [...row])
→ 2차원 배열 복사

structuredClone()
→ 깊은 복사
```
