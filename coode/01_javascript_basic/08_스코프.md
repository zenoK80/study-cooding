# 08. 스코프

## 전역 스코프

함수나 블록 밖에서 만든 변수는 아래쪽 어디서든 사용할 수 있다.

```js
const number = 10;

function printNumber() {
  console.log(number);
}

printNumber();

// 10
```

* 바깥에서 만든 변수는 함수 안에서도 접근할 수 있다.

---

## 함수 스코프

함수 안에서 만든 변수는 함수 밖에서 사용할 수 없다.

```js
function test() {
  const number = 10;

  console.log(number);
}

test();

// console.log(number); // Error
```

* `number`는 `test` 함수 안에서만 사용할 수 있다.

---

## 블록 스코프

`let`, `const`는 `{ }` 안에서만 사용할 수 있다.

```js
if (true) {
  const message = "Hello";

  console.log(message);
}

// console.log(message); // Error
```

---

## 같은 이름의 변수

안쪽에서는 같은 이름의 변수를 새로 만들 수 있다.

```js
const number = 10;

function test() {
  const number = 20;

  console.log(number);
}

test();
console.log(number);

// 20
// 10
```

* 가까운 스코프의 변수를 먼저 사용한다.

---

## 반복문의 변수

```js
for (let i = 0; i < 3; i++) {
  console.log(i);
}

// console.log(i); // Error
```

* `i`는 `for` 블록 안에서만 사용할 수 있다.

---

## 핵심

```text
전역 변수
→ 바깥에서 선언
→ 안쪽에서도 사용 가능

지역 변수
→ 함수나 블록 안에서 선언
→ 바깥에서는 사용 불가

let, const
→ 블록 스코프
```
