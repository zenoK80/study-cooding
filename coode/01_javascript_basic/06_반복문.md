# 06. 반복문

## for

정해진 횟수만큼 반복한다.

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// 0
// 1
// 2
// 3
// 4
```

* `let i = 0`: 시작값
* `i < 5`: 반복 조건
* `i++`: 반복할 때마다 1 증가

---

## 배열 반복하기

```js
const numbers = [10, 20, 30];

for (let i = 0; i < numbers.length; i++) {
  console.log(numbers[i]);
}

// 10
// 20
// 30
```

* `numbers.length`: 배열의 길이
* `numbers[i]`: 현재 위치의 값

---

## for...of

배열의 값을 하나씩 꺼낼 때 사용한다.

```js
const numbers = [10, 20, 30];

for (const number of numbers) {
  console.log(number);
}

// 10
// 20
// 30
```

* 인덱스가 필요 없으면 `for...of`가 간단하다.

---

## while

조건이 참인 동안 계속 반복한다.

```js
let count = 0;

while (count < 3) {
  console.log(count);
  count++;
}

// 0
// 1
// 2
```

---

## 합계 구하기

```js
const numbers = [1, 2, 3, 4, 5];

let sum = 0;

for (const number of numbers) {
  sum += number;
}

// console.log(sum); 15
```

---

## break

반복문을 바로 종료한다.

```js
for (let i = 0; i < 10; i++) {
  if (i === 3) {
    break;
  }

  console.log(i);
}

// 0
// 1
// 2
```

---

## continue

현재 반복만 건너뛰고 다음 반복으로 간다.

```js
for (let i = 0; i < 5; i++) {
  if (i === 2) {
    continue;
  }

  console.log(i);
}

// 0
// 1
// 3
// 4
```

---

## 이중 반복문

반복문 안에 반복문을 사용할 수 있다.

```js
for (let i = 0; i < 2; i++) {
  for (let j = 0; j < 3; j++) {
    console.log(i, j);
  }
}

// 0 0
// 0 1
// 0 2
// 1 0
// 1 1
// 1 2
```

---

## 핵심

```text

for...of

while
→ 조건이 참인 동안 반복

break
→ 반복 종료

continue
→
```
