# 컴포넌트
컴포넌트는 화면을 나눈 작은 UI 조각이다.
```jsx
function Header(){
  return <header>Header</header>;
}
```
- `Header`: 컴포넌트 이름
- 컴포넌트 이름은 보통 대문자로 시작한다.
- `return`: 화면에 보여줄 JSX를 반환한다.

---

# 컴포넌트 사용하기
```jsx
function Header(){
  return <header>Header</header>
}

function App(){
  return <Header/>
}
```
- `<Header />` : 만든 컴포넌트를 사용하는 문법

---

# 여러 컴포넌트 조합하기
```jsx
function Header(){
  return <header>Header</header>;
}

function Main(){
  return <main>Main</main>;
}

function App(){
  return(
    <>
      <Header/>
      <Main/>
    </>
  )
}
```
화면을 작은 컴포넌트로 나눈 뒤 조합해서 만든다.

---

# 컴포넌트 재사용
```jsx
function Button() {
return <button>클릭</button>;
}

function App() {
  return ( <> <Button /> <Button /> <Button /> </> );
}
```
같은 컴포넌트를 여러 번 사용할 수 있다.

---

# 핵심
Component
→ 화면을 나눈 작은 UI 단위

function ComponentName()
→ 컴포넌트 정의

<ComponentName />
→ 컴포넌트 사용

컴포넌트 이름
→ 대문자로 시작
