# 03. 해시 알고리즘이란?

## 한마디로

**키를 이용해서 데이터를 빠르게 저장하고 찾는 방식입니다.** ‘완주하지 못한 선수’에서는 이름을 키로 사용해 인원수를 찾았습니다.

```javascript
const counts = new Map();
counts.set('kim', 2); // 키: 'kim', 값: 2
counts.set('lee', 1); // 키: 'lee', 값: 1
counts.get('kim');    // kim에 저장한 값 조회 → 2
```

- **키**: 값을 찾기 위한 이름표. 여기서는 선수 이름입니다.
- **값**: 이름표에 저장한 내용. 여기서는 인원수지만, 다른 데이터도 저장할 수 있습니다.

## 왜 빠르게 찾을 수 있나?

- 정렬되지 않은 배열에서 이름을 찾으면 보통 원소를 하나씩 비교합니다. 마지막에 있거나 없으면 전체를 확인해야 합니다.
- 해시는 **키를 계산해서 저장 위치를 찾는 데 사용**합니다. 매번 전체 데이터를 처음부터 비교하지 않도록 합니다.

```text
'kim'이라는 키 → 해시 함수로 계산 → 저장 위치 확인 → 저장한 값 2 조회
```

- **해시 함수**: 키를 받아 해시값을 계산하는 함수입니다. 그 결과를 저장 위치를 정하는 데 사용합니다.
- **해시 테이블**: 이 방식으로 키와 값을 저장하는 자료구조입니다. 자료구조는 데이터를 담고 정리하는 방식이라는 뜻입니다.
- **해시 충돌**: 서로 다른 키가 같은 저장 위치로 연결되는 경우입니다. 구현 내부에서 키를 구분해 처리하므로 무조건 덮어쓰는 것은 아닙니다.
- 코딩테스트에서 ‘해시 알고리즘’은 보통 **해시 자료구조를 활용한 풀이**를 뜻합니다. 암호화나 비밀번호 해시를 구현하는 문제라는 뜻은 아닙니다.

## 내가 해시 함수를 만든 적은 없는데?

**직접 만들 필요 없이 객체·Map을 키별 저장소로 사용한 것입니다.** 내부에서 데이터를 찾는 세부 처리는 JavaScript 엔진이 담당합니다.

```javascript
// 객체로 저장·조회
const object = Object.create(null);
object['kim'] = 2;
object['kim']; // 2

// Map으로 저장·조회
const counts = new Map();
counts.set('kim', 2);
counts.get('kim'); // 2
```

- JavaScript가 객체·Map의 내부 구현을 반드시 특정 해시 테이블 방식으로 고정하는 것은 아닙니다. 코테에서는 일반적인 해시 기반 구현으로 복잡도를 설명합니다.
- 배열의 `.map()`은 원소를 변환해 새 배열을 만드는 메서드입니다. 위의 `Map`과는 별개입니다.

## 완주하지 못한 선수가 왜 해시 문제인가?

- 참가자 이름을 키로 찾아 인원수를 1씩 더합니다.
- 완주자 이름을 키로 찾아 인원수를 1씩 뺍니다.
- 마지막에 값이 1인 이름을 반환합니다. 같은 이름이 여러 번 나와도 개수로 구분합니다.

```text
참가자 ['kim', 'kim', 'lee'] → kim: 2, lee: 1
완주자 ['kim', 'lee'] 차감   → kim: 1, lee: 0
결과                       → 'kim'
```

**이름별 값을 반복해서 찾아야 하므로 해시 방식이 잘 맞는 문제입니다.** 반드시 해시로 풀어야 하는 것은 아니며, 정렬해서 비교해도 됩니다.

## 정리

- **해시**: 키를 계산해서 데이터를 찾을 위치를 정하는 방식.
- **해시 테이블**: 그 방식을 이용해 키·값을 저장하는 자료구조.
- 일반적인 해시 구현에서는 조회·저장 한 번이 평균 `O(1)`입니다. 데이터가 늘어도 작업량이 평균적으로 일정하다는 뜻이며, 1초라는 뜻은 아닙니다.
- 선수 문제는 참가자·완주자를 순회하므로 평균 시간 `O(n)`, 서로 다른 이름을 최대 n개 저장하므로 최악의 추가 공간 `O(n)`입니다.
- 충돌과 구현 방식에 따라 최악 비용은 달라집니다. 평균 `O(1)`이 모든 경우의 속도를 보장하지는 않습니다.
- **찾는 값이 있는지 확인, 이름별 개수 세기, ID별 데이터 조회**처럼 키로 반복 조회하는 문제에서 활용할 수 있습니다.
