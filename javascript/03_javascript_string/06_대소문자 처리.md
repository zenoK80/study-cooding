# toUpperCase()
문자열을 모두 대문자로 바꾼다.
```js
const text = "hello";
const result = text.toUpperCase();
console.log(text);
// "HELLO"
```

---

# upLoswerCase()
문자열을 모두 소문자로 바꾼다.
```js
const text ="HELLO";
const result = text.toLowerCase();
console.log(result);
// "hello"
```

---

# 대소문자 무시하고 비교하기
```js
const first = "Hello";
const second = "hello";
const result = first.toLowerCase() === second.toLowerCase();
console.log(result);
// true
```

---

# 원본 문자열은 그대로
```js
const text = "Hello";

const result = text.toUpperCase();

// console.log(text); "Hello"
// console.log(result); "HELLO"
```
- 문자열은 직접 바뀌지 않는다.
- 새로운 문자열을 반환한다.

---

# 핵심
toUpperCase()
→ 모두 대문자로 변환

toLowerCase()
→ 모두 소문자로 변환

둘 다
→ 새 문자열 반환
→ 원본 유지
