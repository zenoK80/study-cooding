# 부분 문자열
부분 문자열은 문자열 안에 들어있는 일부 문자열이다.

`"javascript"`
ex)
- "java"
- "script"
- "ava"

---

# includes()
특정 문자열이 포함되어 있는지 확인한다.
```js
const text = "javascript";
const result = text.includes("script");
console.log(result);
// true
```
- 포함 → true
- 없음 → false

---

# slice()로 부분 문자열 만들기
```js
const text = "javascript";
const result = text.slice(0, 4);
// console.log(result); "java"
```
- 시작 index 포함
- 끝 index 제외

---

# 모든 부분 문자열 확인하기
```js
const text = "abc";
for (let start = 0; start < text.length; start++){
	for (let end = start + 1; end <= text.length; end++){
		console.log(text.slice(start,end));
	}
}
// a
// ab
// abc
// b
// bc
// c
```
흐름:

start = 0
→ a
→ ab
→ abc

start = 1
→ b
→ bc

start = 2
→ c

---

# 핵심
부분 문자열
→ 문자열의 일부

includes()
→ 포함 여부 확인

slice(start, end)
→ 부분 문자열 잘라내기

이중 반복문 + slice()
→ 모든 부분 문자열 만들기
