# 문자열 순회
문자열도 배열처럼 한 글자씩 순서대로 확인할 수 있다.
```js
const text = "hello";
for(let index = 0; index < text.length; index++){
	console.log(text[index]);
}
// h
// e
// l
// l
// o
```
- `text.length`: 문자열 길이
- `text[index]`: 현재 위치의 문자

---

# for...of
문자만 필요하면 더 간단하게 순회할 수 있다.
```js
const text = "hello";
for (const character of text){
	console.log(character);
}
// h
// e
// l
// l
// o
```
- `character`: 현재 문자

---

# index와 문자 같이 사용
```js
const text = "abc";
for(let index = 0; index < text.length; index++){
	const character = text[index];
	console.log(index,character);
}
// 0 a
// 1 b
// 2 c
```

# 특정 문자 개수 세기
```js
const text = "banana";
let count = 0;

for(const character of text){
	if(character ==="a"){
		count++;
	}
}

// console.log(count); 3
```

---

# 핵심
- `for` -> index가 필요할 때
- `for...of` -> 문자만 필요할 때
- `text[index]` -> 해당 위치의 문자
- `text.length` -> 문자열 길이
