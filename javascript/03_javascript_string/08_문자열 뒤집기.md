# 문자열 뒤집기
문자열은 `reverse()`를 바로 사용할 수 없다.
그래서 먼저 배열로 바꾼다.

```js
const text = "hello";
const reversed = text.split("").reverse().join("");
console.log(reversed)
// "olleh"
```
- `split("")`: 문자열을 한 글자씩 잘라 배열로 만든다.
- `reverse()`: 배열의 순서를 반대로 뒤집는다.
- `join("")`: 배열을 다시 문자열로 합친다.

---

# 실행 흐름
```
"hello"
↓ split("")

["h", "e", "l", "l", "o"]
↓  reverse()

["o", "l", "l", "e", "h"]
↓ join("")

"olleh"
```

---

# 원본 문자열
```js
const text = "hello";
const reversed = text.split("").reverse().join("");
console.log(reversed)
// "olleh"
console.log(text);
// "hello"
```
- 원본 문자열은 바뀌지 않는다.
- 뒤집힌 새 문자열이 만들어진다.

---

# 핵심
문자열 뒤집기
split("") → 배열로 변환
reverse() → 순서 뒤집기
join("") → 문자열로 다시 합치기
