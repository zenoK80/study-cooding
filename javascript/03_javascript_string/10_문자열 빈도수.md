# 문자열 빈도수
문자열에서 각 문자가 몇 번 나오는지 센다.
```js
const text = "banana";
const count = {};
for(const character of text){
	count[character] = (count[character] ?? 0) + 1;
}
console.log(count);
// {b:1, a:3, n:2 }
```
- character : 현재 문자
- count[character] : 현재까지 나온 개수
- ?? 0 : 처음 나온 문자면 0부터 시작

---

# 특정 문자만 세기
```js
const text = "banana"
let count = 0;
for (const character of text){
	if(character === "a" ){ count++;}
}
console.log(count)
```

---

# Map으로 세기
```js
const text = "banana"
const count = new Map();

for(const character of text){
	count.set(character,(count.get(character) ?? 0) + 1);
}

console.log(count.get("a"))
// 3
```

--

# 핵심
Object 방식
```js
count[character] = (count[character] ?? 0) + 1
````
Map 방식
```js
count.set(
  character,
  (count.get(character) ?? 0) + 1
)
```
문자열 빈도수
→ 각 문자가 몇 번 나왔는지 계산
