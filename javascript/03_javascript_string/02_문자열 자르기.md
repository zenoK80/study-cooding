# slice()
문자열의 일부를 잘라서 새 문자열을 만든다.
```js
const text = "abcdf";
const result = text.slice(1,4);
// console.log(result); "bcd"
```
- 인자1: 시작 index
- 인자2: 끝 index
- 끝 index는 포함하지 않는다.

---

# 끝까지 자르기
```js
const text = "abcdef";
const result = text.slice(2);
// console.log(result); "cdef"
```
- 인자2를 생략하면 끝까지 자른다.

---

# 음수 index
```js
const text = "abcdef";
const result = text.slice(-2);
// console.log(result); "ef"
```
- `-1`:마지막 문자
- `-2`:뒤에서 두 번째 문자

---

# substring()
`slice()`와 비슷하게 문자열을 자른다.
```js
const text = "abcdef";
const result = text.substring(1,4);
// console.log(result); "bcd"
```
- 인자1: 시작 index
- 인자2: 끝 index
- 끝 index는 포함하지 않는다.

---

# slice()와 substring() 차이
```js
const text = "abcdef";
console.log(text.slice(-2));
// "ef"

console.log(text.substring(-2));
// "abcdef"
```
- `slice()` : 음수 index 사용 가능
- `substring()` : 음수를 0처럼 처리

---

# 핵심
`slice(시작, 끝)`
→ 시작부터 끝 직전까지 자름
→ 음수 index 가능

`substring(시작, 끝)`
→ slice와 비슷
→ 음수 index는 0처럼 처리
