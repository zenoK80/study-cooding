# charCodeAt()
문자를 숫자 코드로 바꾼다.
```js
const text = "A";
const code = text.charCodeAt(0);
console.log(code);
// 65
```
- `charCodeAt(index)`: 해당 위치 문자의 코드값 반환

---

# 소문자 코드
```js
const text = "a";
console.log(text.charCodeAt(0))
// 97
```
대표 값:

"A" → 65
"B" → 66
"C" → 67

"a" → 97
"b" → 98
"c" → 99

---

# String.fromCharCode()
숫자 코드를 문자로 바꾼다.
```js
const character = String.fromCharCode(65);
console.log(character);
// "A"
```

---

# 문자 이동하기
```js
const code = "A".charCodeAt(0);
const next = String.fromCharCode(code + 1);
console.log(next)
// "B"
```

---

# 알파벳 위치 구하기
```js
const character = "C";
const position = character.charCodeAt(0) - "A".charCodeAt(0)
console.log(position)
// 2
```
- 67 - 65 = 2

---

# 핵심
charCodeAt(index)
→ 문자 → 숫자 코드

String.fromCharCode(number)
→ 숫자 코드 → 문자

"A" → 65
"a" → 97
