# 팰린드롬
팰린드롬(Palindrome, 회문)은 앞으로 읽으나 뒤로 읽으나 동일한 단어나 문장
- level
- madam
- racecar
- 토마토
- 기러기

---

# 뒤집어서 비교하기
```js
const text = "level";
const reversed = text.split("").reverse().join("");

const result = text === reversed;
console.log(result);
// true
```
- 원래 문자열과 뒤집은 문자열이 같으면 팰린드롬이다.

---

# 함수로 만들기
```js
function isPalindrome(text){
	const reversed = text.split("").reverse().join("");
	return text === reversed;
}

console.log(isPalindrome("level"))
// true
console.log(isPalindrome("hello"))
// false
```

---

# 양쪽에서 비교하기
문자열을 뒤집지 않고 직접 비교할 수 있다.
```js
const text = "level";
let isPalindrome = true;
for(let index = 0; index < text.length / 2; index++){
	if(text[index] !== text[text.length - 1 - index]){
		isPalindrome = false;
		break;
	}
}
console.log(isPalindrome)
// true
```
비교 흐름:
1. index = 0
2. text[0] ↔ text[4]

3. index = 1
4. text[1] ↔ text[3]

# 핵심
팰린드롬
→ 앞뒤가 같은 문자열

간단한 방법
→ 뒤집어서 원본과 비교

text === reversed
→ true면 팰린드롬
