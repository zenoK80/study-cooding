# 02. 폰켓몬

## 문제 설명

당신은 폰켓몬을 잡기 위한 오랜 여행 끝에, 홍 박사님의 연구실에 도착했습니다. 홍 박사님은 당신에게 자신의 연구실에 있는 총 N 마리의 폰켓몬 중에서 N/2마리를 가져가도 좋다고 했습니다.

홍 박사님 연구실의 폰켓몬은 종류에 따라 번호를 붙여 구분합니다. 따라서 같은 종류의 폰켓몬은 같은 번호를 가지고 있습니다. 예를 들어 연구실에 총 4마리의 폰켓몬이 있고, 각 폰켓몬의 종류 번호가 [3번, 1번, 2번, 3번]이라면 이는 3번 폰켓몬 두 마리, 1번 폰켓몬 한 마리, 2번 폰켓몬 한 마리가 있음을 나타냅니다. 이때, 4마리의 폰켓몬 중 2마리를 고르는 방법은 다음과 같이 6가지가 있습니다.

1. 첫 번째(3번), 두 번째(1번) 폰켓몬을 선택
2. 첫 번째(3번), 세 번째(2번) 폰켓몬을 선택
3. 첫 번째(3번), 네 번째(3번) 폰켓몬을 선택
4. 두 번째(1번), 세 번째(2번) 폰켓몬을 선택
5. 두 번째(1번), 네 번째(3번) 폰켓몬을 선택
6. 세 번째(2번), 네 번째(3번) 폰켓몬을 선택

이때, 첫 번째(3번) 폰켓몬과 네 번째(3번) 폰켓몬을 선택하는 방법은 한 종류(3번 폰켓몬 두 마리)의 폰켓몬만 가질 수 있지만, 다른 방법들은 모두 두 종류의 폰켓몬을 가질 수 있습니다. 따라서 위 예시에서 가질 수 있는 폰켓몬 종류 수의 최댓값은 2가 됩니다.

당신은 최대한 다양한 종류의 폰켓몬을 가지길 원하기 때문에, 최대한 많은 종류의 폰켓몬을 포함해서 N/2마리를 선택하려 합니다. N마리 폰켓몬의 종류 번호가 담긴 배열 nums가 매개변수로 주어질 때, N/2마리의 폰켓몬을 선택하는 방법 중, 가장 많은 종류의 폰켓몬을 선택하는 방법을 찾아, 그때의 폰켓몬 종류 번호의 개수를 return 하도록 solution 함수를 완성해주세요.

## 제한사항

- nums는 폰켓몬의 종류 번호가 담긴 1차원 배열입니다.
- nums의 길이(N)는 1 이상 10,000 이하의 자연수이며, 항상 짝수로 주어집니다.
- 폰켓몬의 종류 번호는 1 이상 200,000 이하의 자연수로 나타냅니다.
- 가장 많은 종류의 폰켓몬을 선택하는 방법이 여러 가지인 경우에도, 선택할 수 있는 폰켓몬 종류 개수의 최댓값 하나만 return 하면 됩니다.

## 입출력 예

| nums | result |
| --- | --- |
| [3, 1, 2, 3] | 2 |
| [3, 3, 3, 2, 2, 4] | 3 |
| [3, 3, 3, 2, 2, 2] | 2 |

## 입출력 예 설명

- 예제 #1: 문제의 예시와 같습니다.
- 예제 #2: 6마리의 폰켓몬이 있으므로 3마리를 골라야 합니다. 3번 한 마리, 2번 한 마리, 4번 한 마리를 고르면 가장 많은 종류를 고를 수 있으므로 3을 return 합니다.
- 예제 #3: 6마리의 폰켓몬이 있으므로 3마리를 골라야 합니다. 3번 한 마리와 2번 두 마리, 혹은 3번 두 마리와 2번 한 마리를 고르면 됩니다. 따라서 최대 고를 수 있는 종류의 수는 2입니다.

## 내가 푼 답

```javascript
function solution(N) {
  let result = '';
  const k = N.length / 2;
  const set = new Set(N);

  if (k < set.size) {return result = k;}
  if (k > set.size) {return result = set.size;}
  if (k === set.size) {return result = k;}
}
```

- **정답입니다.** 종류가 선택 가능 마릿수보다 많으면 k, 적으면 종류 수, 같으면 둘 중 어느 값이든 반환하면 됩니다.
- 매개변수 이름 N도 가능하지만, 문제 설명의 N은 마릿수이고 네 코드의 N은 배열입니다. nums로 쓰면 혼동이 줄어듭니다.
- `return result = k`는 result에 k를 저장한 뒤 그 값을 반환합니다. 동작은 맞지만 이후 result를 쓰지 않으므로 `return k`로 충분합니다.
- 시간: 일반적인 해시 기반 Set에서 원소 n개 처리 → 평균 `O(n)`. 추가 공간: 서로 다른 종류 u개 저장 → `O(u)`, 최악 `O(n)`. 여기서 n은 입력 배열 길이입니다.

## 다른 방법

### (1) Math.min — 추천

```javascript
function solution(nums) {
  const limit = nums.length / 2;
  const types = new Set(nums).size;
  return Math.min(limit, types);
}
```

- 네 세 가지 조건을 ‘두 값 중 작은 값’으로 표현한 것입니다. 시간 평균 `O(n)`, 추가 공간 최악 `O(n)`으로 네 풀이와 같습니다.

### (2) Set.size와 삼항 연산자

```javascript
function solution(nums) {
  const limit = nums.length / 2;
  const types = new Set(nums).size;
  return types > limit ? limit : types;
}
```

- 올려준 noDuplicatePokemon·pokemonVarietyCount 풀이와 같은 원리입니다. Set의 size만 조회하므로 별도 배열은 필요 없습니다.
- 시간 평균 `O(n)`, 추가 공간 `O(u)`입니다. n은 전체 마릿수, u는 전체 종류 수이며 u는 최대 n입니다.

### (3) Set을 배열로 바꾸고 length 사용 — 전개 구문 연습

```javascript
function solution(nums) {
  const limit = nums.length / 2;
  const types = [...new Set(nums)];
  return types.length > limit ? limit : types.length;
}
```

- new Set으로 중복 제거 → 전개 구문으로 새 배열 생성 → length 조회 순서입니다. `[3, 1, 2, 3]` → `[3, 1, 2]` → 길이 3.
- 시간: Set 생성 평균 O(n) + 배열로 복사 O(u) → 평균 `O(n)`. 추가 공간: Set과 새 배열 → `O(u)`. (1)·(2)와 빅오는 같지만 별도 배열 생성·복사가 추가됩니다.
- 종류 목록을 배열로 사용할 때는 유용하지만 개수만 필요하면 Set.size가 더 직접적입니다.

### (4) Set.add와 조기 반환 — 충분한 종류를 찾으면 끝내기

```javascript
function solution(nums) {
  const limit = nums.length / 2;
  const types = new Set();
  for (const num of nums) {
    types.add(num);
    if (types.size === limit) return limit;
  }
  return types.size;
}
```

- 서로 다른 종류를 limit개 발견하면 이미 가능한 최대 종류 수를 확보했으므로 나머지를 보지 않아도 됩니다.
- 끝까지 봐도 limit개가 안 되면 실제 발견한 종류 수를 반환합니다. 실제 폰켓몬 선택 목록을 만들 필요는 없습니다.
- 시간: 해시 기반 Set의 add를 평균 O(1)로 볼 때 최대 n개 처리 → 평균 비용 기준 `O(n)`. 추가 공간: 최대 min(u, limit)개 저장 → `O(min(u, limit))`, 최악 `O(n)`.

## 정리

### 왜 작은 값이 최대 종류 수인가?

- **마릿수**는 실제 데려가는 폰켓몬 수, **종류 수**는 그 안에 서로 다른 번호가 몇 개인지입니다. `[3, 3, 2]`는 3마리지만 2종류입니다.
- `/ 2`는 찾아낸 패턴이 아니라 **전체의 절반만 가져갈 수 있다는 문제 규칙**입니다. 총 6마리면 정확히 3마리를 골라야 합니다.
- 종류 수를 최대화하려면 먼저 서로 다른 종류를 한 마리씩 고릅니다. 같은 종류를 더 골라도 종류 수는 늘지 않습니다.

**경우 1: 가져갈 자리가 더 적음**

```text
전체: [1, 2, 3, 4, 5, 6]
가져갈 수 있음: 3마리 / 존재하는 종류: 6종류
선택 예: [1, 2, 3] → 3종류
4종류를 가져가려면 최소 4마리가 필요하므로 불가능
최대 종류 수 = 3
```

**경우 2: 실제 종류가 더 적음**

```text
전체: [3, 3, 3, 2, 2, 2]
가져갈 수 있음: 3마리 / 존재하는 종류: 2종류
먼저 종류별로 [3, 2] 선택 → 2종류 확보
남은 한 자리에 3 또는 2 추가 → 예: [3, 2, 3]
3마리를 채워도 없는 새 종류를 만들 수는 없음
최대 종류 수 = 2
```

- 즉, 최대 종류 수는 **가져갈 자리 수도 넘을 수 없고, 실제 종류 수도 넘을 수 없습니다.** 그래서 두 제한 중 작은 쪽에 막힙니다.
- 그 작은 값은 실제로 달성 가능합니다. 종류가 충분하면 자리마다 다른 종류를 넣고, 부족하면 모든 종류를 한 마리씩 고른 뒤 남은 자리를 중복으로 채우면 됩니다.
- **작은 종류 수를 일부러 고르는 것이 아니라, 두 제한 안에서 가능한 가장 큰 종류 수를 구하는 것**입니다.

### 문법과 추천

- `new Set(배열)` : 중복된 값을 하나씩만 보관하는 Set을 만듭니다. `[3, 1, 2, 3]` → 값 3, 1, 2가 저장됩니다. 원본 배열은 바뀌지 않습니다.
- `set.size` : Set에 저장된 값의 개수입니다. 이 문제에서는 종류 수입니다. 메서드가 아니라 속성이므로 괄호를 붙이지 않습니다.
- `배열.length`는 전체 마릿수, `Set.size`는 중복을 제외한 종류 수입니다.
- `Math.min(a, b)` : 두 숫자 중 작은 값을 반환합니다. `Math.min(2, 3)` → 2.
- 선택할 수 있는 종류는 가져갈 마릿수보다 많을 수 없고, 실제 존재하는 종류 수보다도 많을 수 없습니다. 따라서 둘 중 작은 값이 정답입니다.
- `[3, 1, 2, 3]`은 종류가 3개여도 2마리만 가져가므로 최대 2종류입니다.
- `[3, 3, 3, 2, 2, 2]`는 3마리를 가져가도 종류가 2개뿐이라 최대 2종류입니다.
- `Set`은 중복 없는 값을 저장하고, `Map`은 키와 값을 짝지어 저장합니다. 이번 문제는 이름별 개수처럼 값을 따로 기록할 필요 없이 종류 수만 세면 됩니다.
- 해시 유형인 이유는 중복 여부를 빠르게 확인하는 자료구조가 잘 맞기 때문입니다. JavaScript가 Set의 내부 구현을 반드시 특정 해시 방식으로 고정하는 것은 아닙니다.
- `set.add(값)` : Set에 값을 추가합니다. 이미 있는 값이면 개수가 늘지 않습니다. `add(3)`을 두 번 해도 3은 하나만 저장됩니다.
- `[...set]` : Set의 값들을 펼쳐 새 배열로 만듭니다. Set은 size, 배열은 length로 개수를 확인합니다.
- `types > limit ? limit : types` : 종류가 자리 수보다 많으면 자리 수, 아니면 종류 수를 반환합니다. 같으면 어느 쪽도 같은 값이라 >=로 비교해도 결과가 같습니다.
- `Math.floor(nums.length / 2)` : 길이가 항상 짝수라 이미 정수입니다. 여기서는 floor가 없어도 됩니다.
- **추천은 (1) Math.min + Set.size**입니다. (2)는 조건문 연습, (3)은 Set을 배열로 바꾸는 연습, (4)는 더 확인할 필요가 없는 시점에 반환하는 연습용입니다.
