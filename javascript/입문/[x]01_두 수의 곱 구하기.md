# 01. 두 수의 곱 구하기

## 문제 안내

> 정수 num1 , num2 가 매개변수 주어집니다. num1 과 num2 …

문제 조건·제한사항·상세 설명은 위 공식 원문에서 확인합니다. 아래는 풀이를 기록할 학습 노트입니다.

## 입력·출력 / 데이터 표

| num1 | num2 | result |
| --- | --- | --- |
| 3 | 4 | 12 |
| 27 | 19 | 513 |

## 문제 코드

```javascript
function solution(num1, num2) {
    var answer = 0;
    return answer;
}
```

## 내가 푼 답

```javascript
function solution(num1, num2) {
  let answer = 0;
  if (num1 < 0 || num1 > 100 || !Number.isInteger(num1)) return;
  if (num2 < 0 || num2 > 100 || !Number.isInteger(num2)) return;
  answer = num1 * num2;
  return answer;
}
```

## 다른 방법

### (1) 곱셈 결과 바로 반환 — 추천

```javascript
function solution(num1, num2) {
  return num1 * num2;
}
```

---

### (2) 화살표 함수

```javascript
const solution = (num1, num2) => num1 * num2;
```

---

### (3) 반복 덧셈 — 원리 연습용

```javascript
function solution(num1, num2) {
  let answer = 0;
  for (let i = 0; i < num2; i++) {answer += num1;}
  return answer;
}
```

---

## 정리

- `*`: 두 숫자를 곱합니다. `3 * 4` → `12`.
- `&&`(그리고): 조건이 모두 참인지 확인합니다. `num1 >= 0 && num1 <= 100` → 정상 범위.
- `||`(또는): 조건 중 하나라도 참인지 확인합니다. `num1 < 0 || num1 > 100` → 범위 밖.
- `!`: 참·거짓을 뒤집습니다. `!true` → `false`, `!false` → `true`.
- `Number.isInteger(값)`: 숫자 자료형의 정수인지 검사합니다. `3` → `true`, `3.5`·`'3'`·`NaN` → `false`.
- `!Number.isInteger(값)`: 정수가 아니면 `true`입니다. 잘못된 입력을 걸러낼 때 사용합니다.
- `isNaN(값)`: 숫자로 변환한 결과가 `NaN`인지 검사합니다. `isNaN('abc')` → `true`, `isNaN('3')`·`isNaN(3.5)` → `false`.
- `!isNaN(값)`: 숫자로 변환한 결과가 `NaN`이 아니면 `true`입니다. `'3'`과 `3.5`도 통과하므로 정수 검사를 대신할 수 없습니다.
- `Number.isNaN(값)`: 변환 없이 값 자체가 `NaN`인지 검사합니다. `Number.isNaN(NaN)` → `true`, `Number.isNaN('abc')` → `false`.
- `if (조건) return;`: 조건이 참이면 함수를 종료하고 `undefined`를 반환합니다. `if (!isNaN(num1)) return;`으로 쓰면 정상 숫자도 종료시켜 버립니다.
- 내 답은 범위 밖이거나 정수가 아니면 종료하므로 `||`를 씁니다. 정상 입력이면 아래로 넘어가 `num1 * num2`를 반환합니다.
- 범위 검사는 `0 <= num1 && num1 <= 100`처럼 씁니다. `0 <= num1 <= 100`은 JavaScript에서 왼쪽 비교 결과를 다시 100과 비교하므로 잘못된 표현입니다.
- 화살표 함수의 `=> 표현식`은 결과를 자동 반환합니다. `{}`를 쓰면 `return`이 필요합니다.
- 반복 덧셈은 `num1`을 `num2`번 더합니다. 직접 곱셈은 `O(1)`, 반복 덧셈은 `O(num2)`이고 추가 공간은 모두 `O(1)`입니다.
- 이 문제는 `0`과 `100`을 포함한 정수 입력을 보장합니다. 입력 검사는 연습용이며 실제 제출은 `return num1 * num2;`면 충분합니다.
