# 02. 두 수의 나눗셈

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/120806?language=javascript)

## 문제 설명

정수 `num1`과 `num2`가 매개변수로 주어질 때, `num1`을 `num2`로 나눈 값에 1,000을 곱한 후 정수 부분을 return 하도록 solution 함수를 완성해주세요.

## 제한사항

- 0 < `num1` ≤ 100
- 0 < `num2` ≤ 100

## 입출력 예

| num1 | num2 | result |
| --- | --- | --- |
| 3 | 2 | 1500 |
| 7 | 3 | 2333 |
| 1 | 16 | 62 |

## 입출력 예 설명

- 예제 #1: num1이 3, num2가 2이므로 3 / 2 = 1.5에 1,000을 곱하면 1500이 됩니다.
- 예제 #2: num1이 7, num2가 3이므로 7 / 3 = 2.33333…에 1,000을 곱하면 2333.3333…이 되며, 정수 부분은 2333입니다.
- 예제 #3: num1이 1, num2가 16이므로 1 / 16 = 0.0625에 1,000을 곱하면 62.5가 되며, 정수 부분은 62입니다.

## 문제 코드

```javascript
function solution(num1, num2) {
  var answer = 0;
  return answer;
}
```

## 내가 푼 답

```javascript
function solution(num1, num2) {
  return Math.trunc(num1 / num2 * 1000);
}
```

- 나누기 → 1000 곱하기 → 소수 부분 버리기 순서입니다. `1 / 16 * 1000 = 62.5` → 62 반환.
- **시간 복잡도 `O(1)`**: 입력 크기와 관계없이 정해진 횟수만 계산합니다. **추가 공간 복잡도 `O(1)`**: 숫자 계산만 하고 배열 등을 만들지 않습니다. 이 문제의 숫자 범위 기준입니다.

## 다른 방법

### (1) Math.floor — 양수이므로 내림도 가능

```javascript
function solution(num1, num2) {
  return Math.floor((num1 / num2) * 1000);
}
```

- 이 문제에서는 나눈 값이 양수라 내림과 소수 부분 버림의 결과가 같습니다. 음수에서는 다를 수 있습니다.
- 시간 `O(1)`, 추가 공간 `O(1)`.

---

### (2) 화살표 함수 — 같은 풀이를 한 줄로

```javascript
const solution = (num1, num2) => Math.trunc(num1 / num2 * 1000);
```

- 중괄호 없는 화살표 함수는 표현식의 값을 자동 반환합니다. 한 줄이라고 계산이 더 빨라지는 것은 아닙니다.
- 시간 `O(1)`, 추가 공간 `O(1)`.

---

### (3) 계산 결과를 변수에 저장 — 순서 확인용

```javascript
function solution(num1, num2) {
  const scaled = (num1 / num2) * 1000;
  const answer = Math.trunc(scaled);
  return answer;
}
```

- scaled에 1000배한 값을 담고, 소수 부분을 버린 결과를 answer에 저장합니다.
- 시간 `O(1)`, 추가 공간 `O(1)`. 숫자 변수가 두 개 늘어도 고정 개수라 O(1)입니다.

---

## 정리

### 올림·반올림·내림·버림

- `Math.ceil(값)` : 값 이상인 가장 작은 정수로 올립니다. `Math.ceil(3.2)` → 4.
- `Math.round(값)` : 가장 가까운 정수로 반올림합니다. `Math.round(3.4)` → 3, `Math.round(3.5)` → 4.
- `Math.floor(값)` : 값 이하인 가장 큰 정수로 내립니다. `Math.floor(3.9)` → 3.
- `Math.trunc(값)` : 소수 부분을 버립니다. `Math.trunc(3.9)` → 3.
- 내림과 버림은 음수에서 다릅니다. `Math.floor(-3.7)` → -4, `Math.trunc(-3.7)` → -3.
- JavaScript 반올림은 정확히 중간이면 더 큰 정수 쪽입니다. `Math.round(-3.5)` → -3. 음수에서도 무조건 절댓값을 올리는 것은 아닙니다.
- 위 함수들은 자릿수를 지정하는 두 번째 인자를 사용하지 않습니다. `Math.floor(값, 0)`의 0은 무시됩니다. SQL의 `ROUND(값, 0)`과 다릅니다.

### 이 문제에서 주의할 점

- `/`는 나눗셈, `*`는 곱셈입니다. 우선순위가 같아 `num1 / num2 * 1000`은 왼쪽부터 계산합니다.
- 정수 부분을 구하는 것이므로 반올림·올림이 아닙니다. 62.5는 63이 아니라 62가 되어야 합니다.
- `Math.trunc(num1 / num2) * 1000`처럼 먼저 소수를 버리면 틀립니다. 1/16을 먼저 버리면 0이 되어 결과도 0입니다.
- 입력 num2는 1 이상이므로 문제에서는 0으로 나누는 경우를 처리할 필요가 없습니다.
- `Math`는 JavaScript가 제공하는 수학 기능 모음 객체이고, trunc·floor 등은 그 객체의 메서드입니다. `Math`의 M은 대문자입니다.
- `parseInt()`는 문자열을 정수로 해석하는 함수입니다. 숫자의 소수를 버리는 목적에는 `Math.trunc()`가 더 명확합니다.
- `~~값`, `값 | 0` 같은 비트 연산도 이 문제 범위에서는 활용할 수 있지만 32비트 정수 변환이라는 제약이 있어 기본 풀이로 권장하지 않습니다.
- **추천은 네 Math.trunc 풀이**입니다. 문제에서 요구한 ‘정수 부분’이라는 뜻을 가장 직접적으로 표현합니다.
