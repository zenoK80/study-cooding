# 03. 숫자 비교하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/120807?language=javascript)

## 문제 설명

정수 `num1`과 `num2`가 매개변수로 주어집니다. 두 수가 같으면 1, 다르면 -1을 return 하도록 solution 함수를 완성해주세요.

## 제한사항

- 0 ≤ `num1` ≤ 10,000
- 0 ≤ `num2` ≤ 10,000

## 입출력 예

| num1 | num2 | result |
| --- | --- | --- |
| 2 | 3 | -1 |
| 11 | 11 | 1 |
| 7 | 99 | -1 |

## 입출력 예 설명

- 예제 #1: num1이 2이고 num2가 3이므로 다릅니다. 따라서 -1을 return 합니다.
- 예제 #2: num1이 11이고 num2가 11이므로 같습니다. 따라서 1을 return 합니다.
- 예제 #3: num1이 7이고 num2가 99이므로 다릅니다. 따라서 -1을 return 합니다.

## 문제 코드

```javascript
function solution(num1, num2) {
  var answer = 0;
  return answer;
}
```

## 내가 푼 답

```javascript
const solution = (num1, num2) => {
  return num1 === num2 ? 1 : -1;
};
```

- 시간 `O(1)`: 비교 한 번. 추가 공간 `O(1)`: 숫자 하나를 반환합니다.

## 다른 방법

### (1) 화살표 함수의 자동 반환

```javascript
const solution = (num1, num2) => num1 === num2 ? 1 : -1;
```

### (2) if로 풀어 쓰기

```javascript
function solution(num1, num2) {
  if (num1 === num2) return 1;
  return -1;
}
```

### (3) 두 수의 차이로 비교 — 처음 작성한 방법

```javascript
const solution = (num1, num2) => {
  return num1 - num2 === 0 ? 1 : -1;
};
```

- 이 문제의 정수 범위에서는 모두 정답입니다. 직접 ===로 비교하는 편이 의도가 명확합니다. 모두 시간 `O(1)`, 추가 공간 `O(1)`입니다.

## 정리

- `===`: 자료형을 자동 변환하지 않고 같은지 비교합니다. 결과는 true 또는 false입니다.
- `==`: 자료형이 다르면 변환해서 비교할 수 있습니다. `3 == '3'`은 true, `3 === '3'`은 false입니다.
- `=`: 대입입니다. 비교가 아닙니다.
- `조건 ? 참일때값 : 거짓일때값`: 삼항 연산자. 같으면 1, 다르면 -1을 선택합니다.
- `return num1 === num2`만 쓰면 true/false를 반환하므로 요구한 1/-1과 다릅니다.
- `=> 표현식`은 자동 반환합니다. `=> { ... }`에서는 return을 직접 써야 합니다.
- if에서 1을 반환하면 함수가 끝납니다. 다를 때만 아래 return -1을 실행합니다.
- 입력 숫자가 커져도 그 숫자만큼 반복하지 않습니다. 이 문제의 수 범위에서는 비교 한 번 → 시간 `O(1)`입니다.
