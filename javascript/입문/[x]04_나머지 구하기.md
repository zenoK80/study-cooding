# 04. 나머지 구하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/120810?language=javascript)

## 문제 설명

정수 `num1`, `num2`가 매개변수로 주어질 때, `num1`을 `num2`로 나눈 나머지를 return 하도록 solution 함수를 완성해주세요.

## 제한사항

- 0 < `num1` ≤ 100
- 0 < `num2` ≤ 100

## 입출력 예

| num1 | num2 | result |
| --- | --- | --- |
| 3 | 2 | 1 |
| 10 | 5 | 0 |

## 입출력 예 설명

- 예제 #1: num1이 3, num2가 2이므로 3을 2로 나눈 나머지 1을 return 합니다.
- 예제 #2: num1이 10, num2가 5이므로 10을 5로 나눈 나머지 0을 return 합니다.

## 문제 코드

```javascript
function solution(num1, num2) {
  var answer = 0;
  return answer;
}
```

## 내가 푼 답

```javascript
const solution = (num1, num2) => {
  return num1 % num2;
};
```

- 시간 `O(1)`: 나머지 계산 한 번. 추가 공간 `O(1)`: 숫자 하나 반환. 이 문제의 숫자 범위 기준입니다.

## 다른 방법

### (1) 화살표 함수의 자동 반환

```javascript
const solution = (num1, num2) => num1 % num2;
```

- 네 코드에서 중괄호와 return을 함께 생략한 것입니다. 계산 결과는 같고, 한 줄이라 더 빠른 것은 아닙니다.

### (2) 일반 함수 선언

```javascript
function solution(num1, num2) {
  return num1 % num2;
}
```

### (3) 정수 몫으로 계산 — 원리 연습용

```javascript
function solution(num1, num2) {
  const quotient = Math.trunc(num1 / num2);
  return num1 - quotient * num2;
}
```

- 나머지 = 나누어지는 수 − 정수 몫 × 나누는 수. `7 - 2 * 3 = 1`입니다.
- 모두 시간 `O(1)`, 추가 공간 `O(1)`입니다. 이 문제의 작은 양의 정수 범위에서 동작하며 직접 %를 쓰는 네 답을 추천합니다.

## 정리

### 나머지와 반환

- `%`: 나눈 나머지. `3 % 2` → 1, `10 % 5` → 0입니다. 백분율을 계산하는 기호가 아닙니다.
- `/`: 나눈 값. `7 / 3` → 약 2.333…, `7 % 3` → 1입니다.
- `=> 표현식`: 결과를 자동 반환합니다. `=> {return 표현식;}`과 이 문제에서는 같은 동작입니다.
- `=> {num1 % num2;}`는 return이 없어 계산만 하고 undefined를 반환합니다.
- 일반 함수와 화살표 함수는 this 등의 차이가 있지만, 이 문제처럼 매개변수로 계산만 하면 결과는 같습니다.

### pass는 무엇인가?

```javascript
// 참고한 코드: pass는 JavaScript의 기본 기능이 아님
function solution(num1, num2) {
  if (num2 === 0) {
    pass;
  } else {
    return num1 % num2;
  }
}
```

- Python의 pass는 아무 작업도 하지 않는 문법입니다. JavaScript에는 pass 키워드가 없습니다.
- JavaScript의 `pass;`는 pass라는 변수를 읽는 문장입니다. 선언하지 않았다면 해당 줄이 실행될 때 ReferenceError가 납니다. Pass도 기본 제공되지 않습니다.
- 이 문제는 num2가 1~100이라 pass 줄이 실행되지 않습니다. 코드가 통과해도 pass가 올바른 기능이라는 뜻은 아닙니다.
- Number의 `num1 % 0`은 NaN입니다. 이 문제에서는 0이 주어지지 않으므로 분기 없이 네 답처럼 작성하면 됩니다.
- `return;`은 함수 종료, `continue`는 이번 반복 건너뛰기, `break`는 반복문 또는 switch 종료입니다. 서로 다른 동작입니다.
