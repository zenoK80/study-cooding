# 04. 연산자

## 산술 연산자

숫자를 계산할 때 사용한다.

```js
const a = 10;
const b = 3;

// console.log(a + b); 13
// console.log(a - b); 7
// console.log(a * b); 30
// console.log(a / b); 3.333...
// console.log(a % b); 1
```

* `+` : 더하기
* `-` : 빼기
* `*` : 곱하기
* `/` : 나누기
* `%` : 나머지

---

## 나머지 연산자

짝수, 홀수 판별에 자주 사용한다.

```js
const number = 7;

// console.log(number % 2); 1
```

```text
짝수 → number % 2 === 0
홀수 → number % 2 !== 0
```

---

## 비교 연산자

두 값을 비교하면 `true`, `false`가 나온다.

```js
const a = 10;
const b = 20;

// console.log(a > b); false
// console.log(a < b); true
// console.log(a >= 10); true
// console.log(a <= 5); false
```

---

## === / !==

두 값이 같은지 확인한다.

```js
const a = 10;

// console.log(a === 10); true
// console.log(a !== 10); false
```

`==`보다 `===`를 사용하는 것이 좋다.

```js
// console.log(10 == "10"); true
// console.log(10 === "10"); false
```

* `==` : 값만 비교
* `===` : 값과 자료형까지 비교

---

## 논리 연산자

```js
const age = 20;
const hasTicket = true;

// console.log(age >= 18 && hasTicket); true
// console.log(age < 18 || hasTicket); true
// console.log(!hasTicket); false
```

* `&&` : 둘 다 참이면 `true`
* `||` : 하나라도 참이면 `true`
* `!` : 참/거짓 반대로 변경

---

## 증가 / 감소

```js
let count = 0;

count++;
count++;

// console.log(count); 2

count--;

// console.log(count); 1
```

* `++` : 1 증가
* `--` : 1 감소

---

## 복합 대입 연산자

```js
let number = 10;

number += 5;
// console.log(number); 15

number -= 3;
// console.log(number); 12

number *= 2;
// console.log(number); 24
```

```text
a += 5 → a = a + 5
a -= 5 → a = a - 5
a *= 5 → a = a * 5
```

---

## 삼항 연산자

조건에 따라 값을 선택한다.

```js
const age = 20;

const result = age >= 18 ? "성인" : "미성년자";

// console.log(result); 성인
```

형태:

```js
조건 ? 참일 때 값 : 거짓일 때 값
```

---

## 핵심

```text
+ - * / %   → 계산
=== !==     → 같은지 비교
> < >= <=   → 크기 비교
&& || !     → 논리 연산
++ --       → 1 증가 / 감소
+= -= *=    → 계산 후 저장
? :         → 조건에 따라 값 선택
```
