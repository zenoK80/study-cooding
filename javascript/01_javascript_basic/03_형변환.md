# 03. 형변환

## Number로 변환
- 문자열을 숫자로 바꾼다.

```js
const value = "123";
const number = Number(value);

// console.log(number); 123
// console.log(typeof number); number
```
- `Number("123)` -> `123`
- 숫자로 바꿀 수 없으면 `NaN`이 된다.
```js
const value = Number("abc");
// console.log(value); Nan
```

---

## String으로 변환
- 값을 문자열로 바꾼다.
```js
const number = 123;
const text = String(number);
// console.log(text); "123"
// console.log(typeof text); string
```

---

## Boolean으로 변환
값을 `true`, `false`로 바꾼다.
```js
Boolean(1) // true
Boolean(0) // false
Boolean("hello") // true
Boolean("") // false
```
### 대표적인 falsy 값:
```text
false
0
""
null
undefined
NaN
```

---

## parseInt
- 문자열을 정수로 변환한다.
```js
const value = "123";
const number = parseInt(value);
// console.log(number); 123
```
- 소수점은 버린다.
```js
const number = parseFloat("12.7");
```

---

## parseFloat

- 문자열을 실수로 변환한다.

```js
const number = parseFloat("12.7");

// console.log(number); 12.7
```

---

## 숫자 ↔ 문자열

자주 쓰는 변환이다.

```js
const number = 123;

const text = String(number);
const back = Number(text);

// console.log(text); "123"
// console.log(back); 123
```

---

## 배열의 문자열 숫자 변환

```js
const input = ["1", "2", "3"];

const numbers = input.map(Number);

// console.log(numbers); [1, 2, 3]
```

---

## 핵심

```text
Number()     → 숫자로 변환
String()     → 문자열로 변환
Boolean()    → true / false로 변환
parseInt()   → 정수로 변환
parseFloat() → 실수로 변환
```
