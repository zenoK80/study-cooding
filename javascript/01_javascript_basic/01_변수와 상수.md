# 변수와 상수
## `let`
- 갚이 바뀔 수 있는 변수에 사용
- let: 값을 다시 대입할 수 있다.
- 점수, 합계, 카운트처럼 값이 변할 때 사용한다.

---

## `const`
- 값을 다시 대입하지 않을 변수에 사용
- const: 새로운 값을 다시 대입할 수 없다.
- 기본적으로 const를 사용하고, 값이 바뀔 때만 let을 쓰면 된다.

---

## 값 누적하기
```js
let total = 0;

total += 10;
total += 20;
// console.log(total); 30
```
- total += 10: 기존 값에 10을 더한다.
- 합계나 정답을 계속 갱신할 때 사용한다.

---

## const 배열

- const 배열도 내부 값은 변경할 수 있다.
```js
const numbers = [1, 2, 3];

numbers.push(4);

// console.log(numbers); [1, 2, 3, 4]
```

---

## 하지만 배열 자체를 새 배열로 바꾸는 것은 안 된다.

```js
const numbers = [1, 2, 3];

// numbers = [4, 5, 6]; // Error
const numbers = [1, 2, 3];

let answer = 0;

for (const number of numbers) {
  answer += number;
}
// console.log(answer); 6
```

- numbers: 바뀌지 않음 → const
- number: 반복할 때마다 새 값을 받음 → const
- answer: 계속 값이 바뀜 → let

---

## 핵심
- 값이 안 바뀜 → const
- 값이 바뀜 → let
- var → 거의 사용하지 않음
