# 02.자료형
## Number
- 숫자를 저장한다.
```js
const age = 20; const price = 1500; const temperature = -3.5;
```
- 정수와 소수를 모두 Number로 사용한다.
- JavaScript는 정수형과 실수형을 따로 나누지 않는다.

---

## String
- 문자열을 저장한다.
```js
const name ="Javascript";
const message = 'Hello';
```
- `""` 또는 `''`로 감싼다.

---

## Boolean
- 참과 거짓을 저장한다.
```js
const isAdult = true;
const isEmpty = false;
```
- 값은 `true`, `false` 두 개 뿐이다.

---

## null
- 값이 없음을 직접 표현할 때 사용한다.
```js
const result = null;
```
- 개발자가 직접 "값 없음"을 넣은 상태

---

## undefined
- 값이 아직 정해지지 않은 상태
```js
let value;

```
- 변수를 선언하고 값을 넣지 않으면 undefined가 된다.

---

## Array
- 여러 값을 순서대로 저장한다.
```js
const numbers = [10, 20, 30];
// console.log(numbers[0]); 10
// console.log(numbers[1]); 20
```
- 배열의 위치는 0부터 시작한다.

---

## Object
- 여러 값을 이름과 함께 저장한다.
```js
const user = {
	name: "Kim",
	age: 20
}
// console.log(user.name); Kim
 // console.log(user.age); 20
```
- key: value 형태로 값을 저장한다.

---

## typeof
- 값의 자료형을 확인한다.
```js
const number = 10;
const text = "hello";
const check = true;

// console.log(typeof number); number
// console.log(typeof text); string
// console.log(typeof check); boolean
```
---

## 핵심
- 10          → Number
- "hello"     → String
- true        → Boolean
- null        → null
- undefined   → undefined
- [1, 2, 3]   → Array
- { a: 1 }    → Object
