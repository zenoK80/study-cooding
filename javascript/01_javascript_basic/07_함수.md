# 07. 함수

## 함수 만들기

반복해서 사용할 코드를 하나로 묶는다.

```js
function sayHello() {
  console.log("Hello");
}

sayHello();

// Hello
```

* `function`: 함수를 정의한다.
* `sayHello`: 함수 이름.
* `sayHello()`: 함수를 실행한다.

---

## 함수에 값 전달하기

함수는 값을 받아서 사용할 수 있다.

```js
function printNumber(number) {
  console.log(number);
}

printNumber(10);

// 10
```

* `number`: 매개변수.
* `10`: 함수에 전달한 값.

---

## 함수에 여러 값 전달하기

```js
function addNumbers(firstNumber, secondNumber) {
  const total = firstNumber + secondNumber;

  console.log(total);
}

addNumbers(3, 4);

// 7
```

* `firstNumber`, `secondNumber`: 받은 값을 저장한다.

---

## 결과 돌려받기

`return`으로 함수의 결과를 돌려준다.

```js
function addNumbers(firstNumber, secondNumber) {
  const total = firstNumber + secondNumber;

  return total;
}

const answer = addNumbers(3, 4);

// console.log(answer); 7
```

* `return`: 함수의 결과를 돌려준다.
* 반환된 값은 변수에 저장할 수 있다.

---

## return을 만나면 함수 종료

```js
function checkNumber(number) {
  if (number < 0) {
    return;
  }

  console.log(number);
}

checkNumber(-1);
checkNumber(5);

// 5
```

* `return`을 만나면 그 함수는 즉시 끝난다.

---

## 함수에서 조건 처리하기

```js
function isEven(number) {
  if (number % 2 === 0) {
    return true;
  }

  return false;
}

// console.log(isEven(4)); true
// console.log(isEven(7)); false
```

---

## 화살표 함수

함수를 짧게 작성할 수 있다.

```js
const addNumbers = (a, b) => {
  return a + b;
};

// console.log(addNumbers(3, 4)); 7
```

한 줄이면 더 줄일 수 있다.

```js
const addNumbers = (a, b) => a + b;

// console.log(addNumbers(3, 4)); 7
```

---

## 핵심

```text
function
→ 함수 정의

매개변수
→ 함수가 받은 값을 저장

return
→ 결과 반환

함수()
→ 함수 실행
```
