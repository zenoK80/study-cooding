# 09. 구조 분해 할당

## 배열 구조 분해

배열의 값을 변수에 바로 나눠 담을 수 있다.

```js
const numbers = [10, 20];

const [first, second] = numbers;

// console.log(first); 10
// console.log(second); 20
```

* 배열의 순서대로 값이 들어간다.

---

## 일부 값만 받기

```js
const numbers = [10, 20, 30];

const [first, , third] = numbers;

// console.log(first); 10
// console.log(third); 30
```

* 필요 없는 값은 비워둘 수 있다.

---

## 변수 값 교환하기

```js
let a = 10;
let b = 20;

[a, b] = [b, a];

// console.log(a); 20
// console.log(b); 10
```

---

## 객체 구조 분해

객체의 값을 변수로 바로 꺼낼 수 있다.

```js
const user = {
  name: "Kim",
  age: 20
};

const { name, age } = user;

// console.log(name); Kim
// console.log(age); 20
```

* 객체는 `key` 이름과 같은 변수에 값이 들어간다.

---

## 변수 이름 바꾸기

```js
const user = {
  name: "Kim"
};

const { name: userName } = user;

// console.log(userName); Kim
```

---

## 함수에서 구조 분해

```js
function printPoint([x, y]) {
  console.log(x, y);
}

printPoint([3, 5]);

// 3 5
```

배열의 값을 바로 나눠 받을 수 있다.

---

## 핵심

```text
배열
const [a, b] = array;

객체
const { a, b } = object;

값 교환
[a, b] = [b, a];
```
