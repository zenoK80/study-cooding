# 01. 문자 리스트를 문자열로 변환하기

[프로그래머스 문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181941?language=javascript)

## 문제 설명

문자들이 담겨있는 배열 `arr`가 주어집니다. `arr`의 원소들을 순서대로 이어 붙인 문자열을 return 하는 `solution` 함수를 작성해 주세요.

## 제한사항

- 1 ≤ `arr`의 길이 ≤ 200
- `arr`의 원소는 전부 알파벳 소문자로 이루어진 길이가 1인 문자열입니다.

## 입출력 예

| arr | result |
|---|---|
| `["a", "b", "c"]` | `"abc"` |

## 문제

```javascript
function solution(arr) {
  var answer = '';
  return answer;
}
```

## 답

### 1. 기본 `for`문
```javascript
function solution(arr) {
  let answer = '';
  for (let i = 0; i < arr.length; i++) {answer += arr[i];}
  return answer;
}
```

---

### 2. `join()`
```javascript
function solution(arr) {
  return arr.join('');
}
```

---

### 3. `forEach()`
```javascript
function solution(arr) {
  let answer = '';
  arr.forEach((str) => {answer += str;});
  return answer;
}
```
---

### 4. `for...of`
```javascript
function solution(arr) {
  let answer = '';
  for (const str of arr) {answer += str;}
  return answer;
}
```

---

### 5. 화살표 함수와 `join()`
```javascript
const solution = (arr) => arr.join('');
```
---

### 6. `join()` 결과를 변수에 저장
```javascript
function solution(arr) {
  let answer = arr.join('');
  return answer;
}
```

---

## 정리

- `for`: 초기식, 조건식, 증감식을 지정해 반복합니다. 인덱스가 필요할 때 사용합니다.
- `join('')`: 배열의 원소 사이에 아무것도 넣지 않고 하나의 문자열로 합칩니다. 원본 배열은 바뀌지 않습니다.
- `forEach()`: 배열의 원소마다 콜백 함수를 실행합니다. `break`와 `continue`로 중간 종료할 수 없습니다.
- `for...of`: 배열, 문자열, `Map`, `Set` 같은 iterable의 **값**을 순회합니다. 일반 객체에는 바로 사용할 수 없습니다.
- `for...in`: 상속된 것을 포함한 열거 가능한 문자열 **키**를 순회합니다. 배열에서는 추가 속성도 포함될 수 있어 값 순회에는 `for...of`가 적합합니다.
- `for...of`는 값, `for...in`은 키를 가져온다는 차이가 있습니다.
- 객체를 값으로 순회하려면 `Object.values(obj)`, 키와 값을 함께 순회하려면 `Object.entries(obj)`를 `for...of`와 사용합니다.
- 화살표 함수는 반환식이 하나면 `{}`와 `return`을 생략할 수 있습니다. 단, 자신만의 `this`를 만들지 않습니다.
- `let`은 재할당할 값, `const`는 재할당하지 않을 값에 사용합니다. 현대 JavaScript에서는 `var`보다 `let`, `const`를 주로 사용합니다.
- 이 문제에는 목적이 가장 분명하고 코드가 짧은 `arr.join('')`이 가장 적합합니다.
