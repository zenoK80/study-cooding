# 02. 특정한 문자를 대문자로 바꾸기

[프로그래머스 문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181873?language=javascript)

## 문제 설명

영소문자로 이루어진 문자열 `my_string`과 영소문자 1글자로 이루어진 문자열 `alp`가 주어질 때, `my_string`에서 `alp`에 해당하는 모든 글자를 대문자로 바꾼 문자열을 return 하는 `solution` 함수를 작성해 주세요.

## 제한사항

- 1 ≤ `my_string`의 길이 ≤ 1,000

## 입출력 예

| my_string | alp | result |
|---|---|---|
| `"programmers"` | `"p"` | `"Programmers"` |
| `"lowercase"` | `"x"` | `"lowercase"` |

## 입출력 예 설명

- `"programmers"`의 모든 `p`를 `P`로 바꾸면 `"Programmers"`입니다.
- `"lowercase"`에는 `x`가 없으므로 원래 문자열을 return 합니다.

## 문제

```javascript
function solution(my_string, alp) {
  var answer = '';
  return answer;
}
```

---

## 풀이
### (1) `for...of`와 삼항 연산자 사용
```javascript
function solution(my_string, alp){
  let answer = '';
  for (const str of my_string) { answer += str === alp ? str.toUpperCase() : str;}
  return answer;
}
```
---
### (2) 전개 구문과 `map()` 사용
```javascript
function solution(my_string,alp){
  return [...my_string].map((str)=> str === alp ? str.toUpperCase() : str).join('');
}
```
---
### (3) `replaceAll()` 사용 — 추천
```javascript
function solution(my_string, alp) {
  return my_string.replaceAll(alp, alp.toUpperCase());
}
```

---

### (4) `split()`과 `join()` 사용
```javascript
function solution(my_string, alp) {
  return my_string.split(alp).join(alp.toUpperCase());
}
```

---

### (5) 정규식과 `replace()` 사용
```javascript
function solution(my_string, alp) {
  const regexp = new RegExp(alp, 'g');
  return my_string.replace(regexp, alp.toUpperCase());
}
```

---

## 정리
- `for...of`: 배열·문자열·`Set`·`Map` 같은 iterable의 **값**을 순회합니다. 일반 객체에는 바로 사용할 수 없습니다.
- iterable: 값을 하나씩 순서대로 꺼낼 수 있는 객체입니다. 문자열, 배열, `Set`, `Map`, `arguments`, `NodeList` 등이 있습니다.
- `[...값]`: iterable을 펼쳐 배열로 만듭니다. `[...'abc']`의 결과는 `['a', 'b', 'c']`입니다.
- `{...객체}`: 일반 객체의 속성을 다른 객체 안에 펼칩니다. 일반 객체는 `[...객체]`로 펼칠 수 없습니다.
- `for...in`: 상속된 것을 포함한 열거 가능한 문자열 키를 순회합니다. `Object.keys()`·`values()`·`entries()`는 객체 자신의 열거 가능한 문자열 키에 해당하는 항목만 배열로 반환합니다.
- `toUpperCase()`: 문자열을 대문자로 바꾼 새 문자열을 반환합니다. `'abc'.toUpperCase()`의 결과는 `'ABC'`입니다.
- `replaceAll(찾을값, 바꿀값)`: 일치하는 모든 부분을 교체한 새 문자열을 반환합니다. 이 문제에 가장 적합합니다.
- `replace('p', 'P')`는 첫 번째 일치만 바꿉니다. `replace(/p/g, 'P')`는 모두 바꿉니다.
- `split(구분자)`: 문자열을 구분자로 잘라 배열로 반환합니다. `'apple'.split('p')`의 결과는 `['a', '', 'le']`입니다.
- `join(구분자)`: 배열 원소 사이에 구분자를 넣어 문자열로 합칩니다. `['a', '', 'le'].join('P')`의 결과는 `'aPPle'`입니다.
- `new RegExp(패턴, 'g')`: 문자열 전체에서 패턴을 찾는 정규식을 만듭니다. `replace(정규식, 바꿀값)`으로 모두 교체할 수 있습니다.
- `map()`: 배열의 각 원소를 변환해 새 배열을 반환합니다. 문자열에는 없으므로 먼저 `[...문자열]`로 배열을 만듭니다.
- `filter()`: 조건에 맞는 배열 원소만 남깁니다. 문자를 바꾸는 이 문제에는 적합하지 않습니다.
