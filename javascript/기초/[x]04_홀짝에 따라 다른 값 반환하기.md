# 04. 홀짝에 따라 다른 값 반환하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181935?language=javascript)

## 문제 설명

양의 정수 `n`이 매개변수로 주어질 때, `n`이 홀수라면 `n` 이하의 홀수인 모든 양의 정수의 합을 return 하고 `n`이 짝수라면 `n` 이하의 짝수인 모든 양의 정수의 제곱의 합을 return 하는 solution 함수를 작성해 주세요.

## 제한사항

- 1 ≤ `n` ≤ 100

## 입출력 예

| n | result |
| --- | --- |
| 7 | 16 |
| 10 | 220 |

## 입출력 예 설명

- 예제 #1: n은 7로 홀수입니다. 7 이하의 모든 양의 홀수는 1, 3, 5, 7이고 이들의 합인 1 + 3 + 5 + 7 = 16을 return 합니다.
- 예제 #2: n은 10으로 짝수입니다. 10 이하의 모든 양의 짝수는 2, 4, 6, 8, 10이고 이들의 제곱의 합인 2² + 4² + 6² + 8² + 10² = 4 + 16 + 36 + 64 + 100 = 220을 return 합니다.

## 문제 코드

```javascript
function solution(n) {
  var answer = 0;
  return answer;
}
```

## 내가 푼 답
```javascript
function solution(n) {
    if(n < 1 || n > 100) return;
    var answer = 0;

    if(n % 2 === 1) {
        for(let i = 0; i <= n; i++){
            if(i % 2 === 0) continue;
            answer += i;
        }
    }

    if(n % 2 === 0) {
         for(let i = 0; i <= n; i++){
            if(i % 2 === 1) continue;
            answer += i**2;
        }
    }
    return answer;
}
```
- **시간 복잡도 `O(n)`**: 홀수·짝수 분기 중 하나만 실행합니다. i=0부터 n까지 총 n+1번 확인하므로 `O(n + 1) → O(n)`입니다. continue로 건너뛰어도 홀짝 확인은 수행합니다.
- **추가 공간 복잡도 `O(1)`**: answer와 반복 변수 i처럼 일정한 개수의 숫자만 유지합니다. n이 커져도 배열처럼 저장 항목을 늘리지 않습니다. 이 문제의 숫자 범위 기준입니다.

## 다른 방법

### (1) 2씩 증가하는 for문 — 추천

```javascript
function solution(n) {
  let answer = 0;
  if (n % 2 === 1) {
    for (let i = 1; i <= n; i += 2) {answer += i;}
  } else {
    for (let i = 2; i <= n; i += 2) {answer += i ** 2;}
  }
  return answer;
}
```

- 1, 3, 5… 또는 2, 4, 6…만 확인하므로 반복 안의 홀짝 검사와 continue가 필요 없습니다.
- 시간: 약 n/2번 반복 → `O(n)`. 추가 공간: `O(1)`. 내 답보다 반복은 적지만 빅오 표기는 같습니다.

---

### (2) 반복문 하나와 삼항 연산자

```javascript
function solution(n) {
  let answer = 0;
  const isEven = n % 2 === 0;
  for (let i = 1; i <= n; i++) {
    if (i % 2 === n % 2) {answer += isEven ? i ** 2 : i;}
  }
  return answer;
}
```

- i와 n의 나머지가 같으면 둘 다 홀수이거나 둘 다 짝수입니다. n이 짝수면 제곱해서, 홀수면 그대로 더합니다.
- 시간: n번 반복 → `O(n)`. 추가 공간: `O(1)`.

---

### (3) Array.from + filter + reduce — 배열 메서드 연습

```javascript
function solution(n) {
  const isEven = n % 2 === 0;
  const numbers = Array.from({length: n}, (_, i) => i + 1);
  const selected = numbers.filter(value => value % 2 === n % 2);
  return selected.reduce((sum, value) => sum + (isEven ? value ** 2 : value), 0);
}
```

- n=7이면 numbers는 `[1, 2, 3, 4, 5, 6, 7]`, selected는 `[1, 3, 5, 7]`, 누적 결과는 16입니다.
- 시간: 생성 n번 + 필터 n번 + 누적 약 n/2번 → `O(n)`. 추가 공간: 배열 두 개 → `O(n)`.

---

### (4) 홀수 합과 짝수 제곱 합을 모두 구하기

```javascript
function solution(n) {
  let oddSum = 0;
  let evenSum = 0;
  for (let i = n; i > 0; i--) {
    if (i % 2 === 0) {evenSum += Math.pow(i, 2);}
    else {oddSum += i;}
  }
  return n % 2 === 0 ? evenSum : oddSum;
}
```

- n부터 1까지 내려가며 두 합을 따로 저장하고 필요한 합을 반환합니다. 사용하지 않을 합도 계산합니다.
- 시간: n번 반복 → `O(n)`. 추가 공간: 합계 변수 두 개 → `O(1)`.

---

### (5) 수학 공식 — 반복 없이 계산

```javascript
function solution(n) {
  if (n % 2 === 1) return ((n + 1) / 2) ** 2;
  return n * (n + 1) * (n + 2) / 6;
}
```

- 홀수: 처음 m개 홀수의 합은 `m²`입니다. n 이하 홀수는 `(n + 1) / 2`개이므로 그 개수를 제곱합니다. n=7 → 4개 → `4² = 16`.
- 짝수: n=2m일 때 `2² + 4² + … + (2m)² = 4 × (1² + 2² + … + m²)`입니다.
- 제곱합 공식 `1² + … + m² = m(m + 1)(2m + 1) / 6`에 m=n/2를 넣어 정리하면 `n(n + 1)(n + 2) / 6`입니다. n=10 → `10 × 11 × 12 / 6 = 220`.
- 시간: 정해진 횟수의 계산 → `O(1)`. 추가 공간: `O(1)`. 이 문제의 수 범위에서 계산하는 기준입니다.

---

## 정리

### 내 풀이와 실수

- 내 답은 맞습니다. 홀수 분기에서는 짝수를, 짝수 분기에서는 홀수를 continue로 건너뜁니다.
- 두 if 중 하나만 실행하며 0~n을 확인하므로 시간은 `O(n)`, 추가 공간은 `O(1)`입니다.
- `continue`는 이번 반복만 건너뛰지만 `return`은 함수 전체를 끝냅니다. 홀수 분기에서 i=0일 때 return하면 합계 계산 전에 종료됩니다.
- `i <= n`은 n까지 포함합니다. `< =`처럼 띄우면 오류입니다.
- i=0부터 시작해도 홀수 분기에서는 건너뛰고 짝수 분기에서는 0을 더하므로 결과에 영향이 없습니다.
- 입력 범위는 문제에서 보장하므로 검사 코드는 없어도 됩니다.

### 조건·반복·제곱

- `%` : 나눗셈의 나머지. 양의 정수에서 `n % 2 === 1`은 홀수, `n % 2 === 0`은 짝수입니다.
- `continue` : 이번 반복의 남은 부분을 건너뜁니다. 기본 for문에서는 증감식을 실행한 뒤 조건을 다시 확인합니다.
- `break` : 현재 반복문을 끝내고 반복문 다음으로 이동합니다.
- `return` : 현재 함수를 끝내고 값을 반환합니다. 값 없이 쓰면 undefined를 반환합니다.
- `i += 2` : `i = i + 2`와 같습니다. 홀수만 또는 짝수만 방문할 때 사용합니다.
- `answer += i` : `answer = answer + i`와 같습니다.
- `i ** 2`, `i * i`, `Math.pow(i, 2)` : 이 문제에서 모두 i의 제곱입니다. `i**`만 쓰면 지수가 없어 오류입니다.
- `if / else` : 조건이 참이면 if, 아니면 else를 실행합니다. 양의 정수는 홀수 또는 짝수라 두 번째 if 대신 else를 써도 됩니다.
- `조건 ? 참일때값 : 거짓일때값` : 삼항 연산자. `isEven ? i ** 2 : i`는 짝수 조건이면 제곱, 아니면 i를 선택합니다.

### 배열 메서드와 인덱스

- `Array.from({length: n}, (_, i) => i + 1)` : 길이가 n인 배열을 만들며 각 위치 i에 i+1을 넣습니다. n=3이면 `[1, 2, 3]`입니다.
- `_` : 사용하지 않는 현재 값을 받은 변수명일 뿐, 특별한 연산자가 아닙니다. i는 0부터 시작하는 인덱스입니다.
- `Array(n).fill().map((value, i) => i + 1)` : undefined로 각 자리를 채운 뒤 1~n 배열로 바꾸는 다른 표현입니다.
- `Array(n)`만 만들면 빈 슬롯이라 map·reduce가 건너뜁니다. `.fill()`로 실제 undefined 값을 채우면 콜백이 실행됩니다.
- `filter(조건함수)` : 조건이 참인 원소만 남긴 새 배열을 반환합니다.
- `reduce((누적값, 현재원소) => 다음누적값, 시작값)` : 원소를 순회하며 결과를 누적합니다. 합계의 시작값은 0입니다.
- `reduce((acc, value, i) => ..., 0)` : 콜백의 세 번째 인자는 인덱스입니다. 원문의 `(acc, _, i)`는 현재 값 대신 인덱스로 수를 계산한 방식입니다.
- `Math.ceil(n / 2)` : n/2를 올림합니다. n이 홀수면 n 이하 홀수의 개수, 짝수면 n 이하 짝수의 개수입니다.
- i=0,1,2…에서 `2 * i + 1`은 1,3,5…, `2 * (i + 1)`은 2,4,6…입니다. 원문의 길이 절반짜리 배열 풀이가 이 원리입니다.

### 어떤 답이 좋나?

- 추천은 (1) 2씩 증가하는 for문입니다. 필요한 수만 방문하고 과정이 명확합니다. 내 답도 충분히 유효합니다.
- 계산량이 가장 적은 것은 (5) 공식 풀이입니다. 다만 공식을 설명할 수 있어야 하므로, 지금은 (1)부터 이해하면 됩니다.
- (3)은 배열 메서드 연습용입니다. 단순 합계에는 배열 없이 풀 수도 있으므로 추가 공간을 비교해 봅니다.
- 입력별 정답 100개 나열은 각 값이 맞으면 동작하지만 오타·누락에 취약하고 범위 변경에 대응하기 어렵습니다. 긴 삼항식 전체를 복사하는 대신 풀이 원리를 익힙니다.
- n≤100이라 정답과 가독성이 우선입니다. 복잡도는 입력 범위를 확장한다고 생각하고 n에 따른 증가량으로 비교했습니다.
