# 06. 수 조작하기 1

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181926?language=javascript)

## 문제 설명

정수 `n`과 문자열 `control`이 주어집니다. `control`은 "w", "a", "s", "d"의 4개의 문자로 이루어져 있으며, `control`의 앞에서부터 순서대로 문자에 따라 `n`의 값을 바꿉니다.

- "w": `n`이 1 커집니다.
- "s": `n`이 1 작아집니다.
- "d": `n`이 10 커집니다.
- "a": `n`이 10 작아집니다.

위 규칙에 따라 `n`을 바꿨을 때 가장 마지막에 나오는 `n`의 값을 return 하는 solution 함수를 완성해 주세요.

## 제한사항

- -100,000 ≤ `n` ≤ 100,000
- 1 ≤ `control`의 길이 ≤ 100,000
  - `control`은 알파벳 소문자 "w", "a", "s", "d"로 이루어진 문자열입니다.

## 입출력 예

| n | control | result |
| --- | --- | --- |
| 0 | "wsdawsdassw" | -1 |

## 입출력 예 설명

- 예제 #1: 수 n은 control에 따라 다음과 같은 순서로 변하게 됩니다.
- 0 → 1 → 0 → 10 → 0 → 1 → 0 → 10 → 0 → -1 → -2 → -1
- 따라서 -1을 return 합니다.

## 문제 코드

```javascript
function solution(n, control) {
  var answer = 0;
  return answer;
}
```

## 내가 푼 답

```javascript
const solution = (n, control) => {
  for (const char of control) {
    if (char === 'w') n++;
    if (char === 's') n--;
    if (char === 'd') n += 10;
    if (char === 'a') n -= 10;
  }
  return n;
};
```

- 네 답은 맞습니다. return을 반복문 밖에 두어 모든 문자를 처리한 뒤 최종 n을 반환합니다.
- 아래에서 m은 control.length입니다. 입력 n은 시작 숫자라 시간 복잡도의 기준으로 사용하지 않습니다.
- **시간**: 문자 m개마다 조건 4개 확인 → `O(4m) = O(m)`. **추가 공간**: 숫자·문자 변수만 유지 → `O(1)`.

## 다른 방법

### (1) switch와 기본 for문 — 문자별 분기

```javascript
function solution(n, control) {
  for (let i = 0; i < control.length; i++) {
    switch (control[i]) {
      case 'w': n++; break;
      case 's': n--; break;
      case 'd': n += 10; break;
      case 'a': n -= 10; break;
    }
  }
  return n;
}
```

- switch로 현재 문자를 검사하고 해당 case를 실행합니다. break는 switch만 끝내며 바깥 for문은 계속됩니다.
- **시간**: m개 문자 처리 → `O(m)`. **추가 공간**: `O(1)`.

---

### (2) 객체와 for...of — 변화량 조회, 추천

```javascript
function solution(n, control) {
  const changes = {w: 1, s: -1, d: 10, a: -10};
  for (const char of control) {n += changes[char];}
  return n;
}
```

- char가 'd'이면 `changes[char]`는 `changes['d']`, 즉 10입니다. 네 개의 if 대신 문자별 변화량을 읽어 더합니다.
- **시간**: m번 조회·덧셈 → `O(m)`. **추가 공간**: 객체에 항상 4개 항목만 저장 → `O(1)`. 객체라고 무조건 O(m)은 아닙니다.

---

### (3) split과 forEach — 배열로 바꿔 순회

```javascript
function solution(n, control) {
  let answer = n;
  const changes = {w: 1, s: -1, d: 10, a: -10};
  control.split('').forEach(char => {answer += changes[char];});
  return answer;
}
```

- control을 문자 배열로 바꿔 하나씩 처리합니다. 시작 숫자가 있으므로 answer는 0이 아닌 n에서 시작합니다.
- **시간**: 분리 m개 + 순회 m개 → `O(m)`. **추가 공간**: 문자 배열 → `O(m)`.

---

### (4) 함수가 들어 있는 객체와 reduce — 함수 조회 후 실행

```javascript
const operations = {
  w: n => n + 1,
  s: n => n - 1,
  d: n => n + 10,
  a: n => n - 10,
};

function solution(n, control) {
  return [...control].reduce((prev, op) => operations[op](prev), n);
}
```

- operations의 값은 숫자가 아니라 함수입니다. op가 'd', prev가 5이면 `operations['d'](5)` → 15입니다.
- reduce의 시작값은 n, prev는 직전 계산 결과, op는 현재 문자입니다. 함수가 반환한 숫자가 다음 prev로 넘어갑니다.
- **시간**: 문자 배열 생성 + m번 함수 실행 → `O(m)`. **추가 공간**: 문자 배열 → `O(m)`. 함수 4개는 고정 공간입니다.

---

### (5) map과 reduce — 변화량 배열을 만들어 합산

```javascript
function solution(n, control) {
  const changes = {w: 1, s: -1, d: 10, a: -10};
  return [...control].map(char => changes[char]).reduce((sum, value) => sum + value, n);
}
```

- 예: control이 'wda'면 `['w', 'd', 'a']` → `[1, 10, -10]` → 시작값 n에 전부 더합니다.
- 이번 문제의 명령은 전부 고정된 숫자를 더하거나 빼므로 변화량 합산이 가능합니다. 모든 명령 문제가 이렇게 단순 합산되는 것은 아닙니다.
- **시간**: 문자 배열 생성 m + map m + reduce m → `O(m)`. **추가 공간**: 문자 배열과 변화량 배열 → `O(m)`.
- 원문의 setValue 함수·중첩 삼항식 대신 같은 규칙을 changes 객체로 표현했습니다. 삼항식의 마지막 -10은 a만 남는다는 입력 조건에 의존합니다.

---

## 정리

### 문자열과 반복

- 문자열은 iterable이므로 `for (const char of control)`로 바로 한 글자씩 꺼낼 수 있습니다. 이 문제는 배열 변환이 필요하지 않습니다.
- `[...control]`, `control.split('')` : 이 문제의 영문 문자 문자열을 문자 배열로 만듭니다. `'ws'` → `['w', 's']`.
- `slice(시작, 끝)` : 문자열 일부를 가져오며 결과도 문자열입니다. 배열 변환 메서드가 아닙니다.
- `control[i]` : 문자열의 i번째 문자입니다. i는 0부터 시작합니다.
- `const char` : 매 반복마다 새 변수가 생기므로 같은 선언으로 다른 문자를 받을 수 있습니다.

### 조건과 종료 위치

- 네 답의 독립된 if 네 개도 맞습니다. 한 문자가 동시에 w와 s일 수 없으므로 한 번의 반복에서 변경은 한 번만 일어납니다.
- `else if`로 연결하면 앞 조건이 참일 때 뒤 조건은 확인하지 않습니다. 이 문제에서는 결과와 빅오가 동일합니다.
- `switch(값)` : 값에 일치하는 case부터 실행합니다. case에서 break를 생략하면 다음 case의 실행문까지 이어질 수 있습니다.
- switch 안의 `break`는 switch를 끝냅니다. `continue`는 바깥 반복문의 다음 반복으로 넘어가고, `return`은 함수 전체를 끝냅니다.
- `return n`은 반복문 밖에 둡니다. 안에 두면 첫 문자만 처리하고 끝납니다.
- `n++`, `n--` : n을 1 증가·감소시킵니다. `n += 10`, `n -= 10`은 10씩 증가·감소입니다.
- 매개변수 n은 함수 안에서 재대입할 수 있습니다. 숫자는 원시값이므로 호출한 쪽의 숫자 변수를 직접 변경하는 것은 아닙니다.

### 객체의 값으로 숫자 또는 함수 저장

- `changes = {w: 1}` : w라는 키에 숫자 1 저장. `changes['w']` → 1.
- `operations = {w: n => n + 1}` : w라는 키에 함수 저장. `operations['w']`는 함수이고, `operations['w'](5)`는 그 함수를 실행한 결과 6입니다.
- `operations[op](prev)` : op라는 키로 함수 조회 → 괄호 안의 prev를 인자로 전달 → 함수 실행입니다.
- `changes.char`는 글자 그대로 char라는 키를 찾습니다. 변수 char에 든 문자를 키로 쓰려면 `changes[char]`입니다.
- 함수가 받는 n과 solution의 n은 서로 다른 함수 범위의 변수입니다. 이름이 같다고 같은 변수는 아닙니다.

### 배열 메서드·반환

- `forEach(함수)` : 각 원소에 작업을 실행합니다. 반환값은 undefined이므로 계산한 answer를 별도로 반환합니다.
- `map(함수)` : 각 원소를 변환한 새 배열을 반환합니다. (5)는 문자를 숫자 변화량으로 바꿉니다.
- `reduce((누적값, 현재원소) => 다음누적값, 시작값)` : (4)·(5)의 시작값은 n입니다. 0을 넣으면 주어진 시작 숫자가 빠집니다.
- 화살표 함수가 `=> 표현식` 형태이면 결과를 자동 반환합니다. `=> { ... }` 형태에서는 필요한 값을 return으로 직접 반환해야 합니다.

### 추천과 복잡도

- 네 if 풀이도 충분히 좋습니다. switch를 배우려면 (1), 반복되는 분기를 줄이려면 (2)를 참고합니다.
- (4)는 함수를 객체의 값으로 저장하고 꺼내 실행하는 문법을 배우기 좋습니다. 짧다고 반드시 더 빠른 것은 아닙니다.
- 모든 풀이의 시간은 `O(m)`입니다. 문자 배열을 만들지 않는 내 답·(1)·(2)는 추가 공간 `O(1)`, 배열을 만드는 (3)·(4)·(5)는 `O(m)`입니다.
- 반환값은 숫자 하나라 결과를 저장하는 공간은 `O(1)`입니다. 공간 차이는 중간에 만드는 배열에서 생깁니다.
