# 05. 조건에 맞게 수열 변환하기 3

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181835?language=javascript)

## 문제 설명

정수 배열 `arr`와 자연수 `k`가 주어집니다.

만약 `k`가 홀수라면 `arr`의 모든 원소에 `k`를 곱하고, `k`가 짝수라면 `arr`의 모든 원소에 `k`를 더합니다.

이러한 변환을 마친 후의 `arr`를 return 하는 solution 함수를 완성해 주세요.

## 제한사항

- 1 ≤ `arr`의 길이 ≤ 1,000,000
  - 1 ≤ `arr`의 원소의 값 ≤ 100
- 1 ≤ `k` ≤ 100

## 입출력 예

| arr | k | result |
| --- | --- | --- |
| [1, 2, 3, 100, 99, 98] | 3 | [3, 6, 9, 300, 297, 294] |
| [1, 2, 3, 100, 99, 98] | 2 | [3, 4, 5, 102, 101, 100] |

## 입출력 예 설명

- 예제 #1: 주어진 k인 3은 홀수이므로, 전체 배열에 3을 곱합니다. 따라서 [3, 6, 9, 300, 297, 294]를 return 합니다.
- 예제 #2: 주어진 k인 2는 짝수이므로, 전체 배열에 2를 더합니다. 따라서 [3, 4, 5, 102, 101, 100]을 return 합니다.

## 문제 코드

```javascript
function solution(arr, k) {
  var answer = [];
  return answer;
}
```

## 내가 푼 답

```javascript
function solution(arr, k) {
  var answer = [];

  if (k % 2 === 0) {
    answer = arr.map(value => value + k);
  } else {
    answer = arr.map(value => value * k);
  }

  return answer;
}
```

- **시간 복잡도 `O(n)`**: 여기서 n은 arr.length입니다. 두 분기 중 하나의 map만 실행되며, n개 원소마다 덧셈 또는 곱셈을 한 번 합니다.
- **공간 복잡도 `O(n)` — 결과 배열 포함**: map이 n개 원소를 담은 새 배열을 만듭니다. answer에 대입한다고 배열이 한 번 더 복사되지는 않습니다.
- 출력 결과 배열을 제외한 보조 공간만 계산하면 `O(1)`입니다. 공간 비교 시 결과 배열을 포함했는지 구분합니다.

## 다른 방법

각 풀이에서 n은 arr.length입니다. 아래 공간은 입력 배열을 제외하고 새 결과 배열은 포함합니다.

### (1) map과 삼항 연산자 — 간결한 풀이

```javascript
const solution = (arr, k) => arr.map(value => k % 2 ? value * k : value + k);
```

- 양의 정수 k에서 `k % 2`는 홀수면 1(참), 짝수면 0(거짓)입니다. `=== 1`을 생략한 표현입니다.
- 바깥 화살표 함수는 map의 결과 배열, 안쪽 화살표 함수는 변환한 숫자를 자동 반환합니다.
- 시간: 원소 n개 변환 → `O(n)`. 추가 공간: 새 배열 → `O(n)`.

---

### (2) for...of와 push — 원소를 꺼내 직접 추가

```javascript
function solution(arr, k) {
  const answer = [];
  for (const num of arr) {
    if (k % 2 === 0) {answer.push(num + k);}
    else {answer.push(num * k);}
  }
  return answer;
}
```

- 올려준 코드의 `for(num of arr)`는 선언이 빠져 있어 `const num`으로 고쳤습니다. 미선언 변수 대입은 엄격 모드에서 오류이고, 그 밖에서는 전역 변수를 만들 수 있습니다.
- 시간: n번 순회·추가 → 일반적인 배열 구현에서 분할상환 기준 `O(n)`. 추가 공간: 새 배열 → `O(n)`.

---

### (3) 기본 for문과 인덱스 — 결과 위치에 저장

```javascript
function solution(arr, k) {
  const answer = [];
  const isOdd = k % 2 === 1;
  for (let i = 0; i < arr.length; i++) {answer[i] = isOdd ? arr[i] * k : arr[i] + k;}
  return answer;
}
```

- `answer[i] = 값`으로 같은 위치에 결과를 저장합니다. isOdd는 반복문 밖에서 한 번 계산합니다.
- 시간: n개 처리 → `O(n)`. 추가 공간: 새 배열 → `O(n)`.

---

### (4) reduce와 push — 누적 배열 연습

```javascript
function solution(arr, k) {
  const isOdd = k % 2 === 1;
  return arr.reduce((acc, value) => {
    acc.push(isOdd ? value * k : value + k);
    return acc;
  }, []);
}
```

- 마지막 `[]`가 처음 acc로 들어갑니다. 같은 배열에 값을 추가하고 return acc로 다음 반복에 전달합니다.
- `return acc.push(...)`는 안 됩니다. push는 배열이 아니라 새 길이를 반환하므로 추가한 뒤 배열을 따로 반환합니다.
- 시간: n개 누적 → 일반적인 배열 구현에서 분할상환 기준 `O(n)`. 추가 공간: 누적 배열 → `O(n)`.

---

### (5) 원본 배열 직접 변경 — 추가 공간 줄이기

```javascript
function solution(arr, k) {
  const isOdd = k % 2 === 1;
  for (let i = 0; i < arr.length; i++) {arr[i] = isOdd ? arr[i] * k : arr[i] + k;}
  return arr;
}
```

- 새 배열을 만들지 않고 arr의 각 값을 덮어씁니다. 반환한 배열은 입력 배열과 같은 객체입니다.
- 시간: n개 처리 → `O(n)`. 추가 공간: 고정된 변수만 → `O(1)`. 이미 받은 입력 배열은 공간 계산에서 제외합니다.
- 이 문제는 원본 보존을 요구하지 않지만, 실제 코드에서 다른 곳도 arr를 사용한다면 값이 함께 바뀌는 점을 주의합니다.

---

## 정리

- `map()` : 각 원소를 변환한 새 배열을 반환합니다. 위 코드는 원본 arr를 바꾸지 않습니다.
- `value` : map이 현재 꺼낸 원소입니다. 짝수 k는 더하고 홀수 k는 곱한 값을 새 배열에 넣습니다.
- **시간 복잡도**: 반복문 개수 자체가 아니라, 메서드 내부 작업까지 포함한 총 작업량이 입력 크기에 따라 얼마나 증가하는지 봅니다.
- **공간 복잡도**: 변수 이름의 개수가 아니라, 저장하는 데이터 크기가 입력에 따라 얼마나 증가하는지 봅니다.
- 숫자 합계 하나만 유지하면 보통 `O(1)`, 길이 n인 새 배열을 만들면 그 배열은 `O(n)` 공간입니다.

### 이번에 비교할 문법

- `조건 ? 참일때값 : 거짓일때값` : 삼항 연산자. `k % 2 ? 곱셈 : 덧셈`은 홀수면 곱셈, 짝수면 덧셈입니다.
- `for...of` : 배열의 원소를 하나씩 꺼냅니다. 반복마다 새 num 변수가 만들어지므로 값을 재대입하지 않으면 const를 쓸 수 있습니다.
- `push(값)` : 배열 끝에 값을 추가하며, 반환값은 변경된 배열 길이입니다. `const a = []; a.push(3);` → a는 `[3]`, push의 반환값은 1.
- `const answer = []` : 다른 배열을 answer에 재대입할 수 없다는 뜻입니다. push나 `answer[i] = 값`으로 내부를 바꾸는 것은 가능합니다.
- `answer[i] = 값` : 계산한 값을 결과 배열의 i번째 위치에 저장합니다. `arr[i] = 값`이면 원본 배열을 바꿉니다.
- `reduce((누적값, 현재원소) => {return 다음누적값;}, 시작값)` : 이번 풀이는 시작값과 누적값이 배열입니다. 현재원소는 숫자입니다.
- `forEach()`로도 빈 결과 배열에 push할 수 있습니다. 원소마다 변환한 배열이 목적이라면 map이 더 직접적입니다.
- reduce에서 매번 `[...acc, 새값]`을 반환하면 기존 원소를 반복 복사해 총 `1 + 2 + … + n`만큼 작업합니다. 최악 `O(n²)`이 될 수 있어 이 문제의 최대 100만 개 입력에는 피합니다.
- 분할상환 기준이란, 배열이 커지며 가끔 발생하는 확장 비용을 여러 번의 추가 작업에 나누어 분석한다는 뜻입니다.

### 추천

- **읽기 쉬운 답**: 네 if/else + map 풀이. 홀짝 분기가 명확하고 원본도 보존합니다.
- **간결한 답**: (1) map + 삼항 연산자. 짧지만 처음에는 `k % 2 === 1`로 조건을 명시해도 됩니다.
- **공간 절약**: (5) 원본 수정. 새 배열이 없지만 원본이 바뀝니다.
- 나머지는 반복문·누적 문법 연습용입니다. reduce나 한 줄 코드가 무조건 더 빠른 것은 아닙니다.
