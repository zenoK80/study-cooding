# 그냥 대입하면 복사가 아니다
```js
const original = [1,2,3];
const copied = original;
copied[0] = 100;
console.log(original)
// [100,2,3]
```
- original, copied가 같은 배열을 참조한다.

---

# Spread로 복사
```js
const original = [1,2,3];
const copied = [...original];

copied[0] = 100;

console.log(original)
console.log(copied)
// [1,2,3]
// [100,2,3]
```
- [...original] : 배열의 값을 펼쳐서 새로운 배열 생성

---

# slice()로 복사
```js
const original = [1,2,3];
const copied = original.slice();
copied[0] = 100;
console.log(original)
// [1,2,3]
```
- slice()에 범위를 안 넣으면 전체 배열을 복사한다.

---

# Array.from()으로 복사
```js
const original = [1,2,3];
const copied = Array.from(original);

copied[0] = 100;
console.log(original)
// [1,2,3]
```
- `Array.from(original)`: 배열을 기반으로 새로운 배열 생성

---

# 2차원 배열 복사
```js
const original = [
	[1,2],
	[3,4]
];
const copied = original.map(row=>[...row]);
copied[0][0] = 100;

console.log(original)
// [[1,2],[3,4]]
console.log(copied)
// [[100,2],[3,4]]
```
- 바깥 배열뿐 아니라 각 행도 새로 복사한다.

---

# 정리
- map() 자체가 깊은 복사를 해주는 건 아니고, `[...]` 때문에 복사가 된다

- `array.slice(시작위치, 끝위치)`
- 인자1: 시작 index
- 인자2: 끝 index
- 끝 index는 포함 안 함
- 인자3은 없음

---

# 핵심

`const copied = original` → 복사 아님 → 같은 배열 참조

`[...original]` → 새 배열 복사

`original.slice()` → 새 배열 복사

`Array.from(original)` → 새 배열 복사

2차원 배열→ `original.map(row => [...row])`
