# join()
배열의 값들을 하나의 문자열로 합친다.
```js
const words = ["hello","world"];
const result = words.join(" ");
console.log(result);
// "hello world"
```
- `" "`: 값 사이에 공백을 넣는다.

---

# 구분자 없이 합치기
```js
const letters = ["h","e","l","l","o"];
const result = letters.join("");
console.log(result)
// "hello"
```

---

# 쉼표로 합치기
```js
const numbers = [1,2,3];
const result = numbers.join(",");
console.log(result);
// "1,2,3"
```

---

# 아무것도 안 넣으면
```js
const numbers = [1,2,3];
const result = numbers.join();
console.log(result)
// "1,2,3"
```
- 기본 구분자는 `,`이다.

---

# 변수도 사용 가능
```js
const separator = "-";
const words = ["a","b","c"];
const result = words.join(seperator);
console.log(result);
// "a-b-c"
```

---

# 핵심
`join(구분자)`
→ 배열을 문자열로 합침

`join("")`
→ 구분자 없이 합침

`join(" ")`
→ 공백으로 합침

`join()`
→ 기본값 ","로 합침
