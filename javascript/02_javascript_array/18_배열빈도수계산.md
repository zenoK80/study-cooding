# Object로 개수 세기
```JavaScript
const numbers = [1,2,2,3,3,3];
const count = {};
for (const number of numbers){
  count[number] = (count[number] ?? 0) + 1;
}

console.log(count);
// {1:1 ,2:2, 3:3}
```
- `count[number]`: 해당 숫자의 현재 개수
- `?? 0` : 아직 없으면 0
- `+1` : 개수 1 증가

---

# 동작 흐름
1. number = 2
2. count[2] 아직 없음 -> undefined
3. undefined ?? 0 -> 0
4. 0 + 1 -> 1
5. 다시 2를 만나면: count[2] = 1
6. 1 ?? 0 -> 1
7. 1 + 1 -> 2

# 문자열 개수 세기
```JavaScript
const fruits = ["apple","banana","apple"];
const count = {};
for(const fruit of fruits){
  count[fruit] = (count[fruit] ?? 0) +1;
}
console.log(count);
// { apple : 2, banana: 1}
```

---

# Map으로 개수 세기
```js
const numbers = [1,2,2,3];
const count = new Map();
for(const number of numbers){
  count.set(number,(count.get(number) ?? 0) + 1);
}
console.log(count.get(2))
// 2
```
---

# 정리
- `new Map()` : 빈 Map 객체를 만든다.
- `map.set(인자1, 인자2)` : 인자1을 key로, 인자2를 value로 저장한다.
- `map.get(인자1)` : 인자1 key에 저장된 value를 가져온다. 없으면 undefined를 반환한다.
- `Map`: Javascript의 내장 자료구조 (key-value 형태로 데이터를 저장하는 컬렉션 객체) → key와 value를 한 쌍으로 저장하는 자료구조
- `Object vs Map` : 둘 다 key-value 형태로 저장하지만, Map은 key-value 저장용 메서드가 따로 있고 key 타입 제한이 적어서 데이터 조회·추가·삭제에 더 편하다.

```
Object
→ obj[key] = value
→ obj[key]
→ delete obj[key]
→ key는 주로 문자열 / Symbol

Map
→ map.set(key, value)
→ map.get(key)
→ map.has(key)
→ map.delete(key)
→ map.clear()
→ map.size
→ key에 숫자, 객체, 함수 등도 사용 가능
```

```JavaScript
const map = new Map();
map.set("apple",3)
map.get("apple") // 3
map.has("apple") // true
map.delete("apple") // 삭제
map.size // 현재 개수
```
- 즉 Map은 추가 / 조회 / 존재확인 / 삭제 / 전체삭제 / 개수확인 메서드가 전용으로 있어서 편하다.

---

# 핵심
- Object 방식: `count[value] = (count[value] ?? 0) + 1`
- Map 방식: `count.set(value, (count.get(value) ?? 0) + 1)`
- 빈도수 → 값이 몇 번 나왔는지 세는 것
