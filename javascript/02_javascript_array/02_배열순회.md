# for문으로 순회
인덱스를 이용해서 배열의 값을 하나씩 확인한다.
```js
const numbers = [10,20,30];
for(let index=0; index < numbers.length; index++){
	console.log(numbers[index]);
}
// 10
// 20
// 30
```
- index: 현재 위치
- numbers[index]: 현재 값
-numbers.length: 배열 길이

---

# for...of
배열의 값을 바로 하나씩 꺼낸다.
```js
const numbers = [10,20,30];
for (const number of numbers){
	console.log(number);
}
// 10
// 20
// 30
```
- 인덱스가 필요 없으면 더 간단하다.

---

# 값과 인덱스 같이 사용하기
```js
const numbers = [10,20,30];
for (let index = 0; index < numbers.length; index++) {
	const number = numbers[index];
	console.log(index,number);
}
// 0 10
// 1 20
// 2 30
```

---

# 배열 합 구하기
```js
const numbers = [1,2,3,4];
let sum = 0;
for (const number of numbers){
	sum += number;
}
// console.log(sum); 10
```

---

# 조건에 맞는 값 찾기
```js
const numbers = [3,8,5,12];
for (const number of numbers){
	if(number>10) console.log(number);
}
// 12
```

---

# 정리
- for → 인덱스가 필요할 때
- for...of → 값만 필요할 때
- numbers[index] → 현재 위치의 값
- numbers.length → 배열 길이
