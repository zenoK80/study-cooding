# 17. 배열 생성

## 배열 만들기

여러 값을 순서대로 저장할 때 배열을 사용한다.

```js
const numbers = [10, 20, 30];

// console.log(numbers); [10, 20, 30]
```

* 배열의 값은 `[]` 안에 넣는다.
* 각 값은 `,`로 구분한다.

---

## 빈 배열 만들기

```js
const numbers = [];

// console.log(numbers); []
```

나중에 값을 추가할 수 있다.

```js
const numbers = [];

numbers.push(10);
numbers.push(20);

// console.log(numbers); [10, 20]
```

---

## 인덱스로 값 가져오기

배열의 위치는 `0`부터 시작한다.

```js
const numbers = [10, 20, 30];

// console.log(numbers[0]); 10
// console.log(numbers[1]); 20
// console.log(numbers[2]); 30
```

---

## 배열 길이

```js
const numbers = [10, 20, 30];

// console.log(numbers.length); 3
```

* `length`: 배열에 들어있는 값의 개수.

---

## Array로 만들기

```js
const numbers = new Array(1, 2, 3);

// console.log(numbers); [1, 2, 3]
```

보통은 아래 방식이 더 간단하다.

```js
const numbers = [1, 2, 3];
```

---

## 원하는 길이의 배열 만들기

```js
const numbers = Array(5);

// console.log(numbers.length); 5
```

값을 채우려면 `fill()`을 사용한다.

```js
const numbers = Array(5).fill(0);

// console.log(numbers); [0, 0, 0, 0, 0]
```

* `Array(5)` : 길이 5인 배열 생성
* `fill(0)` : 모든 칸을 `0`으로 채움

---

## Array.from()

`Array.from()`도 길이를 정해서 배열을 만들 수 있다.

```js
const numbers = Array.from(
  { length: 5 },
  () => 0
);

// console.log(numbers); [0, 0, 0, 0, 0]
```

* `{ length: 5 }` : 5칸을 만든다.
* `() => 0` : 각 칸에 `0`을 넣는다.

즉 이런 느낌이다.

```text
1번째 칸 → 0
2번째 칸 → 0
3번째 칸 → 0
4번째 칸 → 0
5번째 칸 → 0
```

---

## Array.from()에서 index 사용하기

```js
const numbers = Array.from(
  { length: 5 },
  (_, index) => index
);

// console.log(numbers); [0, 1, 2, 3, 4]
```

`Array.from()`의 두 번째 함수는 이런 값을 받을 수 있다.

```js
(value, index) => 값
```

* `value` : 현재 칸의 값
* `index` : 현재 칸의 번호

여기서는 `value`를 사용하지 않기 때문에 `_`라고 적었다.

```js
(_, index) => index
```

`_`는 특별한 문법이 아니다.

```text
_ = 사용하지 않을 값이라는 뜻으로 자주 쓰는 변수 이름
```

`index`는 다음처럼 들어온다.

```text
첫 번째 칸 → index = 0
두 번째 칸 → index = 1
세 번째 칸 → index = 2
네 번째 칸 → index = 3
다섯 번째 칸 → index = 4
```

그래서:

```js
(_, index) => index
```

는 각 칸에 `index`를 그대로 넣는다는 뜻이다.

결과:

```js
[0, 1, 2, 3, 4]
```

---

## for문으로 보면

이 코드:

```js
const numbers = Array.from(
  { length: 5 },
  (_, index) => index
);
```

는 아래와 비슷하다.

```js
const numbers = [];

for (let index = 0; index < 5; index++) {
  numbers.push(index);
}
```

둘 다 결과는 같다.

```js
[0, 1, 2, 3, 4]
```

---

## index를 계산해서 넣기

```js
const numbers = Array.from(
  { length: 5 },
  (_, index) => index + 1
);

// console.log(numbers); [1, 2, 3, 4, 5]
```

`index`는 `0`부터 시작하므로 `+ 1`하면 `1`부터 시작한다.

---

## 핵심

```text
[1, 2, 3]
→ 기본 배열 생성

[]
→ 빈 배열

Array(5).fill(0)
→ 길이 5를 0으로 채움

Array.from({ length: 5 }, () => 0)
→ 5칸을 만들고 모두 0을 넣음

Array.from({ length: 5 }, (_, index) => index)
→ index를 이용해 [0, 1, 2, 3, 4] 생성

_
→ 사용하지 않을 값을 받는 변수 이름

index
→ 현재 칸의 번호, 0부터 시작
```
