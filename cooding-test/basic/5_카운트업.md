# 5. 카운트 업

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181920?language=javascript)

## 문제 설명

정수 `start_num`와 `end_num`가 주어질 때, `start_num`부터 `end_num`까지의 숫자를 차례로 담은 리스트를 return하도록 solution 함수를 완성해주세요.

## 제한사항

- 0 ≤ `start_num` ≤ `end_num` ≤ 50

## 입출력 예

| start_num | end_num | result |
| ---: | ---: | --- |
| 3 | 10 | `[3, 4, 5, 6, 7, 8, 9, 10]` |

## 입출력 예 설명

- 예제 #1: 3부터 10까지의 숫자들을 담은 리스트 `[3, 4, 5, 6, 7, 8, 9, 10]`을 return합니다.

## 문제 코드

```javascript
function solution(start_num, end_num) {
  var answer = [];
  return answer;
}
```

## 나의 풀이

```javascript
const solution = (start_num, end_num) => {
  const result = [];
  for (start_num; start_num <= end_num; start_num++) {result.push(start_num);}
  return result;
};
```

정답입니다. start_num을 직접 증가시킵니다. 함수 밖에서 전달한 숫자 변수까지 바뀌지는 않습니다. 결과 길이를 r = end_num - start_num + 1(최초 입력 기준)이라 하면 시간 `O(r)`, 결과 배열 포함 추가 공간 `O(r)`.

## 다른 방법

### (1) 별도 반복 변수 사용 — 추천

```javascript
function solution(start_num, end_num) {
  const result = [];
  for (let i = start_num; i <= end_num; i++) {result.push(i);}
  return result;
}
```

입력 매개변수는 유지하고 i만 증가시켜 의도를 명확히 합니다. 시간 `O(r)`, 결과 배열 포함 추가 공간 `O(r)`.

### (2) Array.from + 인덱스 — 내장 메서드 연습

```javascript
function solution(start_num, end_num) {
  return Array.from({ length: end_num - start_num + 1 }, (_, i) => start_num + i);
}
```

원하는 길이의 배열을 만들면서 각 칸에 시작값 + 인덱스를 넣습니다. 시간 `O(r)`, 결과 배열 포함 추가 공간 `O(r)`.

### (3) Array.from + 후위 증가 — 가져온 풀이 수정

```javascript
function solution(start, end) {
  return Array.from({ length: end - start + 1 }, () => start++);
}
```

원래 풀이의 `idx = start;`는 선언되지 않은 변수에 대입하고 사용도 하지 않아 제거했습니다. 엄격 모드에서는 ReferenceError가 나고, 비엄격 환경에서는 의도치 않은 전역 속성을 만들 수 있습니다. 시간 `O(r)`, 결과 배열 포함 추가 공간 `O(r)`.

### (4) while — 반복문 연습

```javascript
function solution(start_num, end_num) {
  const result = [];
  let current = start_num;
  while (current <= end_num) {result.push(current); current++;}
  return result;
}
```

종료값까지 포함해서 저장합니다. 시간 `O(r)`, 결과 배열 포함 추가 공간 `O(r)`.

## 배울 것들

- `push(값)`: 배열의 내장 메서드. 끝에 원소를 추가하고 새 배열 길이를 반환합니다. `result.push(3)`은 result에 3을 넣는 작업입니다.
- `const result = []`: result에 다른 배열을 재대입할 수 없다는 뜻입니다. push로 내부에 원소를 넣는 것은 가능합니다.
- `for (시작식; 조건식; 증감식)`: 조건이 참인 동안 반복합니다. 네 코드의 시작식 `start_num`은 값을 읽을 뿐이라 생략해도 됩니다. `for (; start_num <= end_num; start_num++)`도 가능합니다.
- `<=`: 끝 숫자까지 포함합니다. `<`를 쓰면 end_num이 빠집니다.
- `end - start + 1`: 양 끝을 포함한 숫자 개수. 3~10은 `10 - 3 + 1 = 8`개입니다. 시작과 끝이 같아도 1개입니다.
- `Array.from(배열처럼 생긴 값 또는 iterable, 변환 함수)`: Array에 붙어 있는 내장 정적 메서드. 새 배열을 만듭니다. 기존 배열에 `.from()`을 붙이는 방식이 아닙니다.
- `{ length: 8 }`: length 속성이 8인 일반 객체입니다. 배열 자체는 아니지만 Array.from이 길이를 읽어 8칸을 만들 수 있습니다.
- `(_, i) => start_num + i`: 첫 인자는 현재 값, 둘째는 0부터 시작하는 인덱스입니다. 이 객체에는 숫자 인덱스 속성이 없어 현재 값은 undefined입니다. 사용하지 않을 첫 인자를 `_`라고 이름 붙였습니다.
- `start++`: 증가하기 전 값을 사용한 뒤 start를 1 증가시킵니다. `++start`는 먼저 증가시킨 값을 사용하므로 여기서는 시작 숫자를 놓칩니다.
- `Array.from()`은 길이만큼 변환 함수를 실행합니다. 코드가 한 줄이어도 시간 복잡도가 `O(1)`이 되는 것은 아닙니다.

### Array.from 예시를 풀어 읽기

```javascript
const start = 3;
const end = 5;
const result = Array.from({ length: end - start + 1 }, (_, i) => start + i);
console.log(result); // [3, 4, 5]
// i = 0 → 3 + 0 = 3
// i = 1 → 3 + 1 = 4
// i = 2 → 3 + 2 = 5
```

### 후위 증가 예시

```javascript
let value = 3;
const before = value++;
console.log(before); // 3
console.log(value);  // 4
```

## 정리

- 알고리즘은 시작값부터 끝값까지 순서대로 열거하는 단순 반복입니다.
- 네 for + push 풀이로 충분합니다. 별도 i를 쓰면 시작값을 유지할 수 있습니다.
- 모든 풀이가 r개를 만들어야 하므로 시간 `O(r)`, 결과 배열 포함 추가 공간 `O(r)`입니다. 반환 배열을 제외한 보조 공간은 `O(1)`입니다.
- 입력이 `[0, 0]`이면 `[0]`, `[3, 3]`이면 `[3]`, `[0, 50]`이면 51개인지 확인하면 경계 조건을 점검할 수 있습니다.
