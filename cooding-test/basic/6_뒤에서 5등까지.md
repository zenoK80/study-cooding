# 6. 뒤에서 5등까지

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181853?language=javascript)

## 문제 설명

정수로 이루어진 리스트 `num_list`가 주어집니다. `num_list`에서 가장 작은 5개의 수를 오름차순으로 담은 리스트를 return하도록 solution 함수를 완성해주세요.

## 제한사항

- 6 ≤ `num_list`의 길이 ≤ 30
- 1 ≤ `num_list`의 원소 ≤ 100

## 입출력 예

| num_list | result |
| --- | --- |
| `[12, 4, 15, 46, 38, 1, 14]` | `[1, 4, 12, 14, 15]` |

## 입출력 예 설명

- 예제 #1: `[12, 4, 15, 46, 38, 1, 14]`를 정렬하면 `[1, 4, 12, 14, 15, 38, 46]`이 됩니다. 앞에서부터 5개를 고르면 `[1, 4, 12, 14, 15]`입니다.

## 문제 코드

```javascript
function solution(num_list) {
  var answer = [];
  return answer;
}
```

## 나의 풀이

```javascript
const solution = (num_list) => {
  num_list.sort((a, b) => a - b);
  const result = new Array(5);
  for (let i = 0; i < 5; i++) {result[i] = num_list[i];}
  return result;
};
```

정답입니다. 원본 배열을 숫자 오름차순으로 정렬한 뒤 인덱스 0~4의 값을 새 배열에 담습니다. 작성한 로직은 그대로 두고 줄 배치만 정돈했습니다.

## 다른 방법

### (1) sort + slice — 가장 간단한 풀이

```javascript
function solution(num_list) {
  return num_list.sort((a, b) => a - b).slice(0, 5);
}
```

정렬한 배열에서 앞의 5개를 복사해 반환합니다. 원본 배열의 순서는 바뀝니다.

### (2) 복사 + sort + slice — 원본 보존 시 추천

```javascript
function solution(num_list) {
  return [...num_list].sort((a, b) => a - b).slice(0, 5);
}
```

먼저 배열을 복사하므로 입력 num_list는 바뀌지 않습니다. 이 문제처럼 원소가 숫자라면 얕은 복사로 충분합니다.

### (3) sort + push — 배열 추가 연습

```javascript
function solution(num_list) {
  num_list.sort((a, b) => a - b);
  const result = [];
  for (let i = 0; i < 5; i++) {result.push(num_list[i]);}
  return result;
}
```

네 풀이의 인덱스 대입을 push로 바꾼 형태입니다. 결과는 같고, 원본 배열은 정렬됩니다.

### (4) 빈도수 배열 — 제한사항 활용 연습

```javascript
function solution(num_list) {
  const counts = new Array(101).fill(0);
  for (const value of num_list) {counts[value]++;}
  const result = [];
  for (let value = 1; value <= 100 && result.length < 5; value++) {
    while (counts[value] > 0 && result.length < 5) {
      result.push(value);
      counts[value]--;
    }
  }
  return result;
}
```

원소가 1~100이라는 조건을 활용합니다. `counts[값]`에 등장 횟수를 저장한 뒤 작은 값부터 5개를 꺼냅니다. 빈도수를 이용한 계수 정렬의 아이디어입니다. 여기서는 sort 풀이만으로 충분합니다.

## 배울 것들

- `sort(비교 함수)`: 배열의 내장 메서드. **원본 배열을 정렬하고 같은 배열을 반환**합니다. 새 배열을 만들지 않습니다.
- `sort()`에 비교 함수를 생략하면 문자열 기준으로 비교합니다. `[2, 10, 1].sort()` → `[1, 10, 2]`라서 숫자 정렬에는 주의해야 합니다.
- `(a, b) => a - b`: 숫자 오름차순 비교 함수입니다. 반환값이 음수면 a를 b보다 앞에, 양수면 뒤에 둡니다. 0이면 두 값의 순서를 유지합니다. a와 b를 직접 수정하는 코드는 아닙니다.
- `(a, b) => b - a`: 숫자 내림차순 비교 함수입니다.
- `slice(시작, 끝)`: 시작 인덱스부터 **끝 인덱스 직전까지** 복사한 새 배열을 반환합니다. `slice(0, 5)`는 인덱스 0, 1, 2, 3, 4입니다. slice 자체는 원본을 바꾸지 않습니다.
- `splice(시작, 삭제 개수)`: 원본 배열에서 원소를 제거하고 제거한 원소를 반환합니다. slice와 달리 원본이 바뀌므로 구분합니다.
- `new Array(5)`: 길이 5인 빈 슬롯 배열입니다. 0이 다섯 개 들어 있는 것은 아닙니다. 네 코드는 5칸을 모두 대입하므로 문제없습니다.
- `new Array(101).fill(0)`: 101칸에 0을 채웁니다. 인덱스 1~100을 값으로 사용하며 0번 칸은 사용하지 않습니다.
- `result[i] = 값`: 해당 인덱스에 대입합니다. `result.push(값)`는 배열 끝에 추가하고 새 길이를 반환합니다.
- `const result`: 변수 재대입을 막습니다. `result[i] = ...`나 `result.push(...)`처럼 배열 내부를 수정하는 것은 가능합니다.
- `[...num_list]`: 배열을 얕게 복사합니다. 복사본을 정렬하면 원본 배열의 순서를 보존할 수 있습니다.
- `sort(...).slice(...)`: 앞 메서드의 반환값에 다음 메서드를 이어 호출하는 메서드 체이닝입니다.
- 중복된 숫자도 각각 한 개로 셉니다. `[1, 1, 2, 3, 4, 5]`의 답은 `[1, 1, 2, 3, 4]`입니다. Set으로 중복을 제거하면 틀립니다.

### slice를 직접 확인하기

```javascript
const numbers = [1, 4, 12, 14, 15, 38, 46];
console.log(numbers.slice(0, 5)); // [1, 4, 12, 14, 15]
console.log(numbers); // [1, 4, 12, 14, 15, 38, 46]
```

## 시간·공간 복잡도

배열 길이를 n, 정렬 엔진이 쓰는 임시 공간을 S(n)이라고 두면:

- 나의 풀이·(1)·(3): 일반적인 효율적 정렬 기준 시간 `O(n log n)`입니다. 5개 추출은 고정 횟수라 `O(1)`이며 전체 시간은 정렬이 좌우합니다.
- 나의 풀이·(1)·(3)의 결과 배열은 항상 5개라 `O(1)` 공간입니다. 다만 정렬 내부까지 포함한 추가 공간은 `O(S(n) + 1)`입니다. 원본 정렬이라고 무조건 전체 추가 공간이 O(1)인 것은 아닙니다.
- (2): 배열 복사 `O(n)` + 정렬 + 5개 추출이므로 통상 시간 `O(n log n)`. 복사본까지 포함한 추가 공간은 `O(n + S(n))`입니다.
- JavaScript의 sort 시간·공간 복잡도는 엔진 구현에 따라 다릅니다. 특정 구현에서 S(n)이 O(n)이면 위 정렬 풀이들의 추가 공간도 O(n)으로 설명할 수 있습니다.
- (4): 가능한 값의 최댓값을 V라 하면 시간 `O(n + V)`, 추가 공간 `O(V)`입니다. 이 문제는 V = 100으로 고정이므로 시간 `O(n)`, 추가 공간 `O(1)`로 볼 수 있습니다. 결과 5개도 고정 공간입니다.

## 정리

- 핵심은 **숫자 오름차순 정렬 → 앞의 5개 선택**입니다.
- 네 풀이도 맞습니다. 짧게 쓰려면 `sort((a, b) => a - b).slice(0, 5)`를 사용합니다.
- 원본을 유지할 필요가 있으면 정렬 전에 복사합니다.
