# 1. 문자열 곱하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181940?language=javascript)

## 문제 설명

문자열 `my_string`과 정수 `k`가 주어질 때, `my_string`을 `k`번 반복한 문자열을 return 하는 solution 함수를 작성해 주세요.

## 제한사항

- 1 ≤ `my_string`의 길이 ≤ 100
- `my_string`은 영소문자로만 이루어져 있습니다.
- 1 ≤ `k` ≤ 100

## 입출력 예

| my_string | k | result |
| --- | ---: | --- |
| `"string"` | 3 | `"stringstringstring"` |
| `"love"` | 10 | `"lovelovelovelovelovelovelovelovelovelove"` |

## 입출력 예 설명

- 예제 #1: `"string"`을 3번 이어 붙입니다.
- 예제 #2: `"love"`를 10번 이어 붙입니다.

## 문제 코드

```javascript
function solution(my_string, k) {
  var answer = '';
  return answer;
}
```

## 나의 풀이

```javascript
function solution(my_string, k) {
  var answer = '';
  for (let i = 0; i < k; i++) {answer = answer + my_string;}
  return answer;
}
```

이 파일이 비어 있어 이전 대화의 풀이를 정리했습니다. 최초 코드의 `i <= k`는 한 번 더 반복하므로 `i < k`로 수정한 버전입니다.

## 다른 방법

### (1) repeat() — 추천

```javascript
function solution(my_string, k) {
  return my_string.repeat(k);
}
```

문자열을 반복한다는 목적이 가장 분명합니다.

### (2) 화살표 함수

```javascript
const solution = (my_string, k) => my_string.repeat(k);
```

(1)과 같은 메서드를 사용하며 함수 작성 형태만 다릅니다.

### (3) while — 반복문 연습

```javascript
function solution(my_string, k) {
  let answer = '';
  let i = 0;
  while (i < k) {answer += my_string; i++;}
  return answer;
}
```

`i++`가 있어야 조건이 바뀌어 반복이 끝납니다.

## 배울 것들

- `repeat(횟수)`: 문자열의 내장 메서드. 반복한 새 문자열을 반환합니다. `'ab'.repeat(3)` → `'ababab'`.
- `for`, `while`: 반복문 키워드입니다. 메서드가 아닙니다.
- `i < k`: `0`부터 `k - 1`까지 정확히 k번 반복합니다. `i <= k`는 k + 1번입니다.
- `answer += my_string`: `answer = answer + my_string`의 축약입니다. 여기서는 문자열 연결입니다.
- 문자열은 불변입니다. 연결한 결과를 `answer`에 다시 대입하는 것이므로 `let`이나 `var`를 사용합니다.
- 화살표 함수의 `=> 표현식`은 그 결과를 반환합니다. `{}`를 사용하면 `return`이 필요합니다.
- `my_string * k`는 문자열 반복이 아닙니다. JavaScript는 숫자 곱셈을 시도하므로 `'ab' * 3`은 `NaN`입니다.

## 시간·공간 복잡도

- 원래 문자열 길이를 L, 반복 횟수를 k라 하면 결과 길이는 L × k입니다.
- 나의 풀이·while: 반복은 k번이지만 문자열 연결 비용도 있습니다. 매번 전체를 복사하는 구현이면 누적 시간은 `O(L × k²)`이며, 실제 동작은 엔진 최적화에 따라 달라집니다.
- repeat: 결과 문자열 생성 비용 기준으로 시간 `O(L × k)`로 설명합니다. 내부 구현은 엔진에 따라 다릅니다.
- 모든 풀이의 결과 저장 공간은 `O(L × k)`입니다. 반복 변수 개수만 보고 전체 공간을 `O(1)`이라고 하면 안 됩니다.
