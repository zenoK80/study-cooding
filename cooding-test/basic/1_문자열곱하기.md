# 1. 문자열 곱하기

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181940?language=javascript)

## 문제 설명

문자열 `my_string`과 정수 `k`가 주어질 때, `my_string`을 `k`번 반복한 문자열을 return 하는 solution 함수를 작성해 주세요.

## 제한사항

- 1 ≤ `my_string`의 길이 ≤ 100
- `my_string`은 영소문자로만 이루어져 있습니다.
- 1 ≤ `k` ≤ 100

## 입출력 예

| my_string | k | result |
| --- | ---: | --- |
| `"string"` | 3 | `"stringstringstring"` |
| `"love"` | 10 | `"lovelovelovelovelovelovelovelovelovelove"` |

## 입출력 예 설명

- 예제 #1: `"string"`을 3번 이어 붙입니다.
- 예제 #2: `"love"`를 10번 이어 붙입니다.

## 문제 코드

```javascript
function solution(my_string, k) {
  var answer = '';
  return answer;
}
```

## 나의 풀이

```javascript
function solution(my_string, k) {
  var answer = '';
  for (let i = 0; i < k; i++) {answer = answer + my_string;}
  return answer;
}
```

이 파일이 비어 있어 이전 대화의 풀이를 정리했습니다. 최초 코드의 `i <= k`는 한 번 더 반복하므로 `i < k`로 수정한 버전입니다.

## 다른 방법

### (1) repeat() — 추천

```javascript
function solution(my_string, k) {
  return my_string.repeat(k);
}
```

문자열을 반복한다는 목적이 가장 분명합니다.

### (2) 화살표 함수

```javascript
const solution = (my_string, k) => my_string.repeat(k);
```

(1)과 같은 메서드를 사용하며 함수 작성 형태만 다릅니다.

### (3) while — 반복문 연습

```javascript
function solution(my_string, k) {
  let answer = '';
  let i = 0;
  while (i < k) {answer += my_string; i++;}
  return answer;
}
```

`i++`가 있어야 조건이 바뀌어 반복이 끝납니다.

## 배울 것들

- `repeat(횟수)`: 문자열의 내장 메서드. 반복한 새 문자열을 반환합니다. `'ab'.repeat(3)` → `'ababab'`.
- `for`, `while`: 반복문 키워드입니다. 메서드가 아닙니다.
- `i < k`: `0`부터 `k - 1`까지 정확히 k번 반복합니다. `i <= k`는 k + 1번입니다.
- `answer += my_string`: `answer = answer + my_string`의 축약입니다. 여기서는 문자열 연결입니다.
- 문자열은 불변입니다. 연결한 결과를 `answer`에 다시 대입하는 것이므로 `let`이나 `var`를 사용합니다.
- 화살표 함수의 `=> 표현식`은 그 결과를 반환합니다. `{}`를 사용하면 `return`이 필요합니다.
- `my_string * k`는 문자열 반복이 아닙니다. JavaScript는 숫자 곱셈을 시도하므로 `'ab' * 3`은 `NaN`입니다.

## 시간·공간 복잡도 쉽게 보기

- **시간 복잡도**: 데이터가 많아지면 해야 할 일이 얼마나 늘어나는지 봅니다. 정확히 몇 초 걸리는지 뜻하는 것은 아닙니다.
- **공간 복잡도**: 풀이 중 새로 저장하는 데이터가 얼마나 늘어나는지 봅니다. 여기서는 정답을 담는 배열·문자열도 포함합니다.
- **O(1)**: 데이터가 늘어도 작업량 또는 저장량이 일정합니다. 딱 1번만 실행한다는 뜻은 아닙니다.
- **O(n)**: 데이터 개수 n에 비례해서 늘어납니다. 10개를 처리하다 20개가 되면 작업도 대략 2배입니다.

### 이 문제에 적용하면

- `'ab'`를 3번 반복하면 `'ababab'`입니다. 원래 2글자 × 3번 = 결과 6글자를 저장합니다.
- `'ab'`를 6번 반복하면 결과가 12글자입니다. 반복 횟수가 늘면 저장할 글자도 늘어나므로 공간이 일정하지 않습니다.
- 원래 글자 수를 L, 반복 횟수를 k라고 쓰면 결과 저장 공간은 `O(L × k)`입니다. 어려운 공식이 아니라 **글자 수 × 반복 횟수**입니다.
- `repeat()`는 코드 한 줄이지만 결과 문자열을 만드는 작업이 있습니다. 결과의 모든 글자를 만드는 비용을 기준으로 시간도 `O(L × k)`로 설명합니다. 내부 처리 방식은 JavaScript 실행 환경마다 다를 수 있습니다.
- for·while은 k번 이어 붙입니다. 다만 문자열이 길어질 때 기존 내용까지 다시 복사할 수 있어, 반복 횟수만 보고 실제 전체 비용을 단정하지 않습니다.

### 더 알아보기: 이어 붙이기의 비용

- 매번 전체를 복사한다고 가정하면 `'ab'` 3번 연결에서 2글자 → 4글자 → 6글자를 만들며 총 12글자 분량을 처리합니다.
- k번이면 `L × (1 + 2 + … + k)`가 되어 시간은 `O(L × k²)`입니다. 실제 엔진은 복사를 미루는 최적화도 하므로 모든 환경에서 반드시 이렇게 걸린다는 뜻은 아닙니다.
- 지금은 **문자열 길이도 작업량에 포함된다**는 점만 먼저 기억하면 됩니다.

**가장 추천하는 풀이: `my_string.repeat(k)` — 문자열을 반복한다는 뜻이 바로 보이고, 직접 반복문을 관리할 필요가 없기 때문입니다.**
