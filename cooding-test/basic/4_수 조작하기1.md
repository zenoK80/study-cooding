# 4. 수 조작하기 1

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181926?language=javascript)

## 문제 설명

정수 `n`과 문자열 `control`이 주어집니다. `control`은 "w", "a", "s", "d"의 4개의 문자로 이루어져 있으며, 앞에서부터 순서대로 문자에 따라 `n`의 값을 바꿉니다.

- `"w"`: n이 1 커집니다.
- `"s"`: n이 1 작아집니다.
- `"d"`: n이 10 커집니다.
- `"a"`: n이 10 작아집니다.

위 규칙에 따라 n을 바꿨을 때 가장 마지막에 나오는 n의 값을 return 하는 solution 함수를 완성해 주세요.

## 제한사항

- -100,000 ≤ `n` ≤ 100,000
- 1 ≤ `control`의 길이 ≤ 100,000
- `control`은 알파벳 소문자 "w", "a", "s", "d"로 이루어진 문자열입니다.

## 입출력 예

| n | control | result |
| ---: | --- | ---: |
| 0 | `"wsdawsdassw"` | -1 |

## 입출력 예 설명

- 예제 #1: `0 → 1 → 0 → 10 → 0 → 1 → 0 → 10 → 0 → -1 → -2 → -1` 순서로 바뀌므로 -1을 반환합니다.

## 문제 코드

```javascript
function solution(n, control) {
  var answer = 0;
  return answer;
}
```

## 나의 풀이

```javascript
const solution = (n, control) => {
  for (const char of control) {
    if (char === 'w') n++;
    if (char === 's') n--;
    if (char === 'd') n += 10;
    if (char === 'a') n -= 10;
  }
  return n;
};
```

정답입니다. 입력한 코드의 로직은 유지하고 표기만 정돈했습니다.
## 다른 방법

### (1) switch — 조건 분기 연습

```javascript
function solution(n, control) {
  for (const char of control) {
    switch (char) {
      case 'w': n++; break;
      case 's': n--; break;
      case 'd': n += 10; break;
      case 'a': n -= 10; break;
    }
  }
  return n;
}
```

문자에 해당하는 case를 실행합니다.

### (2) 객체로 변화량 저장 — 추천

```javascript
function solution(n, control) {
  const changes = { w: 1, s: -1, d: 10, a: -10 };
  for (const char of control) {n += changes[char];}
  return n;
}
```

각 문자에 더할 숫자를 표처럼 저장합니다. 예를 들어 changes['d']는 10입니다.

### (3) split + forEach

```javascript
function solution(n, control) {
  const changes = { w: 1, s: -1, d: 10, a: -10 };
  control.split('').forEach(char => {n += changes[char];});
  return n;
}
```

문자열을 문자 배열로 바꾼 다음 작업합니다. 문자열 길이만큼 새 배열을 만듭니다.

### (4) 전개 구문 + reduce

```javascript
function solution(n, control) {
  const changes = { w: 1, s: -1, d: 10, a: -10 };
  return [...control].reduce((current, char) => current + changes[char], n);
}
```

누적 시작값이 0이 아니라 입력 n입니다. 문자열 길이만큼 새 배열을 만듭니다.

## 배울 것들

- `for...of`: iterable의 값을 순회합니다. 문자열도 바로 순회할 수 있어 배열로 바꿀 필요가 없습니다.
- `const char`: 반복마다 새 바인딩이 만들어지므로 다른 문자를 받을 수 있습니다. 같은 변수에 재대입하는 것과 다릅니다.
- `++`, `--`: 숫자를 1 증가·감소시킵니다. `+= 10`, `-= 10`은 10씩 변경합니다.
- `return n`은 반복문 밖에 있어야 합니다. 안에 두면 첫 문자 처리 후 함수가 끝납니다.
- `switch`, `case`, `break`: 키워드입니다. switch 안의 break는 switch만 끝내므로 바깥 for문은 계속됩니다.
- `changes[char]`: char에 담긴 값을 키로 사용합니다. char가 `'w'`이면 `changes['w']` → 1입니다. `changes.char`는 이름이 `'char'`인 속성을 찾는 다른 코드입니다.
- `split('')`: 문자열 내장 메서드. 이 문제의 영문 문자열 `'ws'`를 `['w', 's']`로 나눕니다.
- `[...control]`: iterable의 값을 펼쳐 배열로 만듭니다. 이 문제의 영문 문자에서는 split('')과 같은 결과입니다. 일부 이모지는 두 방식의 결과가 다를 수 있습니다.
- `forEach(실행 함수)`: 원소별 작업을 실행하며 반환값은 `undefined`입니다. forEach의 결과를 정답으로 반환하지 않습니다.
- `reduce((누적값, 현재문자) => 다음 누적값, n)`: n에서 시작해 문자별 변화량을 누적합니다.
- 알고리즘 분류로는 주어진 명령을 순서대로 적용하는 시뮬레이션입니다. 복잡한 자료구조는 필요 없습니다.

## 시간·공간 복잡도 쉽게 보기

- **시간 복잡도**: 데이터가 많아지면 해야 할 일이 얼마나 늘어나는지 봅니다. 정확히 몇 초 걸리는지 뜻하는 것은 아닙니다.
- **공간 복잡도**: 풀이 중 새로 저장하는 데이터가 얼마나 늘어나는지 봅니다. 여기서는 정답을 담는 배열·문자열도 포함합니다.
- **O(1)**: 데이터가 늘어도 작업량 또는 저장량이 일정합니다. 딱 1번만 실행한다는 뜻은 아닙니다.
- **O(n)**: 데이터 개수 n에 비례해서 늘어납니다. 10개를 처리하다 20개가 되면 작업도 대략 2배입니다.

### 이 문제에 적용하면

- m은 `control.length`, 즉 명령 문자의 개수입니다. n은 시작 숫자라 길이와 구분하려고 m이라고 부릅니다.
- `'wsda'`는 문자 4개를 처리하고, 100글자면 100개를 처리합니다. 따라서 모든 풀이의 시간은 `O(m)`입니다. O(n)과 원리는 같고 문자 이름만 다릅니다.
- **네 풀이·(1) switch**: 문자열을 바로 읽고 n만 바꿉니다. 명령 전체를 새로 저장하지 않으므로 추가 공간은 `O(1)`입니다.
- **(2) 객체**: w, s, d, a의 규칙 4개만 저장합니다. 명령이 길어져도 규칙은 4개 그대로이므로 추가 공간은 `O(1)`입니다.
- **(3) split·(4) 전개 구문**: 먼저 문자열을 새 문자 배열로 만듭니다. 100글자면 배열도 100칸이 생기므로 추가 공간은 `O(m)`입니다.
- 네 if문은 문자마다 최대 4번 검사하지만 `4 × m`도 m에 비례합니다. 빅오에서는 4 같은 고정 배수를 생략합니다.

**가장 추천하는 풀이: (2) 변화량 객체 + for...of — 규칙 4개가 한눈에 보이고, 불필요한 문자 배열을 만들지 않습니다. 네 if 풀이도 시간·공간 증가 정도는 같고 충분히 좋습니다.**
