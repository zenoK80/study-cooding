# 3. 조건에 맞게 수열 변환하기 3

[프로그래머스 원문](https://school.programmers.co.kr/learn/courses/30/lessons/181835?language=javascript)

## 문제 설명

정수 배열 `arr`와 자연수 `k`가 주어집니다.

만약 `k`가 홀수라면 `arr`의 모든 원소에 `k`를 곱하고, `k`가 짝수라면 `arr`의 모든 원소에 `k`를 더합니다.

이러한 변환을 마친 후의 `arr`를 return 하는 solution 함수를 완성해 주세요.

## 제한사항

- 1 ≤ `arr`의 길이 ≤ 1,000,000
- 1 ≤ `arr`의 원소의 값 ≤ 100
- 1 ≤ `k` ≤ 100

## 입출력 예

| arr | k | result |
| --- | ---: | --- |
| `[1, 2, 3, 100, 99, 98]` | 3 | `[3, 6, 9, 300, 297, 294]` |
| `[1, 2, 3, 100, 99, 98]` | 2 | `[3, 4, 5, 102, 101, 100]` |

## 입출력 예 설명

- 예제 #1: k = 3은 홀수이므로 각 원소에 3을 곱합니다.
- 예제 #2: k = 2는 짝수이므로 각 원소에 2를 더합니다.

## 문제 코드

```javascript
function solution(arr, k) {
  var answer = [];
  return answer;
}
```

## 나의 풀이

```javascript
function solution(arr, k) {
  var answer = [];
  if (k % 2 === 0) {
    answer = arr.map(value => value + k);
  } else {
    answer = arr.map(value => value * k);
  }
  return answer;
}
```

정답입니다. map이 새 배열을 만들므로 원본 arr는 유지됩니다. 길이를 n이라 하면 시간 `O(n)`, 결과 배열 포함 추가 공간 `O(n)`.

## 다른 방법

### (1) map + 삼항 연산자 — 추천

```javascript
function solution(arr, k) {
  return arr.map(value => k % 2 === 1 ? value * k : value + k);
}
```

각 원소를 변환한다는 목적이 분명합니다. 시간 `O(n)`, 결과 배열 포함 추가 공간 `O(n)`.

### (2) for...of + push

```javascript
function solution(arr, k) {
  const answer = [];
  const isOdd = k % 2 === 1;
  for (const value of arr) {answer.push(isOdd ? value * k : value + k);}
  return answer;
}
```

값을 하나씩 꺼내 계산한 후 새 배열 뒤에 넣습니다. 시간 `O(n)`, 결과 배열 포함 추가 공간 `O(n)`.

### (3) reduce — 누적값을 배열로 사용

```javascript
function solution(arr, k) {
  return arr.reduce((acc, value) => {
    acc.push(k % 2 === 1 ? value * k : value + k);
    return acc;
  }, []);
}
```

시작값 `[]`가 acc에 들어가고, 같은 배열에 값을 추가합니다. 시간 `O(n)`, 결과 배열 포함 추가 공간 `O(n)`.

### (4) 원본 배열 직접 변경

```javascript
function solution(arr, k) {
  for (let i = 0; i < arr.length; i++) {arr[i] = k % 2 === 1 ? arr[i] * k : arr[i] + k;}
  return arr;
}
```

입력 arr 자체가 바뀝니다. 시간 `O(n)`, 새 배열이 없으므로 추가 공간 `O(1)`입니다. 원본을 보존해야 한다면 사용하지 않습니다.

## 배울 것들

- `map((값, 인덱스) => 바꿀값)`: 배열의 내장 메서드. 각 원소를 변환한 새 배열을 반환합니다.
- `value`는 직접 붙인 매개변수명입니다. `arr.map(value => value + 2)`는 각 원소를 하나씩 받아 2를 더합니다.
- `value => value + k`는 자동 반환입니다. `{}`를 쓰면 `value => {return value + k;}`로 적습니다.
- `push(값)`: 배열 끝에 값을 추가하고 새 길이를 반환합니다. 따라서 reduce에서 `return acc.push(값)`으로 쓰면 누적값이 배열 대신 숫자가 됩니다.
- `const answer = []`여도 `answer.push()`는 가능합니다. 변수 재대입과 배열 내부 수정은 다릅니다.
- `reduce`의 acc는 누적값, value는 현재 원소입니다. `return acc`는 다음 반복에 같은 배열을 전달합니다.
- `map`은 변환, `filter`는 선택, `forEach`는 원소별 작업, `reduce`는 누적 결과 만들기입니다. 이 문제에는 map이 자연스럽습니다.
- `Map`은 키·값 저장 자료구조이고 배열의 `.map()`과는 다릅니다. `Set`은 중복 없는 값 모음이며 이 문제에는 필요 없습니다.
- 추가 공간은 입력 외에 새로 사용하는 저장소입니다. 여기서는 반환 배열도 포함해 표기했습니다. 반환 배열을 제외하면 (1)~(3)의 보조 공간은 `O(1)`입니다.
